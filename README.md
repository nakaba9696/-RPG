# 星の記憶 — ディメンジョン探索RPG（試作）

Fantasian の「ディメンジョン」（遭遇した敵を異空間に溜めて、あとでまとめて戦う）を取り入れたオリジナルの探索RPGです。
素材・コードはすべてこのリポジトリ内で作成しています。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（外部ファイル不要）。

| 操作 | キー |
|---|---|
| 移動 | 矢印キー / WASD |
| 決定・話す・調べる | Z / Enter / Space |
| キャンセル・メニュー | X / Esc |
| ディメンジョン装置 ON/OFF | D |
| 溜めた敵とまとめて戦う | F |

スマホではタッチ用のボタンが画面下に出ます。セーブはメニューから（ブラウザの localStorage に保存）。

## 現在の内容

- マップ4つ（ハルの村・ミストの草原・ひびき洞窟・星見の遺跡）、宝箱、NPC、道具屋、宿屋
- 仲間3人（ヒロ・ミナ・ガルド）、レベルアップでスキル習得、装備
- ターン制バトル、ボス2体、ディメンジョン戦闘（最大20体を波に分けて連戦、ボーナス報酬）
