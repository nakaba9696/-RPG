# 差し替えの表 — 既存の文の直し案（D5）

[docs/knowhow.md](knowhow.md) の「避ける癖」（4.2）・「段階の印」（2.1）・world.md 10 章の「禁止語」で、**もう Map JSON に入っている文**を点検した直し案。
元の文（`docs/world.md` と `data/MapNNN.json`）は書き換えていない。差し替えるのは、そのマップを持つ W（第1段階のマップは W2）。

- 差し替えたら「済」の列に PR 番号を書く。差し替えないと決めたら「見送り」と理由を書く。
- 差し替えるときは Map JSON の 401 の行と、world.md の本文の両方を同じ文にする（world.md の本文の差し替えは、その W の PR で一緒に行ってよい）。
- 行の数が変わるもの（1 ページ 4 行を超えるもの）は無い。
- 点検した範囲：world.md 2.2 目覚め、2.4 セレスの一言、4.6 残留思念 R01–R17、5.1 オーブ「鎖」、6.1 オルドの記憶（R12）。あわせて W1 が Map JSON に足した「調べたときの文」（world.md に無い文）も見た。
- 禁止語（world.md 10 章）に当たる文は、この範囲には無かった。
