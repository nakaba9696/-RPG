# 見た目の土台（V1）

[VISION.md](../VISION.md) の核 8「暗く、神のいない世界」を、MZ に同梱の素材だけで出すための選定表。
子はエディタを開けないので、ここに候補を並べて推しを 1 つ付け、**最終的な見た目は持ち主がエディタで決める**（決定待ちは #24）。
素材（`img/`・`audio/`）の追加も持ち主が行う。子は候補を書くだけ。

作ったもの：
- 画面 1280×720（`data/System.json` の `advanced`）。
- タイルセット 11–14（`data/Tilesets.json`。作り方は `tools/maps/src/v1_tilesets.mjs`）。
- マップごとの色調・遠景・暗がりのプラグイン `Hai_MapTone`（書き方は [plugins/Hai_MapTone.md](plugins/Hai_MapTone.md)）。
- 試験場 Map903「T_見た目の試験場」（タイルセット 14、色調・遠景・暗がりのタグ付き）と、テスト `tests/v_look.mjs`。

## 1. 画面の大きさ 1280×720（#4）
- `System.json` の `advanced.screenWidth`・`screenHeight`・`uiAreaWidth`・`uiAreaHeight` を 1280・720 にした。
  UI の箱（`Graphics.boxWidth`・`boxHeight`）は余白 4 を引いた 1272×712。
- 見えるマスの数：横 26.7 マス × 縦 15 マス（816×624 のときは 17 × 13）。これより小さいマップは画面の真ん中に寄り、外は黒い。
  **ダンジョンのマップは 27 × 15 以上**にすると画面の外に黒い帯が出ない（D1 のマップはすべて満たしている）。
- 戦闘の背景（battlebacks）はコアが画面に合わせて引き伸ばす。敵の位置（`Troops.json` の `x`・`y`）はそのままの座標なので、
  P1 の敵グループ 101–103 は `x × 1280/816`、`y × 720/624` で置き直した。**1–6（MZ の既定・持ち主）は直していない**（エディタで直す）。
- テスト（`tests/lib.mjs`）のブラウザの窓は `System.json` の大きさに合わせる。スクリーンショットは 1280×720 で出る。

## 3. マップごとの色調・遠景・暗がり（推し）
書き方はマップのメモ欄に `<hai_tone:赤,緑,青,グレー>`、`<hai_parallax:名前,横,縦>`、`<hai_dark:半径>`（[plugins/Hai_MapTone.md](plugins/Hai_MapTone.md)）。
数値は推し（試験場で撮った比べ絵は V1 の PR の説明）。持ち主がテストプレイで決め直してよい（W レーンがマップを作るときに付ける）。

| 場所 | 色調（推し） | 遠景 | 暗がり | 狙い |
|---|---|---|---|---|
| 牢獄の間（010） | `-34,-34,-17,51`（少し青く暗い） | なし | なし | 冷たい地下。目覚めの場所は見通せる |
| 巡礼の森（020–021） | `34,34,51,153`（白っぽく色が抜ける＝霧） | なし | なし | 霧の巡礼路（`docs/world.md` 4.2） |
| 礼拝堂の地下納骨所（022） | `-68,-68,-34,119` | なし | `4` | 灰をかぶった骨の棚 |
| 廃坑（026–028） | `-85,-85,-102,68`（黄土色で暗い） | なし | `5`（崩落の間は `3`） | 灯の無い坑道。昇降機の小屋だけ明るくしてもよい |
| 地下牢（033–035） | `-51,-85,-85,85`（赤黒い） | なし | なし（更生の廊下 034 だけ `5`） | 拷問牢。廊下の暗がりで番犬が近くまで見えない |
| オーブの間（036） | `-68,-68,-34,68` | なし | なし | 記憶の場面の前の静けさ |
| 王都の門（015） | `-34,-51,-34,102` | `DarkClouds,1,0` | なし | 白い光の結界の前の曇天 |

- 色調の候補は **3 通り** を推す：A 上の表（場所ごとに色味を変える）／B すべて同じ `-68,-68,-34,68`（統一感。試験場の値）／C 色調なし（素材のまま。暗さは暗がりだけで出す）。推しは A。
- 遠景の候補（同梱 `img/parallaxes`）：`DarkClouds`（曇天）、`DarkSpace`（結界の向こう、虚無）、`RedSky`（灰化の空、第2段階の王都）、`Twilight`。地下は遠景なし。
- 戦闘の背景：同梱は「エリア型のマップでは背景なし（黒）」なので、W レーンはマップの設定で戦闘背景を指定する。推し：森 `Grassland`＋`Forest`、廃坑 `DirtCave`＋`DirtCave`、地下牢 `Stone1`＋`Stone1`、拠点 `Stone2`＋`Room1`。
- 色調は戦闘の画面（敵の絵）にも掛かる（コアが同じ `$gameScreen` の色調を使う）。暗がりは戦闘には掛からない。

## 4. 手がかりの見え方（P2 の Map902 を 1280×720 で）
- そのまま（色調なし）：苔の床（緑の草の 1 マス）がいちばん目立つ。影の途切れ・くぼみ（`A4:45` の茶色い段差の側面）・ひび割れは「見比べると気付く」程度。
- 暗い色調（`-68,-68,-34,68`）＋暗がり半径 6 の下：苔は沈んで「近くで注意すると気付く」程度になり、ほかの手がかりは光の輪に入るまで見えない。
- **判断**：P2 のタイルは変えない（強すぎ・弱すぎではない）。暗がりのあるマップでは、手がかりは光の輪（半径 4 以上）に入れば見える。
  暗がりの半径を 3 以下にするマップでは、手がかりを部屋の入口から 3 マス以内に置く（W レーンへの約束）。
