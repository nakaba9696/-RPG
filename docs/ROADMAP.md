## 共有ファイルと衝突を避けるための約束
- `src/main.js`（起動・シーン切替）と `src/data/items.js` は **追記だけ**。既存行の書き換えが要るときは PR の説明に書き、小さく。
- マップの文字の意味（`src/data/maps/legend.js`）に新しい文字を足すときは追記だけ。同じ文字を2本が足したら、後から入る側が変える。
- セーブの形式に項目を足すときは `save.js` の `VERSION` を上げ、古いセーブを読む分岐を残す。2本が同時に上げたら後から入る側が振り直す。
- キーの割り当て（`src/input.js`）は後から入る側が合わせる。
- 共有の見た目（色・フォント・窓枠）は `src/render/theme.js` に集め、V 以外は読むだけ。
- テスト `tests/run.mjs` は、各レーンが自分の `tests/<lane>_*.mjs` を足す形にして、共有の起動部分は T だけが触る。

- [ ] **C1** シンボルエンカウントと隠し通路。敵をマップ上の動く記号にし（色＝強さ、単純な巡回・弱い追尾）、接触で戦闘、避けられる。ランダムエンカウントと「ディメンジョン」を撤去。隠し通路の文字（見えない通路・隠し扉・片側からだけ開く扉・隠し階段）と、手がかりの描画規則（植生違い・影なし壁・くぼみ）。全滅時は魔石を落として拠点へ戻る。
