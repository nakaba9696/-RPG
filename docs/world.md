## 1. 世界と年表

### 1.1 骨子（10 行）
1. ここは**終わったあとの世界**。約 200 年前の「**二度目の夜**」に、使徒がいっせいに境山を越え、三つの国は一夜で終わった。〔知〕
2. 昔、人は古言の銘で**鐘**を鋳た。鐘の鳴る所に使徒は入らない。昔の、人と使徒の取り決め。四つの地域の鐘と、山の頂の**親鐘**。〔知〕（鐘の鳴る所に使徒は来ない）〔進〕（取り決めと親鐘）
3. 二度目の夜、四つの鐘は**同じ夜に黙った**。頂の鐘楼で、誰かが門叩きの「入れておくれ」に答えた。〔噂〕同じ夜に黙った／〔進：頂〕答えた人
4. 主人公は**死者の思いを聞き、拾い集める使徒**（呼び名の推し「**聞き手**」）。同じ型の使徒は拾った思いを喰う。主人公は喰わずに、思いを生きている人へ届けた。〔進：3 つ目の鐘〕
5. 主人公は人の姿で、黒鉄の砦の**墓守（弔い人）**として暮らしていた。正体を知っていた人は少ない。〔知〕墓守がいた／〔進：3 つ目の鐘〕使徒だったこと
6. 二度目の夜、主人公は死んでいく砦の人の思いを全部拾おうとして、あまりの数に**自分が埋もれ**、記憶を失って 200 年眠った。〔進：3 つ目の鐘〕
7. 今も各地に残る**残留思念**は、そのとき拾いきれなかった思い。主人公にはそれが見え、意志の強い思いは**仲間**として一緒に歩く。〔知〕（見えること・仲間になること）〔秘〕（拾いきれなかった分だと一文で言うこと）
8. 目覚めた墓所の壁の書き付け「**四つの鐘を鳴らして。それから、山の頂の鐘楼へ**」。書いたのは、正体を知っていた生き残りのエルフ**ミルレーネ**。使徒の縄張りを歩けるのは使徒だけなので、主人公にしか頼めなかった。〔知〕書き付け／〔進：015〕書いた人と理由
9. 3 つ目の鐘のあと、主人公は自分が何者かを知る。仲間の一人は「あたしらを喰う気か」と離れ、4 つ目の地域で戻る。〔進：3 つ目の鐘〕
10. 親鐘が鳴ると、使徒は境山の向こうへ退き、灰が止む。仲間は思いを生きている人に届け終え、一人ずつ去る。主人公は使徒なので鐘の内側には住めず、頂の鐘楼に残って夕べに親鐘を鳴らす。麓の子どもが数を数えに登ってくる。〔進：015〕

### 1.4 使徒（この世界の型）
- **人の言葉を解する化け物**。誰もが「使徒」と呼び、土地の呼び名を添える。名（古い刻印の読み）は碑文と記録院の写しにだけ出る。〔知〕呼び名／〔進〕名
- **縄張りを持ち、互いの縄張りに入らない。** 縄張りの中は霧や灰が濃く、人は長くいられない（迷う・息が詰まる）。**使徒は使徒の縄張りを歩ける**。〔知〕人は縄張りに入れない／〔進：3 つ目の鐘〕主人公が歩けた理由
- 自分から動く理由は、それぞれの性分だけ。筋のために動かさない。話が通じても、話が合うとは限らない。人は正面からは勝てない（格三。[knowhow.md 2.3](knowhow.md#23-敵や大きな存在の格)）。
- **使徒とは戦わない。** ボスは使徒の連れか、使徒ではない化け物か、留まりすぎた砦の人の魂（[4.4](#44-ボスの一覧)）。

| 呼び名／名 | 姿と性分 | 縄張り・出る所 | 人との関わり | 段階 |
|---|---|---|---|---|
| **聞き手**（主人公） | 死者の思いを聞き、拾い集める型の使徒。人の姿で砦の墓守をしていた | 縄張りを持たない（死者のいる所を歩く） | 拾った思いを喰わずに、生きている人へ届けた | 〔噂〕墓守さまは死んだ人の声を聞く／〔進：3 つ目の鐘〕主人公だということ |

### 1.5 「誰が悪いか」を決めない
- 頂の鐘番は、戸の外の声に答えた。声は、去年死んだ娘の声だった（〔進：015〕。答えた理由を責める文は書かない）。門叩きは性分どおり入っただけ。〔秘〕（誰が悪いかは誰にも判定させない）
- 主人公は全部を拾おうとして埋もれた。拾えなかった思いが今も各地に残っている。それを主人公の失敗と書かない。〔秘〕
- 断片は食い違わせる：「鐘喰いが食べた」「鐘が古くなった」「頂の鐘番が裏切った」「使徒どうしの取り決めが切れた」。どれが本当かは書かない。

### 1.6 今の暮らし
- 集落は 20〜40 人ほど。井戸と畑と、夜に灯す灯。戸は夜に開けない。〔知〕
- 通貨は**鉄くず**（`Hai_Defeat` が落とす所持金。古い釘・蝶番・鎧の板。集落どうしで重さで量る）。〔知〕
- 祈りは「夕べの数」：夕べに指で鐘の形を切り、三十まで数える。鐘を知らない子もする。〔知〕
- 言い習わし「**墓守さまに言い残す**」：死ぬ前の言葉を墓に向かって言うと、いつか家族に届く。今は誰も届けていない。〔知〕
- 今の人は使徒の名も、古言も、鐘の取り決めも知らない。知っているのは習いと言い伝えだけ（[knowhow.md 2.2](knowhow.md#22-説明役に語らせない)）。

### 1.7 前から見えている手がかり
3 つ目の鐘のあとで「だからか」と思えるように、最初から置いておく。どれも**説明しない**。一つでは答えにならない。
**いちばん大きな手がかりは、ゲームの仕組みそのもの**：残留思念が見えて、仲間にできること。誰も「なぜ見えるのか」を言わない。

| 手がかり | 見える所 | 見せ方 |
|---|---|---|
| 残留思念が見え、仲間にできる | どこでも | 生き残りには思念が見えない（シャノ「誰と話してんの？」）。名の壁で呼んだ仲間も、生き残りには見えない（食堂の席は空いて見える） |
| 年を取らない | 名の壁、墓守の帳面、仲間の一言 | 名の壁の「墓守」の欄だけ、名前が何度も彫り直してある。ベルトラン「お前、俺が来たときから顔が変わらねえな」（冗談として） |
| 古言と使徒の名の刻印が読める | 礼拝堂の碑文、記録院の刻印の写し | 主人公が調べると、ほかの人には読めない行が一行だけ読める（訳は出さない） |
| 縄張りの中で平気 | 霧の壁・灰の吹き溜まり | 生き残りは「ここから先は息ができない」と止まる。主人公だけ入れる。書き付けの「あなたにしか頼めない」 |

### 2.3 目覚めと最初の数分（案内役なし・主人公の台詞なし）
**狙い**：誰にも説明されずに、最初の数分で「ここは崩れた砦」「四つの鐘を鳴らして山の頂へ行く」「まず砦の下と霧の森」「死んだ人の思いが見える」が分かる。
すべて**調べると分かる物**と、最初の生き残りシャノの用事の一言と、最初の残留思念で示す。

1. **墓所**（010 の西。前の世界の目覚めの独房の位置）。画面は黒から始め、棺の並ぶ石の部屋の床で目を開ける。自動で 1 行だけ。
   ```
   床の小さな鈴が、まだ揺れている。
   ```
   扉は開いている。床の灰に、小さな足跡が外へ続く（調べると「灰に、裸足の小さな足跡。外へ駆けていった」）。
2. **最初の残留思念**（墓所の棺の一つ）。棺の上に、薄い人の影が座っている（主人公にだけ見える）。調べると思念（一つの無念）。
   ```
   娘の婚礼の歌を、まだ半分しか覚えていない。
   墓守さん、続きを聞いといてくれ。
   ```
   これで「死んだ人の思いが見える・聞ける」ことを最初に見せる。説明はしない。
3. **墓所の壁の書き付け**。棺の正面の壁。調べると：
   ```
   壁に、刃物で刻んだ字がある。
   「四つの鐘を鳴らして。それから、山の頂の鐘楼へ。
   　あなたにしか頼めない」
   ```
   選択肢なし。読むと `Hai_Thoughts` のメモに「四つの鐘を鳴らす。それから山の頂の鐘楼へ（墓所の壁）」が残る。**これが目的**。
4. **炉**（大広間の北の壁）。調べると「炉は冷えている。脇に、乾いた薪が積んである」→「火を入れる／やめる」。入れると「炉に火が入った」。
   以後、炉は**回復と記録**。`Hai_Defeat` の戻り先と `Hai_Warp` の拠点の結界もここ。
5. **シャノ**（最初の生き残り）。炉に火を入れたあと、柱の陰から出てくる。
   ```
   シャノ「……火、つけたの、あんた？」
   シャノ「おれ、鉄を拾いに来ただけ。鈴、蹴っちゃった。ごめん」
   シャノ「名前は？　……ないの。ふうん。さっき誰と話してたの？」
   シャノ「鐘？　この砦の地下の牢に、一つ吊ってあるって。鉄の扉は開かないけど」
   シャノ「あと、外の森で炊き出しの爺さんが三日帰ってない。霧の中」
   シャノ「おれは霧、だめなんだ。息ができなくなる。……ここ、ちょっといていい？」
   ```
   主人公は答えない（選択肢なし）。シャノは大広間に残り、**倉**が開く（[3.3](#33-部屋が開く順と条件)）。メモに「鐘：砦の地下の牢（シャノ）」「炊き出しの爺さん：外の森の霧（シャノ）」。
6. **中庭**。中庭から東の空を調べると「雲の上に、塔の影が一つ。山の頂だ」。〔知〕
7. **外門**（010 の北）。門の内側を調べると「門の板に、拳ほどの凹みが三つ。縦に並んでいる」。〔噂〕門の外が霧の森（020）。
8. **営倉への鉄扉**（010 の南）。調べると「錆びついて動かない。向こう側に閂があるようだ」。
   → 森から坑道を抜けて営倉へ回り、内側から開けると拠点への近道になる（[mapdesign.md 3 章](mapdesign.md#3-近道の数と場所)）。

- 目覚めの場面は**主人公の台詞なし・説明の語りなし**。名前・世界・正体を誰も言わない。
- 迷ったときの戻り道：炉の前で「休む」と、メモの最新の行がもう一度出る（`Hai_Notes` の画面を開くだけ）。

### 2.4 鐘の間の場面のあとの主人公の一言
鐘の間の場面（[7.2](#72-鐘の間の場面)）のあと、主人公が一行だけ言う。事実か問い。一人称を使わない。場面と同じく、**鳴らした数**で決まる（どの鐘かによらない）。
| 数 | 一言 |
|---|---|
| 1 | 「……覚えている。この人の葬式を出した」 |
| 2 | 「墓守の帳面。全部、同じ手だ」 |
| 3 | 「拾って、拾って……そうか。拾う者だったのか」 |
| 4 | 「喰わずに、届けた。そう決めた日がある」 |

### 2.5 3 つ目の鐘のあと（正体が分かる）
3 つ目の鐘の間で、そこで死んだ人の思念を聞くと、主人公は二度目の夜の墓所を思い出す（7.2 の 3）。場面のあと、転送陣で砦へ戻ると自動で次の場面。
1. **名の壁の前**。呼んでいる仲間（いなければ、炉の前の生き残り）が待っている。主人公の一言「……思いを拾う使徒が、ここにいた」。
2. **仲間の反応は分かれる**（呼んだ仲間だけ。一人一行〜二行。説明させない）：
   | 仲間 | 反応 |
   |---|---|
   | ブルーノ | 震えながら「……知ってました。門の前で、化け物がルカさんを避けて通ったから。言えなかっただけです」 |
   | ノラ | 「あたしらを喰う気か」。名の壁から離れる。**いったん仲間から外れる**（2.6） |
   | ディル | 「刻印の写しに、あんたの型があった。拾う使徒は、拾った物を喰う。……あんたは、喰わなかった」 |
   | ゼリナ | 「つけは帳消しにせえへんで。使徒でも払ってもらう」 |
   | アンセルモ | 「わしの弔いの言葉、半分はお前さんが届けとったんじゃろ。……知っとったよ」 |
   | ベルトラン | 「顔が変わらねえと思ってたんだ。……剣は、変わらず下手だな」 |
   | トゥーラ | 「兄貴は兄貴だろ。飯、食ったのかよ」 |
3. 以後、主人公は**使徒の技**を覚える（2.1）。生き残りの反応は変えない（生き残りは昔を知らない。シャノだけが「だから、誰もいない所と話してたのか」と言う）。
4. 1.7 の手がかりの意味が、仲間の一言と思念で後から開く（骨拾い「拾う者どうし」、思い喰いの「なぜ喰わない」）。

### 2.6 離れる仲間と、戻る場面
- 離れるのは**ノラ**（推し）。二度目の夜に村の家族を失った。同じ型の使徒（思い喰い）が、死んだ人の思いを喰うと知っている。主人公も喰うのではと怖くなる。
- 離れている間、ノラは名の壁から消え、編成に入れられない。記憶の断片は読める。
- **4 つ目の地域に入ると**（どの地域が 4 つ目でもよい。変数「鳴らした鐘の数」が 3 のとき、その地域の入口のイベント）、ノラが道の先で待っている。
  ```
  ノラ「ずっと見てた。あんた、思いを拾っても、一つも喰わなかった」
  ノラ「村のみんなの思いも、拾ってくれたんだよね。たぶん」
  ノラ「……それでも、あんたと鳴らす。行こう！」
  ```
  ノラが戻る。完全体の条件は変えない。
- ノラを呼んでいなかったら、この場面は無い（離れる人がいない）。

## 4. 地図と段階

### 4.0 全体
砦を真ん中に、北に霧の森、北東の山に鉄の坑道、砦の下に営倉。東の尾根に**境山の古道**、西の谷に**焼けた村**、南西の低地に**霧の湖**、北西の丘に**記録院**、山の根の下に**古い鋳物場**、砦の真下に**砦の下の水路**。いちばん東の高みに**山の頂の鐘楼**。
マップは**網の目**につなぎ、1 枚を広くし、近道と「後の物で開く道」で前の場所へ戻らせる。作り方の決まりは [docs/mapdesign.md](mapdesign.md)。
前の世界のマップは**形をそのまま使う前提をやめ**、この網に合わせて作り直す。使い回すのは ID の帯と、遠い所がつながる 4 つ（H22・H31・H34・H35）の考え方、それに形の合う小部屋だけ（4.1）。

  - 記録院の鐘：森 → 焼けた村 →（火の番）→ 記録院。
  - 鋳物場の鐘：坑道 → 境山の古道 →（陣跡の地下壕の鍵）→ 古い鋳物場。
  - 水底の鐘：森 → 焼けた村 → 霧の湖 →（沼主）→ 砦の下の水路、**または** 営倉 →（牢番の鍵束）→ 水路。
- 本道で要る「後の物」は、牢番の鍵束・鐘番の角灯・見張り塔の小鐘の 3 つだけ。ほかの物と仲間で開く道は寄り道（[mapdesign.md 4 章](mapdesign.md#4-後の物で開く道)）。
- ボスの強さは鳴らした鐘の数で変えない。

## 5. 仲間

### 5.1 仲間の決まり
- 各地に、**無念のまま死んだ人の残留思念**がある（`Hai_Thoughts`）。二度目の夜に墓守が拾いきれなかった思い。たいていはその場で、一つの無念をくり返すだけ。〔知〕（あること）〔進：3 つ目の鐘〕（拾いきれなかった分であること）
- そのうち**意志の強いもの**は、遺骸か形見を名の壁に置くと**呼べる**。仲間として一緒に歩き、戦う（`Hai_Companions`）。〔知〕
- **仲間は主人公にしか見えない**。生き残りには見えず、声も聞こえない（食堂の席は空いて見える。1.7）。〔知〕
- 仲間はみな二度目の夜に死んだ砦の人で、**墓守としての主人公を覚えている**。覚えていないのは主人公だけ。仲間は主人公を名前で呼び、昔の続きの口をきく。〔知〕
- **正体を知っていた仲間は少ない**（ディルは刻印で、アンセルモは弔いのそばで、ブルーノは見て。言わなかった）。3 つ目の鐘の前に、仲間に正体を言わせない。
- 仲間が知っているのは**自分が見たことだけ**。仲間に真相を説明させない。
- 記憶は 4 断片（生い立ち・転機・罪か誇り・臨終）。4 つ揃うと完全体で強技（今の仕組みのまま）。〔進〕
- 仲間それぞれに**無念**と、思いを届けたい**生きている人**がいる（たいていは、その人の子孫の生き残り）。親鐘が鳴ったあと、届け終えて去る（8 章）。
- 人物は Morsveld の人物のスターシステム。**性格の芯・口調・癖・好き嫌い**を写し、経歴・家族・国・年はこの世界で新しく作った。絵は Morsveld の素材集の同じ人物のものを使える（人物の id が同じ）。

**ディル（メイジ）**：生い立ち＝字も勘定も捨てられた本で覚えた港の子（080 前庭の書見台）／転機＝砦の書記になり、古言と刻印を読めることを隠した（081 書架）／

## 7. 集める物と真相の出し方

### 7.1 四つの鐘
今の「記憶のオーブ 4 つ」の代わり。鐘は**持ち帰る物ではなく、鳴らす場所**。鐘の間でボスを越え、鐘の綱を引くと鳴る。
**鐘の力は主人公と関係ない。** 鳴らすと鐘の近くの縄張りが少し退き、頂の鐘楼の扉の閂が一つ外れる（銘の決まり：親鐘の戸は、四つが鳴ると開く）。
記憶は鐘からは戻らない。鐘の間には、そこで死んだ鐘番の残留思念があり、鳴らしたあとにそれを聞くと、主人公の記憶の一場面が浮かぶ（7.2。思いを聞く力のほう）。

### 7.2 鐘の間の場面
鐘を鳴らしたあと、鐘の間の**鐘番の残留思念**を聞くと、画面を暗くして主人公の記憶の一場面（文章だけ。7〜10 行）。地の文の主語は「自分」、昔の主人公の台詞は一人称を使わない。**鳴らした数**で場面が決まる（どの鐘でも同じ順）。最後に主人公の一言（2.4）。

7.2.1 一つ目：弔いの日〔進：1 つ目〕（本文。第1段階で作る）
```
夕べ。墓所の前の土が、まだ柔らかい。
兵の母親が、墓標の前に膝をついている。
自分は、墓に耳を寄せる。聞こえた言葉を、そのまま言う。
「春になったら、屋根を直す。約束を守れなくてすまない」
母親は、しばらく何も言わなかった。
それから指で鐘の形を切って、三十まで数えた。
頂の鐘が、ちょうど三十で鳴りやんだ。
```
（主人公の一言：「……覚えている。この人の葬式を出した」）

7.2.2 二つ目：変わらない手（案）：墓守の帳面に名前と言い残しを書く自分の手。上の行に、同じ手の字が何十年分も続く。ベルトランが若い。次の頁ではベルトランに白髪がある。その次の頁では、ベルトランの字で「墓守、まだ若いな」と落書き。自分の手は変わらない。〔進：2 つ目〕

7.2.3 三つ目：二度目の夜の墓所（案・正体が分かる）：鐘が黙る。外で叫び声。墓所の中に、死んでいく人の声が次々に流れ込んでくる。一つ拾う。また一つ。拾うたびに、それは自分の中に積もる。同じ型の使徒なら、ここで喰う。自分は喰わない。数が増えて、自分の名前が声の下に沈んでいく。最後に聞こえたのは、門番が数を数える声。自分は**死者の思いを拾う使徒**で、墓守をしていたことを思い出す。〔進：3 つ目〕
（「墓守は使徒」「思いを喰う」などの語は、この場面から出してよい。10 章）

7.2.4 四つ目：喰わなかった最初の日（案）：ずっと昔、山の麓の村の墓。死んだ子どもの思いを拾い、喰おうとしたとき、墓の前で母親が指で鐘の形を切り、三十まで数えはじめる。自分は口を閉じ、拾った思いをその母親に渡す。それから、人の姿をとった。母親の名前は出さない。〔進：4 つ目〕

7.2.5 頂：親鐘（8 章）：頂の鐘番の思念で、二度目の夜に誰が戸を開けたかが分かる。墓所の書き付けを書いたのがミルレーネだと分かる（彼女が砦に来ていれば、本人が隣で言う）。

## 8. 結末

### 8.1 頂へ
- 四つの鐘を鳴らすと、城壁の上（019）の東の端の門の先、頂への道が通れるようになる（縄張りが退き、灰の吹き溜まりが崩れる）。頂の鐘楼の扉の閂が四つとも外れている。
- 鐘楼の戸の前に、**頂の鐘番**（留まりすぎた魂。二度目の夜に戸を開けた人）が立っている。「もう誰も入れない」とだけくり返す。
  - 頂の鐘番はボス。**使徒とは戦わない**決まりはそのまま（門叩きは出ない）。倒すと静かに崩れ、日誌が残る。主人公は、この人の思いも喰わずに拾う。
- 親鐘には舌が無い。**親鐘の替えの舌**（7.1）を吊る。仲間が一人ずつ一言（記憶が揃っている仲間ほど長い）。ここで仲間は「鳴らしたら、届けに行ける」と**自分で気づいて**口にする（誰かに説明させない）。

### 8.2 結末
| 結末 | 名前 | 条件 | 中身 | 段階 |
|---|---|---|---|---|
| 一 | 夕べの数 | 親鐘を鳴らす | 主人公が綱を引く。三十打つ。四つの地域の鐘が一つずつ応える。使徒は境山の向こうへ退き、灰が止む。仲間は一人ずつ、思いを届けたい生き残り（5.2）のもとへ行き、届け終えて去る（生き残りには見えないが、その人が何かに気づく一行）。主人公は使徒なので鐘の内側には住めない。頂の鐘楼に残り、鐘守りとして夕べに親鐘を鳴らす。麓から子どもが数を数えに登ってくる。最後は静かな朝の頂と、登ってくる小さな足音 | 〔進：015〕 |
