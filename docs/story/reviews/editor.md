## 1. 案ごとの講評

### 案 A「名前」

**テーマ**：一つに絞れている。三案で最も鋭い。「夜に名を呼ばれても答えるな」という世界の習いを、「人は呼ばれて初めて一人になる」に裏返す。しかも世界の側に根がある。名無し兵・檻の番号・署名しない写字生・「印、無し」・空白のつけ帳と、既にある小道具が全部「名が消される場所」として一本に通る。設定を足さずに主題を立てた。これが編集者の言う「設計の強さ」だ。

**主人公の弧**：成立している。八段の「知る順」（名が無い→呼ばれていた→消される場所→呼ぶ声ごと渡した→名は門叩きの口に→ルカ→集めていたのは名→答える）は、どれも前の段を踏まないと次に行けない。中でも「記憶を渡すたび、その人が自分を呼んだ声も出ていく。だから五冊目の帳面は名の欄が空白」は、既にある小道具（帳面）に**因果**を与えた唯一の発明で、驚きの必然がある。序盤に読める帳面が 3 つ目の鐘のあとで裏返り、読み返しに行ける。これは小説の作法そのものだ。

**人物**：弱い。仲間 7 人の「変わる瞬間」は「お名前は」「あたしが付ける」「一行空けとく」「つけ帳」と、全員が**名の話をする一行**で揃っていて、人物が主題の係になっている。ブルーノとトゥーラ以外は、名の糸を外すと世界設計書の一覧と変わらない。生き残りの表も同じ。人が主題を運ぶのではなく、主題が人を使っている。

**伏線と回収、驚きの必然**：帳面の空白・二文字の空白・「呼んでやろうか」で音が来ない・名の欄が変わる、の四つが一本の糸で、回収は全部プレイヤーの手か目で起きる。良い。ただし「二文字の空白」は、初めて遊ぶ人には**文字化けか誤植に見える**。F01 で一度は「誰も空いているとは言わない」でよいが、F03 あたりで型を崩さないと、十一か所すべてが同じ穴だと三つ目で読めてしまう。

**山場と結末**：二つ目の山（塊の間）が三案で最も強い。三つ目の山（頂）はそれに負けている。頂の「読んだ名の数だけ去る」は仕掛けとしては面白いが、場面としては「名を読み上げる戦闘」で、二つ目の山の余韻を消化する作業に見える。頂に、頂だけの出来事が要る。結末の「ルカ！　爺ちゃんが、飯だって！」「答えた。」は短く強く、習いを昼に裏返す着地として正しい。

**文章**：7.2 の司祭の場面が、三案を通じていちばん良い一場面だ。
> 戸の向こうから、声がする。わたしの名を呼んでいる。／墓守の声だ。眠っているのに。／手を止めた。戸は見ない。／眠っている方へ、向き直る。

「夜の戸に答えない」習いを、戸に背を向けて**眠っている本人に名を返す**ことで守った。四行で、愛情と習いと真相が一度に通る。説明が無い。これを書けた作家は信用できる。
書き直した地域五（#201）の列の女の思念「役人は書いた。読み上げもした。／名を呼ばれて、この子が笑った。初めてだ」も、取り立ての帳面という嫌な物に名の糸を通して、事実で終えている。主題を場面で書けている箇所だ。
甘い所：直後の主人公の一言「……戸には、答えなかったのか」は、今の四行が言ったことをもう一度言っている。落ちた彫り刀で止めるべきだ。門叩きの「呼ばれてしまったか。それでは、もう、同胞ではない」の二行目は、主題を口で説明している（呼ばれる＝同胞でなくなる＝人になる）。「呼ばれてしまったか」で切る。

**ご都合・説明過多・感傷**：「夜の戸」の小イベントは「答えると小さな戦闘。何も失わない」とある。何も失わない選択は習いを教えない。歯が無い。頂の「読んでいない名は呑まれになる」は、読まなかったプレイヤーへの罰として働く。罰ではなく「残る重さ」（読まなかった言い残しは、山を下りてもルカの帳面に空白のまま残る）にすると、同じ仕掛けが感傷でなく事実になる。「呼んでやろうか」の選択肢は、どちらでも同じ結果と作家が認めている。二度目の「手だけの選択」で、一度目（夜の戸）と合わせると癖になる。

### 案 B「砦の人々」

**テーマ**：「会ったことのない人からも受け取っている。受け取った側は分からない。それでも届く。プレイヤーだけが両側を見る」。絞れている。しかも**ゲームでしか成立しないテーマ**で、生き残りには仲間が見えないという既存の決まりを、そのまま主題にした。

**主人公の弧**：三案で最も弱い。「届ける側で、受け取る側になったことがない」は良い着眼だが、墓守は旅のあいだずっと**カメラ**で、変わる瞬間が結末の椀と刻みまで無い。3 つ目の鐘の場面は world.md の文を一言だけ変えて（「預けた」→「渡していた」）写しており、塊の間の司祭の場面も world.md のままだ。二つの山に、この案固有の主人公の出来事が一つも無い。群像を軸にするのは構わないが、真ん中が空洞の群像は、長編では十時間もたない。

**人物**：三案で最も良い。七つの対が全部**物**でつながる（巻いた鐘・山の火・二つ目の書見台・「ゼリナ（舟代）」・歌詞の無い節・袖の下の傷と酒の匂い・「帰りは軽い」）。とりわけベルトラン→ピピネル（斬った子に息があり、二百年小屋から出ない）とトゥーラ→シャノ（意味を知らずに言い継がれた「帰りは軽い」）は、それだけで短編になる。人物の望みと傷が、一行の台詞に出ている（ピピネル「酒くさいのう」「行ったか」）。

**伏線と回収、驚きの必然**：ここが問題だ。七組が七組とも血か直接の縁でつながると、**世界が狭くなる**。砦に来た生き残りが、たまたま全員、仲間の子孫か当事者。これは VISION 8 の「一つの真実を語る者はいない」「誰もが自分の暮らしで懸命に生きているだけ」と逆向きの力で、Fanastasis の手触り（自分の知らない所で世界が終わっていた広さ）を削る。アンセルモ→グィドだけが血でつながらず、作家もそこに気づいて「歌は血が無くても届く」と書いた。その一組こそがこの案の正しい形で、ほかの六組がそれに倣うべきだ。イスメネが二百年前の記録院にいた、は七組の中で最も都合がよい。

**山場と結末**：「引く」「まだ」は三案で最高の一手だ。別れの時をプレイヤーの手に渡し、何度でも「まだ」を選べる。これはゲームでしか書けない別れで、小説の編集者として嫉妬する。親鐘の三十打で画面を砦に切り替えるのは逆に惜しい。頂をプレイヤーの手から取り上げている。

**文章**：7.2 の結末の食卓が、三案で最も「人の書いた文」に近い。ずれる返事、遮り、言葉の足りなさが全部ある。
> ヴォルフラム「食え。それはお前の分だ。今日からは」／アデル「……誰に言ってんだ、私」／食卓の椀が十四、伏せて干してある。

最後の一行は物で終わり、始まりの「伏せた椀が一つ」と対になる。これは着地として完成している。
甘い所：七人が立って消え、生き残りが一行気づく、を七度。型は同じで、二十五窓を越える。四人目あたりで読者は型を読む。書き直し（#204）で二組は良くなった。アンセルモ→グィドは節から数え歌「ひとつ、戸の外。ふたつ、扉の前」に替わり、音無しで字だけで通る。ノラの退場は「風か？」から、アンネリーゼが中庭で火を焚く「帰ってくるのがいる」「知らねえ。うちは昔から、そうしてる」に替わり、山の火の糸が結末まで届いた。ただし添えた「二百年前に見張り台で上げた火と、同じ高さの火だ」は作家の注で、画面に出すなら消す。読者はもう分かっている。冒頭の「伏せておく／起こしておく」は、三分目で**結果の無い選択**をプレイヤーに教える。椀の向きが結末に残るなら、残ることを一度だけ見せる場所が要る。

**ご都合・説明過多・感傷**：上に書いた「世界が狭い」が最大。感傷はほぼ無い。トゥーラ「寝ろ、馬鹿」は押し売りの手前で止まっている。

### 案 C「鐘の真実」

**テーマ**：「死んだ人は、ひとこと聞いてもらえたら行ける。鐘も墓守も戸を叩く音も、そのためにあった」。言葉としては一つだが、物語の中では**謎の解答**と**主題**が同じ文で、裏返しが通らないと主題も届かない構造になっている。

**主人公の弧**：三十一の癖（指が一つ多く動く）を、F11・鐘番・井戸番の F09「三十一は無いよ」・門叩き「お前はいつも一つ多い」・シャノ「灯が一個多くない？」・ミルレーネの歌わない節で網にした。**伏線の網としては三案で最高**だ。ただし弧は「数える人が、最後に数えきる」で、内側の変化（何を失い何を選ぶか）は world.md の範囲を出ていない。3 つ目の鐘の場面に足したのは「三十一人目は、まだ来ない」の一行だけ。

**人物**：3.1 の「裏返ったあと」の欄が諸刃。ブルーノ（巻かれなかった鐘だけが音で行ける）、ノラ（山へ向けた火は妹の道）、アンセルモ（歌は鐘の代わりで届かなかった）は裏返して深くなる。研究所（鐘無しで死者を運べる人を作ろうとした）、名無し（名の無い者は乗れない）、骨拾い（同じ側の者）は、全部の断片を裏返しに奉仕させた**後付け**で、読者は「それも伏線でした」の三度目で冷める。裏返るのは三つまででよい。

**伏線と回収、驚きの必然**：裏返しの中身（鐘は壁でなく道、戸を叩くのは迎え）は、既に main にある文（鈴・「入れておくれ」・凹み三つ・「こたえない」・巻かれた鐘・「鳴らしてはいけないそうです」）がほぼそのまま種になっていて、作り直しが少ない。経済としては見事だ。
だが二つ、構造の問題がある。
一つ。**裏返しを運ぶのが、頂で読む四行の銘**だ。作家は「説明する人はいない。銘だけ」と言うが、世界の仕組みを四行で言い切る碑文は、説明役の口を鐘に付け替えただけで、knowhow 2.2 が避けろと言う形そのものだ。おまけに真の結末でミルレーネの節「応えなくば　迎えにゆく」が同じことをもう一度歌う。二度説明している。
二つ。**裏返しが、二百年の惨事を「誤解でした」にしかねない。** 使徒が迎えに来ていただけなら、三つの国が終わった夜も、骨の山も、使徒狩りも、司祭を喰った門叩きも、全部が行き違いになる。作家は「どちらが正しいかは書かない」「届けるは行かせないでもある」と線を引いているが、銘の四行はその線を越えて断定している。逆転物の典型の罠で、驚きは出るが、それまでの十時間の悲しみが軽くなる。

**山場と結末**：7.2 の三十は、一回ごとに誰かが行く構造で、長編の最後としてこれ以上ない型だ。ただ、七人の退場それぞれに砦や村への画面の切り替えを挟むのは、頂の圧を七度切る。切り替えは二度までにして、残りは音だけにする。「ルカ」を塊の間と頂で二度言わせるのは、一度目を薄くする。声の無い「ルカ」は良いが、頂では別の一語が要る。
書き直しで足した結末の夜と朝（7.3、#205）は、三案の結末の中で最も**最初の一行に返る**形になった。外門を三度叩く音で食卓が黙り、アデルが「数えたら、閉めるの。それが決まり」と習いを最後にもう一度言い、開ければ「段に、小さな真鍮の鈴。／紐は、新しい」。冒頭の「紐が、途中で切れている」を一語で返した。開けない側の「閂に手を置いたまま、三十を数えた。／音は、二度目は来なかった」も同じ重さで書けていて、選択を罰しない作りに筋が通っている。朝の「三十のつぎって、なんだっけ」「三十一」は、主人公がゲームで初めて人に何かを教える一行で、弧の着地として正しい。ここは A の「答えた」と並ぶ。

**文章**：仲間の退場の一行は三案でいちばん粒が揃っている。
> ブルーノ「鳴りました。隊長、鳴りました」／ブルーノ「僕のは、巻かなくてよかったみたいです」

これは三案を通じて最良の仲間の台詞だ。鐘を巻く動機と裏返しとブルーノの傷が、説明なしに一行で通る。ディル「あんた、読める顔になったな」、ゼリナ「まけといたる」、ノラ「あんた、足、遅いね！」も良い。
甘い所：アンセルモ「向こうで歌う。ちゃんと最後まで」は感傷の手前。ヴォルフラム「十四人ぶん多い！　誰ぞ来るのか」はできすぎ。冒頭の老人の思念を老人の目に替えた四行（「わしには何も聞こえん。いつものことだ」）は良い改稿。司祭の名をテオと揃えるのは要らない符合。7.3 の最後「炉の火は、まだ燃えている」は物で終えてはいるが、直前の「三十一」のほうが強い。一行で止める勇気が要る。

**ご都合・説明過多・感傷**：銘と節の二重説明。「裏返ったあと」の後付け三件。鳴らした地域の敵が全部東を向いて止まるのは、文字無しの見せ方として三案で最も強い一方、鳴らしたあとの地域から脅威が消える。演出家の領分だが、物語の側でも「止まった者が頂の群れになる」を先に見せておかないと、ただ楽になっただけに見える。

## 3. 順位と理由

**1 位 案 A、2 位 案 B、3 位 案 C。** ただし差は小さく、三案は**混ぜる前提で**読むべきだ。理由は一つ。A のテーマ「名を呼ばれて答える」は、B の「届く」も C の「戸に答える」も中に含めるが、逆は成り立たない。C の裏返しを芯にすると A の墓守のしたことが変わり、B を芯にすると主人公がいない。A を背骨にし、B の肉と C の網を移すのが、傑作に最も近い道だ。

### 案 A を傑作にするための直し（作家への指示）

1. **人を主題の係から解放する。** 仲間 7 人の「変わる瞬間」から、名の話をする一行を四人分削る。代わりに B の七つの対を入れるが、**血か直接の縁でつなぐのは三組まで**（ベルトラン→ピピネル、トゥーラ→シャノ、ゼリナ→ヴォルフラムの帳面）。残りはアンセルモ→グィドの型（血が無くても届く）に倣い、物と言い習わしだけでつなぐ。世界を広いままにしておく。
2. **頂に、頂だけの出来事を置く。** 今の頂は塊の間の消化になっている。B の「引く」「まだ」を綱の前に入れ、C の「三十一」の網（F09・F11・鐘番・門叩き「一つ多い」・シャノ「灯が一個多い」）をそのまま移す。三十を数えるあいだに去る七人の一行は C の粒で書き、ブルーノの「僕のは、巻かなくてよかったみたいです」はそのまま使う。画面の切り替えは二度まで。「ルカ」は塊の間で一度だけ。頂では名を呼ぶのは仲間で、司祭は手ぶらで立つだけにする。
3. **「読んだ名が弾になる」を罰から残り物に変える。** 読まなかった言い残しは呑まれにせず、**山を下りたあとも帳面の名の欄が空白のまま残る**事実にする。結末の書庫で、埋まった行と空白の行が並ぶ。読んだ人には弔いに、読まなかった人には「まだ読める」に見える。真の結末で空白が埋まる仕掛けはそのまま生きる。
4. **夜の戸に歯を付ける。** 答えると、その声の主の思念が書庫の一覧から消える（喰われる）。小さな戦闘は要らない。一度でも失ったプレイヤーだけが、結末の「答えた」の重さを知る。「呼んでやろうか」は選択肢を外し、声だけで一回通す（手だけの選択は夜の戸の一つで足りる）。
5. **主題を口で言う行を三つ消す。** 主人公「……戸には、答えなかったのか」、門叩き「それでは、もう、同胞ではない」、ゼリナの「名前、あったんやな」の前半。司祭の四行と落ちた彫り刀と「ルカ」だけで、場面はもう泣けている。
6. **二文字の空白を十一か所同じにしない。** 空白は六か所まで。残りは「墓守」と役目で呼ぶ人を混ぜ、呼ばれ方の違いそのものを読ませる。F01 の直後に一度だけ、字の読めないシャノに「そこ、何て書いてあんの」と聞かせて、穴が誤植でないことを一言で担保する。

### ほかの案から移植すべき要素（まとめ）
- **B から**：「引く」「まだ」／伏せた椀（始まりに一つ、終わりに十四）／結末の食卓の場面をそのまま結末一の本体に（A の七つの一行は、その場面の台本の見出しとして使う）／仲間に足音を付けない／ベルトラン→ピピネルとトゥーラ→シャノの二組。
- **C から**：三十一の網と「もう一度、引く／手を離す」／鳴らした地域の敵が東を向いて止まる（ただし「止まった者が頂の群れになる」を一度見せる）／ブルーノ・ディル・ゼリナ・ノラの退場の一行／結末の夜の戸（7.3）は、夜の部分（三度の音・食卓が黙る・アデルの「数えたら、閉めるの」・開ける／開けない・「紐は、新しい」）をそのまま取る。朝は A の「ルカ！　爺ちゃんが、飯だって！」「答えた」で終え、C の「三十一」は真の結末の朝にだけ置く（夜に戸を開けた上で、朝に名を呼ばれて答える、で習いの裏返しが一度に済む。両方の朝をやると二重になる）。
- **C から取らないもの**：四行の銘とミルレーネの三つ目の節。裏返しを入れるなら、銘は「鳴る音に、その日の者を乗せよ」の一行（既に写しにある）だけにし、残りは三十回の手で分からせる。
- **B から取らないもの**：イスメネが二百年前の記録院にいたこと。頂の三十で画面を砦に切り替えること。

### 作家全員へ
- 冒頭 10 分は三案とも同じ骨組みで、主人公の台詞は一行、生きた声はシャノだけ。これは決まりどおりだが、**冒頭に緊張が無い**。炉に火を入れる前に、夜の戸を一度だけ叩かせる（音だけ。文は無し）。C の触れ書きとシャノの「戸ぇ開けんなよ」で受ける。三案のどれを選んでも、ここは直す。
- 「……」は三案とも決まりの内にあるが、A の 7.1 でシャノが「……ま、いいや」「……まあいいや」と二度同じ間を取っている。一つにする。
- 「見てた？」はシャノの癖として三案が使い、結末でも使う。効くのは最後の一回だけなので、道中は三回までに抑える。
