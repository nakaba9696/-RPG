# 案 A「名前」— 原作の骨子（N1 #198）

主人公の喪失と回復を軸にした案。世界に何が起きたかの謎（勢力ごとの言い分の食い違い、決め手は最後まで分からない）はそのまま残し、その真ん中を歩く一人の**内側**で物語を立てる。
骨格（墓守・四つの鐘・門叩き・黒鉄の砦・今ある地域とマップ・仲間 7 人・生き残り 7 人・ボス・頼みごと）は動かさない。動かすのは「墓守が何を預け、誰に何を忘れさせ、名前を取り戻すことが何を意味するか」の中身と、それを運ぶ文と仕掛け。

---

## 1. ログラインとテーマ

**ログライン**
記憶も名前も無く、死んだ人の声だけが聞こえる墓守が、四つの鐘を鳴らしに終わった世界を歩く。
歩くほど分かる。名前は自分で持つものではなく、呼ぶ人がいるあいだだけ持てるものだと。

**テーマ（最後にプレイヤーの胸に残す一つのこと）**
「夜に名を呼ばれても、答えるな」と誰もが言う世界で、それでも人は、誰かに名を呼ばれて初めて一人の人になる。
主人公は二百年前、自分を呼んでくれた声を一つずつ手放して眠った。物語の終わりに、見知らぬ死者たちと今を生きる人たちが、新しい口でその名を呼ぶ。失ったものは戻らない。呼ばれる日は、また来る。

**この案が「名前」で語れる理由（世界の側にもう根がある）**
- この世界で名前は**危ないもの**だ。門叩きは夜、身内の声で名を呼び、答えた戸から入る。集落の習い「夜の戸に答えない」は、名を呼ばれても答えない習いでもある。
- 名前は、勢力の文書の中で**欠けていく**。帝国の名無し兵は古言の代に名を払った。研究所の檻では名が番号になった。記録院の写字生は署名しない。生贄の帳面は名の列で、逃げた娘の行は「印、無し」。酒保のつけ帳の墓守の欄だけ名が無い。地域を回るほど、プレイヤーは「名が消される場所」を順に見ていく。
- 主人公は、名を持たない者（使徒）として生まれ、人に名を付けられ、人に呼ばれて墓守になった。名を取り戻すことは過去を取り戻すことではない。**もう一度、呼ばれる者になること**だ。それは危険を引き受けることでもある。

## 2. 主人公の弧

### 2.1 何を失っているか
| 失ったもの | この案での意味 | どこにあるか |
|---|---|---|
| 記憶 | 砦の人たちと暮らした二百年ぶんの場面。どの場面も「誰かが墓守を呼んでいる場面」 | 各地の会話できない薄い思念（F01〜F11）。見ると一つ戻る。**戻った場面の文は、名前の所だけ二文字ぶん空いている** |
| 名前 | 最後に自分を呼んでいた人の、最後の声 | 相棒の司祭の薄い思念。門叩きに喰われて抱えられている |
| 届け先 | 二度目の夜に聞いた、数百人ぶんの言い残しの**相手の名** | 墓守の帳面の五冊目（022）。最後の十数頁は、言い残しの欄だけ埋まり、名の欄が空白 |

主人公が二度目の夜にしたこと（〔進：3 つ目の鐘〕。誰も説明しない。主人公自身の記憶で見る）：
- 墓守は、死にゆく人の**言い残し**を聞き、取り込む使徒だ。取り込むと、その人は言い残したことを**忘れて**軽くなる（これが「誰に何を忘れさせ」）。墓守は重くなる。届けると、その重さは墓守から出ていく。これが墓所の番の仕事だった。帳面の四つの欄（名・言い残し・届けた日・届けた相手）はその記録。
- 二度目の夜、死にゆく人が一度に運びこまれた。取り込んだ思いは数百。喰えば楽になる、と体が知っている。喰えば思いは消え、使徒は強くなる。
- 喰わないために、墓守は**一人に一つずつ、自分の記憶を渡した**。外門の番には一緒に数えた夜を、帳場の娘にはつけの帳面の夜を。渡すたび、喰いたいと言う自分が薄くなる。渡すたび、**その人が自分を呼んだ声も一緒に出ていく**。だから五冊目の帳面は、言い残しだけが並んで名が無い。書いている途中で、その人の名を忘れたから。
- 最後に残った相棒の司祭には、取りもせず、渡しもしなかった。司祭だけが、墓守の名を丸ごと持って夜を迎えた。

### 2.2 何を知るか（順に）
1. 自分には名が無い（名の壁。名前の欄が「墓守」）。
2. 自分は呼ばれていた（薄い思念の空白。「　　、今夜は冷えるぞ」）。
3. 名が消される場所がいくつもある（各地域。名無し兵・檻の番号・印の無い帳面・空白のつけ）。
4. 喰わないために、呼ぶ声ごと渡した（3 つ目の鐘。五冊目の帳面の空白の意味がここで分かる）。
5. 名はまだ誰かの口の中にある。その口は門叩きだ（最後の地域の入口）。
6. ルカ。戸ではなく眠っている方へ向けて言われた名（塊の間）。
7. 集めてきたのは鐘ではなく名前だった（頂の耐える戦い。読んだ名の数だけ、思いが音に乗って去る）。
8. 呼ばれたら、答える（結末の最後の一行）。

### 2.3 何を選ぶか
- **縄張りの入口**：門叩きが「呼んでやろうか」と言う。聞く／聞かない。どちらでも門叩きは名を言えない（声は喰えても、名は喰えなかった）。選びは結果ではなく**プレイヤーの手**に残る。
- **塊の間**：使徒の力を初めて自分の意志で使う。呑まれが溜まると、仲間が旅の呼び方で呼び戻す（「あなた」「あんた」「兄貴」）。名は無くても呼ぶ口はある、をプレイヤーが戦闘で体で知る。
- **頂**：喰わない。数百の言い残しを、名を呼んで一つずつ音に乗せる。読んでいない名はそのまま残り、呑まれになる。
- **結末**：名前を持って山を下り、砦に戻る。真の結末では、墓所の壁の書き付けの下に自分の手で「ルカ」を彫る（宛名）。

### 2.4 プレイヤーが主人公と同じ瞬間に同じことに気づく設計
| 気づき | 主人公の側 | プレイヤーの側（ゲームならではの一致） |
|---|---|---|
| 名が無い | 名の壁の墓守の欄 | メニュー・セーブ・戦闘の名前の欄が「墓守」。役目の名で呼ばれ続ける |
| 呼ばれていた | 薄い思念の場面 | 文の中の二文字の空白。プレイヤーは穴の周りを読む。誰も「空いている」と言わない |
| 渡した | 3 つ目の鐘の場面 | 序盤に読める五冊目の帳面（名の欄が空白）の意味が、ここで裏返る。読み返しに行ける |
| 名はまだ誰かの口に | 門叩きの声 | 選択肢「聞く」を押す手。押しても音は来ない |
| ルカ | 司祭の最後の一語 | その瞬間に名前の欄が「ルカ」に変わる。音は止める。次に開くメニューで初めて見る |
| 集めていたのは名前 | 頂の群れ | 読んだ薄い思念・帳面・名簿の数が、そのまま耐える戦いの「弾」になる |
| 答える | 砦の中庭 | 最後の一行「答えた」で終わる。夜の戸の習いを、昼に裏返す |

## 3. 人物

書き方：望み／傷／プレイヤーとの関係が変わる瞬間。仲間は墓守を知らない見知らぬ死者のまま。誰も正体を指ささない。口調は world.md 11 章のまま。

### 3.1 仲間 7 人
**ブルーノ**（鐘の騎士団の最後の一人）
- 望み：隊の鐘を、誰かに巻いてほしい。
- 傷：隊が一人ずつ倒れるたび鐘を布で巻いた。自分の鐘を巻く者が残らなかった。
- 変わる瞬間：加わった夜、「あなた、お名前は」と聞く。名前の欄を見て「墓守」としか返らない。「それは役目でしょう。……では、あなた、で」。以後ずっと「あなた」。頂の最後のターン、初めて「ルカさん、で、合ってますか」。結末、届け先のアデルが礼拝堂の床の鐘を拾って布を巻く（アデルには見えない。「先輩として、やっとく」）。

**ノラ**（生贄の村の娘）
- 望み：妹の名を、自分の口で言いたい。
- 傷：くじの夜に窓から逃げた。帳面の自分の行は「印、無し」。その下の行が妹。
- 変わる瞬間：祠の番の前で、プレイヤーが帳面の最後の名（妹）を読み上げる。番が止まる。そのあとノラが一度だけ、同じ名を言う。短く、「！」が付かない。以後、妹の話になると急に短くなる癖はそのまま。

**ディル**（記録院の写字生）
- 望み：写しの続きを誰かに読ませたい。
- 傷：教会に渡す写しを二通り写し、どちらを上に置いたか確かめないことにした。写字生は署名しない。どの頁にも自分の名が無い。
- 変わる瞬間：イスメネの読み比べで、イスメネが写しの手を見て「この手の写字生の名を、記録していません。知りません。まだ」と言う。ディルは皮肉で流す。結末、イスメネが書庫の帳面に「写字生、ディル」と書く（手で分かった、とは言わない）。

**ゼリナ**（方舟を出した砦の酒保）
- 望み：舟に乗せた十四人が着いたかを知りたい。つけを回収したい。
- 傷：大人を降ろして子どもを乗せた。降ろした顔を全部覚えている。
- 変わる瞬間：砦の食堂の古い勘定台（F04）で、墓守のつけの欄が空白のまま二百年開いていると気づく。「名前の無い客は、取りっぱぐれるんや」。名が戻ったあと、縄張りの出口で「つけ帳、書き直さなあかん」。結末、墓守が勘定台に鉄くずを三つ置く。

**アンセルモ**（扉の外に残された司祭）
- 望み：扉の内の王に、言いたかったことを言う。外に残された者の名を、一人も落とさず歌う。
- 傷：内に入る札を子どもに渡した。残された民の弔いの歌を、歌の途中で止めた。
- 変わる瞬間：加わってすぐ、「お前さんの名も、いずれ名簿に入れてやる。……無いのか。じゃ、一行空けとく」。墓守と同じ仕事（名を持って歩く）を人の身でしていた男。頂の耐える戦いで、彼の名簿の名が一つ浮かぶたび、歌の続きを一節ずつ歌う。

**ベルトラン**（使徒狩りの傭兵）
- 望み：骨の剣を、売らずに終わりたい。
- 傷：強くなるほど手が自分のものでなくなった。柄に刻んだ持ち主の名は、上から線で消されていく。最後に狩った連れは子どもの姿だった。
- 変わる瞬間：塊の間で主人公が使徒の力を使ったとき、「それ、俺の剣と同じ匂いがする。使うなとは言わねえ。手が自分のものでなくなる前に、止めろ」。骨の剣を抜くと口数が減る癖のまま。

**トゥーラ**（研究所の被験者の子）
- 望み：弟妹に「帰る」の約束を守る。
- 傷：檻では名が番号だった。番号で呼ばれるのが嫌で、年上を全部「兄貴」「姉貴」と呼ぶようになった。
- 変わる瞬間：加わった最初の一言「兄貴、誰だよ」。名前の欄を見て「名前がねえなら、あたしが付ける。兄貴」。塊の間で名が戻ったあと、「兄貴は、兄貴でいいよな」。頂で「ルカ兄貴！」と両方で呼ぶ。

### 3.3 今の勢力の人（物語に効く人だけ）
- **名無し**（帝国の古言使い）：主人公の**裏側の鏡**。人として生まれ、力のために名を払った。墓守は名の無い者として生まれ、人に名をもらった。名無しは「墓守の力で、払ったものを取り戻したい」と迫る。三つ目の道（グィドの手紙のイルゼを渡す）は、この案の主題そのもの：**自分の名は取り戻せないが、人から名をもらうことはできる**。名無しは名乗るのをやめて静かに座る。
- **門叩き**（使徒）：主人公を「同胞」と呼ぶ。同胞とは、名の無い者どうしの呼び方。司祭を喰い、声を持っている。名は持っていない。「呼ばれてしまったか。それでは、もう同胞ではない」と言って退く。
- **ルシアン・ソレンヌ**（夕べの会）：既存のまま。頂で彫り直しを始める。この案では、ルシアンが親鐘の新しい銘に**自分の名を彫る**つもりでいた（指図書の余白に名の下書き）。止められると「名は、要りませんね」と一言で引く。
- **ゲンサイ・ルッツ**：既存のまま。ルッツは姉に名を呼ばれると声が大きくなる。帳面を見せる道は、家の名の列を見せる道。
- **マルゴ・骨拾い**：既存のまま。骨拾いは主人公に頭を深く下げ、「生きておられる方。……いえ」。数を正確に言う使徒は、名を一度も言わない。

## 4. 地域ごとの一話

書き方：その地域だけで読んでも心に残る短編としての筋。「滅びの前の夜」と「今」、どこで泣かせ、どこで驚かせるか、名前の糸、薄い思念。地域二〜五は好きな順なので、どの順でも成り立つ重さに揃える。

### 4.1 地域一「巻かれなかった鐘」（霧の森・鉄の坑道・営倉。必ず最初）
**滅びの前の夜**：鐘の騎士団の最後の行軍。隊長は「戻るに及ばず」の命令書を読み上げなかった。隊は境で一人ずつ倒れ、倒れるたびに次の者がその鐘を布で巻いた。最後に残った大男の末っ子は、礼拝堂の屋根を見ながら膝を折った。鐘はまだ鳴っていた。
同じ夜、砦の営倉で、捕らえた灰の信徒の一人が戸を叩く声に答えた。声は身内の声で、その人の名を呼んだ。九番の房の錠には傷が無い。鍵は廊下の側から回された。牢番は二百年、「誰も出すな」と見張っている。削った名を帳面から削った手は、自分の手だ。
**今**：炉に火が入り、シャノが柱の陰から出る。霧の奥で炊き出しの爺さんが三日迷っている。坑道で見習い騎士が全員を後輩と呼ぶ。
**泣かせる所**：ブルーノの臨終（既存の 5 行のまま）。「隊長。最後の一つ、巻いてくれる人がいません」。
**驚かせる所**：九番の房。外から破られたのではなく、内の錠に傷が無い。鍵束は十二本、輪には十三本の跡。
**名前の糸**：名の壁（墓守の欄だけ削られては彫り直されている）。薄い思念の空白が初めて出る（F01「　　、今夜は冷えるぞ」）。墓守の帳面の五冊目（022）：最後の十数頁は言い残しだけで名が無い。この時点では「古い帳面の書き損じ」にしか見えない。ブルーノが「お名前は」と聞く。
**薄い思念**：F01 墓所の番、F02 門番（一緒に数える）、F03 坑夫の頭、F04 帳場の娘（つけ）、F05 教官（「　　、お前、俺が新兵のころからその顔だな」）、F07 小間使いの子（背比べ。刻みの横に二文字の空白）。

### 4.2 地域二「印、無し」（焼けた村・記録院。森の療養小屋）
**滅びの前の夜**：生贄の村。くじは収めの月。選ばれた娘は、くじの夜に窓から逃げた。帳面のその行は「印、無し」。翌月、同じ家の下の娘が同じ月に選ばれた。逃げた娘は街道の噂でそれを聞き、村へは戻らず、村の見張り台で火を上げた。村に戻る道を照らすつもりだった。足は山の方を向いていた。
記録院では、真名を知れば使徒を縛れると信じた学者が、読んだ名を口から出せなくなった。写字生は教会に渡す写しを二通り写し、どちらを上に置いたか確かめなかった。写字生は署名しない。
**今**：灰の信徒の集落で、鍛冶屋の弟が司祭の隣にいる。姉は弟の名を大声で呼ぶ。記録院で、二百年一人の書庫番が「記録します」と言う。
**泣かせる所**：祠の番の前。プレイヤーが帳面の最後の名を読み上げる（ボスの弱み）。番が止まる。ノラが一度だけ同じ名を言う。「！」が付かない、彼女の唯一の行。
**驚かせる所**：学者の手記の次の頁。同じ一語で埋まっている。読もうとすると目が滑る。名は読む者を縛り返す。
**名前の糸**：「印、無し」の帳面。署名の無い写し。「知りません。まだ」。ルッツに帳面を見せると、家の名の列の中に自分の名を見つけて戻る。
**薄い思念**：F06 伝令の子（駆けっこ。「　　の負けー！」）。

### 4.3 地域五「一握り」（麦の街道と関所・鐘守の修道院。記録院の道の途中）
**滅びの前の夜**：飢えの年、西から押し寄せた民を王国の関所が止め、麦を一握りずつ取り立てた。札は家ごとに一枚。札を作ったあとに生まれた子の名は、どこにも書かれていない。列に並んだ女は、一握りを余分に納めて、子の名を役人の帳面に書かせた。飢えた家の名が残ったのは、取り立てる側の帳面だけだった。
修道院では「西の飢えを救うため、鐘の境を東へ広げる」が決まった。反対した修道士が一人。議事録の反対の欄の名は線で消してある。消したのは本人。消さなければ、下の者が納骨堂の当番にされた。石工の頭は「一晩のみ」と言われ、木は三晩分と書いた。誰にも言わなかった。
**今**：夕べの会の本拠。麦の村で騎士ソレンヌが詰め、修道院で写本係テオが写しを続ける。「読み比べは、好きです」。
**泣かせる所**：列に並んだ女の思念（110。4 行）。
```
札は家に一枚。この子は、札のあとに生まれた。
一握り、余分に納めた。この子の名を書いてもらうために。
役人は書いた。読み上げもした。
名を呼ばれて、この子が笑った。初めてだ。
```
ボスのあと、収税吏の帳面が手に入る。「一握りは王のもの」の下に、飢えた家の名の列。嫌な帳面だが、この地域で名を読める唯一の物。頂で、この帳面の名が浮かぶと去る（6 章の 4）。プレイヤーは頂で初めて、嫌な帳面を読んでおいてよかったと知る。
**驚かせる所**：反対した修道士の思念の最後の行。「名を消したのは、わたしの手。翌日の当番は、わたし」。名を消すことが誰かを守ることでもあった、と修道士は言わない。当番の札が語る。
**名前の糸**：取り立ての帳面だけに残る名。消された反対の名。嘆願書の村の判のうち一つが麦の村の判と同じ。鐘の無い地域なので、鐘の話は像の口と空の鐘架の二つだけ（既存の決まりのまま）。
**薄い思念**：F10 荷車の御者（麦の袋を枕に寝ている墓守を揺らす。「　　、着いたぞ。……起きんな」）。

### 4.4 地域三「十四」（霧の湖・地下水道と地下都市）
**滅びの前の夜**：砦の酒保の女が貯めた金で舟を一艘買った。舟は一艘しか無く、二艘目の木は届かなかった。誰を乗せるかで揉め、大人を降ろして子どもを十四人乗せた。女は桟橋で、灯が見えなくなるまで数を数えた。
砦の真下、王国は民を地下都市へ送り、日没に扉を閉めた。札は千枚、並んだのは千と四百。札を持っていた司祭は、札を外の子どもに渡して外に残り、残された民の名を一人ずつ歌った。歌の途中で止まった。
**今**：湖の家でエルフの女が二百年、灯を灯している。扉の内の村の長は外の話をしない。
**泣かせる所**：「扉の外の歌」（W9 の頼みごとのまま）。弔いの名簿を長に見せる。長は村の習いで外の話をしないはずが、名簿の中の一つの名を声に出して読む。自分の家の名だ。閂を外す。名簿の最後は一行空いている。アンセルモが砦で「一行空けとく」と言ったのは、この行のこと。
**驚かせる所**：酒保のつけ帳。墓守の欄だけ名が空白で、つけは二百年分で銀三枚。ゼリナ「名前の無い客は、取りっぱぐれるんや」。
**名前の糸**：名簿（人の身で名を持って歩いた司祭）。空白のつけ。麦の村の帳面「舟で着いた。十四」と並べると、十四のうち一つが線で消してある。
**薄い思念**：F09 井戸番の女（桶が上がるまで三十を数える。「　　、三十一は無いよ」）。

### 4.5 地域四「宛名」（境山の古道・古い鋳物場と帝国の研究所）
**滅びの前の夜**：帝国の古言兵は、古言を使うたびに影・声・名を払った。恋人へ手紙を書こうとして宛名を思い出せなかった兵がいる。封は切られていない。研究所では骨拾いから買った骨を人に移した。檻の札は名の代わりに番号。坑夫の家の長女は「食べ物が出る仕事」と言われて来て、檻の小さい子らの世話を焼き、骨を移されて檻を曲げ、運びこまれていた親鐘の舌を背負子に載せた。「かえりは かるい」。
**今**：名無し兵の最後の一人が、墓守の力で払ったものを取り戻したいと迫る。烽火台の爺さんの家に、宛名の無い手紙がある。差出人はイルゼ。骨拾いは頭を深く下げる。
**泣かせる所**：名無しの三つ目の道。研究所の奥で「力をよこせ」と迫る名無しに、グィドの手紙のイルゼの名を渡す。名無しは名乗るのをやめて座る。自分の名は戻らない。人から名をもらうことはできる。この場面は終盤の主人公の予告になる（プレイヤーはまだそうと知らない）。
**驚かせる所**：観察記録の何十行目か。前後の行は被験者の番号。そこに「黒鉄の砦の墓守。年を取らない。要観察」。
**名前の糸**：番号で呼ばれた子。宛名の無い手紙。名を払った兵。トゥーラの「兄貴」。
**薄い思念**：F08 東門の番（閂を二人で持ち上げる。「せーの、　　、上げろ」）。

### 4.6 最後の地域「呼んでやろうか」（門叩きの縄張り 170–173。3 つ目の鐘のあと）
3 つ目の鐘のあと、鳴っていない最後の地域の色調が暗くなり、声だけの影が増える。その地域の今の勢力の人が一言（既存の a のまま）。鐘の間の口が霧でふさがれ、戸口が開く。
**縄張りの縁（170）**：門叩きが、その地域の死者の声を次々に替えて話す。最後に相棒の司祭の声になる。
```
同胞よ。お前の名を知っていた者を、あの夜、わたしは喰った。
お前の名は今、わたしの中にしかない。
呼んでやろうか。
```
選択肢「聞く」「聞かない」。聞くと、声が司祭の声になり、口が名の形に開く。音は来ない。「……声は喰えても、名は、喰えなかったか」。聞かないと「賢いな。あの夜も、誰も答えなかった。一人を除いて」。
**喰われた者の廊下（171）**：塊から、その地域で読んだ思念の一行が漏れる（既存の c のまま）。彫り刀の音が近づく。
**塊の間（172）**：ボス。主人公が初めて使徒の力を使う。呑まれが溜まると仲間が旅の呼び方で呼び戻す。崩すと司祭の薄い思念。**戸ではなく、眠っている方へ向けて言われた名**（本文は 7.2）。名前の欄が「ルカ」になる。門叩きの声は遠のく。「呼ばれてしまったか。それでは、もう同胞ではない」。
**戻りの戸口（173）**：鐘の間へ戻り、4 つ目を鳴らす。

### 4.7 終盤「三十」（境山の高み 180–183・頂 015）
**滅びの前の夜**：彫り直しの隊が宿坊に泊まった最後の夜。宿帳の最後の頁は一晩分。氷室の橇は舌を運ぶはずだった。石工は余った木で下りる段を組み、頭は下りてこなかった。砦の鐘守の交代の欄に、墓守の名の所だけ印。
**今**：灰の斜面でソレンヌの先発隊が足場の木を担いでいる（頼みごとの結果で変わる）。頂でルシアンが待っている。「鳴らしてくれて、ありがとう。あとは、私が彫ります」。
**泣かせる所**：F11 砦の鐘守（囲炉裏で鐘を数える指の形を一緒にする。「三十で止めろ。　　、お前はいつも三十一までいく」）。墓守の指が三十一まで動く理由は誰も言わない。頂でプレイヤーが三十回押して、三十一回目を押すかどうか。
**驚かせる所**：ルシアンの指図書の余白に、親鐘の新しい銘に彫るつもりだった名の下書き。自分の名。止めると「名は、要りませんね」。
**頂**：5 章。

## 5. 三つの山

### 5.1 一つ目の山：3 つ目の鐘のあと（084・094・104 のどれか）
鐘を鳴らしたあと、鐘番の思念の二ページ目で、主人公自身の記憶が戻る。画面を暗くし、文章だけ。地の文の主語は「自分」。
```
鐘が黙った。墓所の戸が、外から三度叩かれている。
戸の向こうで、誰かが誰かの名を呼んでいる。身内の声で。
運びこまれてくる。外門の番。帳場の娘。教官。まだ息がある。
一人ずつ、耳を寄せる。言い残しを聞く。
```
```
聞いた分だけ、その人の顔から力が抜ける。軽くなった顔だ。
代わりに自分のものを一つ渡す。一緒に数えた夜を。つけの帳面の夜を。
渡すたび、喰いたいと言う自分が薄くなる。
渡すたび、自分を呼んだ声が、一つ減る。
```
```
帳面に言い残しを書く。名の欄で、手が止まる。
相棒が壁に向かって彫りはじめた。刃の音が、戸を叩く音に混ざる。
最後の一人に渡し終えた。もう、誰にも呼ばれない。
目を閉じた。
```
主人公の一言：「……呼ぶ声ごと、渡したのか」
- 仲間は何も変わらない（墓守を知らない）。砦に戻ると、食堂でゼリナが「舟の金、まだ足りへん夢を見た」と言う。それだけ。

### 5.2 二つ目の山：最後の地域の塊の間（172）
4.6 のとおり。山場の核は三つ。
1. **使徒の力**を初めて自分で使う。強いが呑まれが溜まる。仲間が「あなた」「あんた」「兄貴」で呼び戻す。名が無くても呼ぶ口はある、を戦闘で体で知る。ベルトラン「手が自分のものでなくなる前に、止めろ」。
2. **司祭の最後の記憶**（7.2 に本文）。戸の向こうの声は、墓守の声で司祭の名を呼んでいた。司祭は戸を見ず、眠っている方へ向き直って、名を言った。夜の戸の習いを、司祭は名を呼び返すことで守った。
3. **名前の欄が変わる**。音を止める。仲間の反応は一行ずつ。トゥーラ「兄貴は、兄貴でいいよな」。ゼリナ「つけ帳、書き直さなあかん」。ブルーノは何も言わない（頂まで取っておく）。

### 5.3 三つ目の山：頂（015）
1. 親鐘に舌を吊る。境山じゅうから、二度目の夜に死んだ人たちの残りの思いが集まる。**この案では、群れの大半は、主人公が二百年抱えたままだった言い残し**だ（頂で初めて主人公の外へ出る）。
2. **耐える戦い**「夜の思い」。倒す戦いではない。ターンごとに、名の無い言い残しが一つ浮かぶ（五冊目の帳面の一行）。プレイヤーがその人の名をどこかで読んでいれば（薄い思念・帳面の前の頁・残留思念・アンセルモの名簿・ヴォルフラムの家の帳面）、仲間の誰かがその名を呼び、言い残しは音に乗って去る。読んでいなければ、言い残しは残り、呑まれが一つ溜まる。アンセルモは名簿の名が浮かぶたび、止まっていた歌の続きを一節ずつ歌う。
3. 最後のターン、仲間が、縄張りで聞いた名で初めて主人公を呼ぶ。「……ルカさん、で、合ってますか」「ルカ兄貴！　戻ってこい！」（既存のまま）。
4. 主人公は喰わない。綱を引く。**三十回、プレイヤーが決定を押す。** 一打ごとに思いが一つ去る。三十で止める。もう一度押しても何も起きない（真の結末では、三十一回目に遠い山から知らない鐘が一つ応える）。
5. ルシアンは彫らない。「名は、要りませんね」。ソレンヌの生死は頼みごとの結果（既存のまま）。

### 5.4 結末
**結末 一「夕べの数」**（親鐘を鳴らす）
- 四つの鐘が応え、灰が止む。仲間は一人ずつ、届けたい人のもとへ行き、届けて去る。生き残りには見えない。その人が何かに気づく一行で書く。
  - ブルーノ → アデル：礼拝堂の床の鐘を拾い、布を巻く。「先輩として、やっとく」。
  - ノラ → アンネリーゼ：金槌を止め、家の名の列に一つ足す。
  - ディル → イスメネ：書庫の帳面に「写字生、ディル」。
  - ゼリナ → ヴォルフラム：皿を十四並べて腹から笑う。一つ余る。
  - アンセルモ → 扉の内の村の長：扉の外で、歌を一節。
  - ベルトラン → マルゴ：骨の剣の値を付けない。「売り物じゃない」。
  - トゥーラ → 名無し：名無しが書き付けに「かえった」と書く。イルゼと名乗らず、書き付けに名も無い。
- 主人公は名前を持って山を下り、砦の墓守に戻る。食堂の勘定台に鉄くずを三つ置く。シャノ「それ、何の金？」。名の壁の一番下の段を、シャノに読んでやる。
- 最後の場面。朝の砦の炉。中庭で子ども（麦の村から来たヴォルフラムの孫）が三十まで数える。
  ```
  「ルカ！　爺ちゃんが、飯だって！」
  答えた。
  ```
  昼に名を呼ばれたら答える。夜の戸の習いを、最後の一行で裏返して終える。

**結末 真「遠い鐘」**（条件は〔秘〕。仲間 7 人完全体＋生き残り 7 人＋ミルレーネ。この案での意味：**名を呼ぶ口が十五ある**）

- 砦に戻り、墓所の壁の書き付けの下、止まっていた一画の続きを主人公が自分の手で彫る。「ルカ」。書き付けは宛名のある手紙になる。
- 以後、薄い思念をもう一度見に行くと、空白だった二文字が全部埋まって読める（「ルカ、今夜は冷えるぞ」）。名は、ずっと呼ばれていた。
- 決め手は誰にも分からないまま。誰も責めない（既存のまま）。

## 6. 見せ方の核（文章以外で心を動かす仕掛け、5 つ）

1. **名前の欄**：メニュー・セーブ・戦闘・文章の名前が「墓守」。塊の間で「ルカ」に変わる瞬間、音を止める。プレイヤーは次にメニューを開いたとき、自分の目でそれを見る。誰もそれを口で言わない。
2. **二文字の空白**：薄い思念の場面の中で、墓守の名が呼ばれる所だけ全角二文字ぶん空いている。説明しない。プレイヤーは穴の周りを読む。真の結末のあと、全部の空白が埋まる（もう一度見に行く理由ができる）。
3. **夜の戸**：各地域に一つ、夜（色調が暗い所）で戸を三度叩く音と「墓守さま、入れておくれ」の声が出る小さなイベント。声は、その地域で読んだ死者の声。選択肢「答える」「答えない」。答えると声だけの影が出る（小さな戦闘。何も失わない）。習いをプレイヤーの手で覚えさせ、縄張りの「呼んでやろうか」と結末の「答えた」の両方の伏線にする。
4. **名を集めることが、最後の戦いの弾になる**：頂の耐える戦いは、プレイヤーが読んだ名の数だけ楽になる。薄い思念・帳面・名簿・家の帳面・残留思念の「名のある文」を読んだ記録が、そのまま群れの一つ一つを去らせる。探索が、そのまま弔いになる。読み落とした分は呑まれになり、「読まなかった名がある」を体で知る。
5. **三十回押す**：親鐘の三十打は、プレイヤーが決定を三十回押す。自動で進めない。一打ごとに思いが一つ去り、画面が少し明るくなる。三十で手を止めるかどうかはプレイヤーに任せる。三十一回目は何も起きない（真の結末だけ、遠い鐘）。F11 の「お前はいつも三十一までいく」を、プレイヤーの指でなぞらせる。

ほかに小さく効く所：生き残りには仲間が見えない（食卓の席が空いて見える）。弱い化け物が一瞬ためらう（既存）。縄張りで門叩きの声が替わるたび、文章の窓の名前の欄がその死者の名になる（門叩き自身の名前の欄は空）。
