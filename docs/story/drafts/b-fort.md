# 案 B「砦の人々」— 原作の骨子（N1 #198）

群像が軸。仲間 7 人（死者）と生き残り 7 人（今の人）が、二百年を隔てて一つの食卓に座る。
土台は VISION.md・world.md・text.md・knowhow.md。骨格（墓守・四つの鐘・門叩き・黒鉄の砦・今あるマップ）は残し、人の過去と関係と結末を作り直した。変えた所は 8 章。

---

## 1. ログラインとテーマ

**ログライン**
記憶の無い墓守が、死者を連れて四つの鐘を鳴らしに行く。連れた死者はみな、生きている誰かに届けたい言葉を一つ持っている。砦の食卓には、墓守にしか見えない席が七つ、誰にも見える席が七つある。

**テーマ（最後に胸に残す一つのこと）**
人は、会ったことのない人からも何かを受け取って生きている。受け取った側は、受け取ったと分からない。それでも届く。
プレイヤーだけが食卓の両側を見る。だから、プレイヤーだけが「届いた」と分かる。

## 2. 主人公の弧

**失っているもの**：名前と記憶。それと、席。
墓守は何代にもわたって、死んだ人の言い残しを家族に届けてきた（言い習わし「墓守さまに言い残す」）。届ける側であって、受け取る側になったことがない。背比べの壁に自分の刻みを付けず（F07「墓守は、自分のぶんは刻まない。ずるい」）、酒保のつけ帳の自分の欄は名前が空白で（072）、名の壁の「墓守」の欄は名前が削られては彫り直されている（010）。大広間の長い食卓は十四席。いちばん奥に一つだけ、伏せた椀がある。誰の席かは、最初は分からない。

**知ること**（プレイヤーと同じ瞬間に）
1. 旅のあいだ、プレイヤーは死者を連れて歩き、生き残りの前に立たせる。生き残りには見えない。ところが生き残りの口から、連れている死者にしか意味の分からない一言が出る（シャノ「帰りは軽い、って頭が言うんだ」。トゥーラが背負子に彫った字）。**仲間が気づく瞬間と、プレイヤーが気づく瞬間が同じ**。主人公は何も言わない。言わなくても、プレイヤーは主人公と同じ所に立っている。これを七度くり返す。
2. **3 つ目の鐘のあと**。主人公自身の記憶の場面で、二度目の夜、死んでいく砦の人たちに自分の記憶を一つずつ渡していたと分かる。門番には一緒に数えた夜を、帳場の娘にはつけの帳面を、小間使いの子には壁の刻みを。プレイヤーがここまで集めてきた「会話できない薄い思念」は、全部その受け取りの場面だった。墓守がしていたことは、プレイヤーがこのゲームで十時間やってきたことと同じ。**死者の思いを、喰わずに、生きている人へ運ぶ。** 誰も説明しない。プレイヤーが自分の手の動きで分かる。
3. **最後の地域**。門叩きが抱えた塊の中に、相棒の司祭がいる。司祭は二百年前の最後の夜、墓所の壁に「四つの鐘を鳴らして。それから、山の頂の鐘楼へ」と彫りながら喰われた。司祭の思念は名前を返す。「ルカ」。食卓の伏せた椀の底の印と、壁の字が同じ手だったことを、プレイヤーはここで思い出す。伏せた椀は、司祭が毎晩、墓守のぶんを取っておいた椀だった。

**選ぶこと**
頂で親鐘に舌を吊ると、二度目の夜に死んだ人たちの思いがいっせいに集まる。喰えば楽になる、と体が知っている。喰えば、連れてきた七人もこの先ずっと隣にいる。食卓の七つの席は、墓守の目には埋まったままになる。
鳴らせば、七人は思いを届けて去る。食卓の七つの席は空く。空いた席に、生き残りが椀を置く。
主人公は鳴らす。綱の前の選択肢は「引く」と「まだ」。「まだ」を選ぶと仲間が一人ずつ一言話し、何度でも「まだ」を選べる。引くのはプレイヤーが決める。別れの時をプレイヤーの手に渡す。

**結末で得るもの**
名前。背比べの壁の、自分の刻み。十四の椀。
墓守は初めて、受け取る側になる。

### 3.2 相棒の司祭（会話できない。物語の要）
- 砦の司祭。墓守の相棒。毎晩、大広間の食卓のいちばん奥に墓守のぶんの椀を取っておき、墓守が来ないと伏せておいた。椀の底に小刀で印。
- 名の壁の「墓守」の欄を削っては彫り直した跡は、二人の二百年の言い合い。墓守が自分の名を削る（同じ名が何代も続くのを見られたくない）。司祭が彫り直す。「名前くらい、持っとけ」。〔噂〕のまま。誰も説明しない。壁と椀と彫り刀の革の巻き方で察する。
- 二度目の夜、墓所の壁に書き付けを彫りながら喰われた。最後の一画が止まっている。門叩きの塊の中にいる。解き放つと、名前を返して消える。残るのは刃の欠けた彫り刀。
- 結末で、墓守の背比べの刻みを付けるのに使われるのは、この彫り刀。

## 4. 地域ごとの一話

その地域だけで読んでも短編として立つ筋。「昔」は滅びの前の夜、「今」は二百年後。泣かせ所と驚かせ所を一つずつ。

### 地域一　砦の下（霧の森・鉄の坑道・営倉）—「巻いてくれる人」
- **昔**：鐘の騎士団の最後の行軍。隊が一人倒れるたび、ブルーノがその騎士の鐘を布で巻いた。最後に残った自分の鐘を巻く者はいなかった（記憶 4 は world.md の本文のまま）。坑道では籠が六人までで、門を閉めた坑夫の手。営倉では牢番が九番の房に毎晩飯を運び、顔を見なかった。その夜、九番の房は空いた。
- **今**：シャノは頭に営倉の鐘を外して来いと言われている。ヴォルフラムは霧で三日迷い、「飯を作る所がある」と聞いて砦に居つく。アデルは坑道で鉄を掘り、騎士の鐘を集めている。
- **泣かせ**：ブルーノが砦に来た最初の夜、食卓の末席（隊の末席の癖）に座る。向かいにアデルが座り、誰もいない空気に「いい？　鐘はね、巻くの」と講義する。ブルーノ「……その巻き方は、違います」。アデルには聞こえない。ブルーノは「すみません」と言って、黙って聞く。
- **驚き**：営倉の鐘を鳴らす前にマルゴが買い取りに来る。シャノは「見てた？」と言えなくなる。鳴らしてしまえば、鐘は売れない。鐘は持ち帰る物ではなく、鳴らす場所だと、ここで初めてプレイヤーが知る。

### 地域二　西の谷（焼けた村・記録院・森の療養小屋）—「印、無し」
- **昔**：くじの夜、ノラは窓から逃げ、見張り台で山の方へ火を上げた。村に帰る道を照らすつもりで。妹が代わりに選ばれた。だが祠の帳面の妹の名の横には「印、無し」。使徒は来なかった。記録院では、ディルが二通りの写しを写し、見習いのイスメネが写字台の灯を持っていた。森では、霧の中で羊飼いの群れに混ざった小さなエルフの子を、酒くさい傭兵が斬った。息があった。
- **今**：アンネリーゼの弟ルッツが灰の信徒に入った。アンネリーゼの家は灰ではなく火を拝む。イスメネは二百年書庫を守り、毎日一行書く。ピピネルは療養小屋で昼寝をし、袖の下の傷を人に見せない。
- **泣かせ**：記録院。ディルの記憶 4（書きかけの続きの頁）を持っていくと、イスメネが頁を見て「この手は、知っています」。隣に立つディルが「……言うなよ」。イスメネは帳面に書く。「本日、写しの続き、届く」。そして二つ目の書見台を、しまわない。
- **驚き**：帳面の「印、無し」。ノラは罪を抱えたまま二百年いた。妹は帰った。帳面一行で分かる。ノラは何も言わない。次に砦に戻ったとき、アンネリーゼが鉄を打ちながら家の話をする。「山の火を見て、誰かが帰ってきたんだと」。ノラ「……あたしの火だ」。この一行だけ。

### 地域五　麦の街道と鐘守の修道院 —「ゼリナ（舟代）」
- **昔**：飢えの年、関所で一握りを納めた列。修道院で「飢えを救うため、境を東へ」を決めた会議。反対した修道士。石工の頭は三晩分の木を運んだ（world.md 2.2・text.md 5.7 のまま）。湖を渡った十四の子どもが、着いた岸から歩いて麦の村に住みついた。
- **今**：夕べの会の本拠。テオの読み比べ、院長、足場の木（頼みごとは world.md のまま）。
- **泣かせ**：麦の村のヴォルフラムの家の帳面。最初の頁に「舟で着いた。十四」と十四の名。その下に、別の手で一つ「ゼリナ（舟代）」。ゼリナは帳面を見て勘定の声で十四を数え、十五番目で止まる。「……うちの名、勝手に書きなや」。それだけ。
- **驚き**：修道院の鐘架は空で、街道の祠の像の鐘の口は開いている。鐘の無い地域に鐘の話が二つだけ。誰も理由を言わない。

### 地域三　南の水（霧の湖・地下水道と地下都市）—「両側の歌」
- **昔**：ゼリナは桟橋で舟の灯が見えなくなるまで数えた。アンセルモは扉の外で、札を子に渡し、残された民の弔いの歌を歌い続け、途中で止まった。ミルレーネは灯を点した。
- **今**：ミルレーネの灯は一晩も欠けていない。扉の内の村の長は外の話をしない。
- **泣かせ**：閉じた扉の前。アンセルモの遺骸を調べたあと、扉の内側から子どもの声が文章の窓に出る。「ひとつ、戸の外。ふたつ、扉の前」。遊びの数え歌だ。アンセルモが外で歌い続けた弔いの歌の、数える所だけが残った。札を持って入った子が、中で教えた。アンセルモ「中でも数えとるんか。三つ目を抜いてな」。頼みごと「扉の外の歌」で名簿を長に見せると、長は閂を外す（W9 のまま）。
- **驚き**：この数え歌は、もう一か所にある。境山の烽火台で、グィドが夕べの山を数えている。「ひとつ、戸の外。ふたつ、扉の前」。山の数を、外に残された人の数え歌で数えている。扉の内と外と、血のつながらない灯守。音は要らない。字だけで分かる（音の無いゲームのままでも成立する）。

### 地域四　東の山（境山の古道・古い鋳物場と研究所）—「かえりは かるい」
- **昔**：名無し兵は名を払った。トゥーラは「食べ物が出る仕事」と言われて研究所へ行き、檻を曲げ、親鐘の舌を背負子に載せて「かえりは かるい」と彫った。ベルトランは骨拾いの洞の前で剣を杖に立ったまま死んだ。
- **今**：グィドの灯。骨拾いの取り引き。名無しの書き付け。
- **泣かせ**：トゥーラが砦に来た最初の夜。シャノが梁から下りて背負子を床に置く。「帰りは軽い、って頭が言うんだ。拾い屋はみんな言う。意味は知らねえ」。トゥーラ「……誰に教わった、それ」。シャノには聞こえない。シャノは飯を食わずに梁へ戻る。トゥーラ「兄貴。あいつ、飯食ってない」。ここから毎晩、トゥーラは聞こえない相手に小言を言う。

## 6. 見せ方の核（文章以外で心を動かす仕掛け）

1. **食卓の両側**。大広間の食卓は十四席。生き残りが来るたびに片側が埋まる（変数「生き残りの数」。今の仕組みのまま）。仲間を呼ぶたびに反対側が埋まる（仲間のスプライトを半透明で置く。生き残りのイベントは仲間の席を素通りして話す）。プレイヤーだけが十四人を見る。結末で仲間の席が空き、生き残りがそこに椀を置く。一つ目の椀は、始まりの伏せた椀。
2. **数える**。鐘を鳴らす操作は、毎回、綱を引いて三十を数える（画面に一から三十）。仲間がいれば数を分けて唱える（ブルーノは祈りの速さで、ノラは速く、アンセルモは節をつけて）。頂の三十は、砦の生き残りが数える。夕べの数は世界の祈りで、プレイヤーの操作でもある。
3. **呼び方の積み重ねから、名前へ**。戦闘のメッセージと掛け合いで、仲間は十数時間「あなた」「あんた」「兄貴」「お前さん」「お前」と呼ぶ。縄張りの呑まれの戻しも、その呼び方。頂の最後のターンで初めて「ルカ」。ゲームの一番長いくり返しを、一度だけ変える。
4. **手で刻む**。墓所の背比べの壁（F07）は旅のあいだ何度でも調べられ、子どもたちの刻みだけが並ぶ。結末でピピネルが主人公を壁に立たせ、司祭の彫り刀で一つ刻む。名の壁の墓守の欄は、真の結末で主人公が彫る。壁はセーブデータに残る。
5. **音と匂いの無さ**。仲間には足音の効果音を付けない。生き残りには付ける。仲間は食べられず、匂いも出ない。ピピネルだけが、ベルトランの席の前で鼻を動かす（エルフで、斬られて運ばれた側だから）。結末のあと、大広間に残る足音は生き残りのものだけ。「まだ」の選択肢（5.3）も、これに数える。プレイヤーが別れの時を決める。

七度くり返す「気づき」の形。一つだけ、ゲームで出す形で。
```
シャノ「見てた？　今日は留め金が五つ。重かった」
シャノ「帰りは軽い、って頭が言うんだ。拾い屋はみんな言う。意味は知らねえ」
```
```
トゥーラ「……誰に教わった、それ」
```
シャノは梁へ登る。飯を食っていない。
```
トゥーラ「兄貴。あいつ、飯食ってない」
```
```
「……背負子の字と、同じだ」
```
- 主人公の一言は事実だけ。トゥーラはこのあと、聞こえない相手に毎晩小言を言う。シャノは毎晩、梁の上で寝る。結末の夜まで。
