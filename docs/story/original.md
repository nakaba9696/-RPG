# 原作の骨子・決定版 —「最後の鐘」（N2、#209）

持ち主の決め（#198 の講評のあと）：**案 C「鐘の真実」を骨に、A「名前」と B「砦の人々」を混ぜる。**
骨は C の「三十と三十一」の網、鳴らした地域の敵が東を向いて止まること、頂で親鐘を三十引くこと、結末の夜の戸と段の鈴。A からは塊の間の司祭の場面と名前の欄、序盤からの夜の戸。B からは十四席の食卓と伏せた椀、綱の前の「まだ」、トゥーラとシャノ、朝の背比べの刻み。
講評から受けたこと：裏返しを説明する銘は一行だけにして、残りは三十回の手で分からせる。惨事を「誤解でした」にしない。裏返る断片は三つまで。血や直接の縁でつなぐ対は三組まで。地域ごとに主人公に事実の一言。頂のあとに歩ける時間を作る。「ルカ」は塊の間で一度だけ。頂の画面の切り替えは二度まで。冒頭 10 分に案の顔を三つ（戸を叩く音・伏せた椀・「戸ぇ開けんなよ」）。足音の仕組みと二文字の空白は作らない。読み逃しを罰にしない。
三つの案（`drafts/`）は残す。設定の正本は引き続き `world.md`。この骨子と食い違う所は、N3 の書き下ろしのあとに world.md を直す（8 章）。

## 1. ログラインとテーマ

**ログライン**
鐘の鳴る所に使徒は来ない。だから四つの鐘を鳴らして頂へ、と壁の字に教わって、記憶も名前も無い墓守は、死者を連れて歩き出す。
四つ目が鳴った頂で墓守は、自分の手で綱を三十回引く。一回ごとに、連れてきた誰かが行く。鐘が二百年のあいだ何を運んでいたのかを、墓守は数えて知る。

**テーマ（最後に胸に残す一つ）**
死んだ人は、ひとこと聞いてもらえたら行ける。鐘も、墓守も、夜に戸を叩く音も、そのためにあった。
この世界の人は二百年、夜の戸に答えなかった。プレイヤーは旅の途中で何度か答え、最後の夜に戸を開け、朝に名を呼ばれて答える。

**裏返しの中身（持ち主だけが読む要約。ゲームの中では誰も言わない）**
- 鐘は壁ではなく道。夕べに三十鳴らすと、その日に死んだ人の思いが音に乗って境山を越える。「鐘の鳴る所に使徒は入らない」は本当で、理由は「来なくていいから」。
- 鳴らない所の死者は、使徒が戸を叩いて迎えに来る。身内の声の「入れておくれ」は、死者の声そのもの。内から開けた所だけに入れるのは、取り決めの文言どおり。
- **裏返しても軽くならない所**：二百年前の夜、鐘が三十で止まり、使徒はいっせいに越えて来て、三つの国は終わった。門叩きは砦の人を喰い、相棒の司祭を喰った。使徒狩りは子どもの姿の連れを斬り、骨拾いは骨を塔に積んだ。迎えに来た者も、喰う者だった。「届ける」墓守と「喰う」門叩きのどちらが正しいかは、最後まで誰も言わない。
- 裏返る断片は三つだけ：ブルーノの巻かれなかった鐘、ノラの山へ向けた火、アンセルモの扉の外の歌。研究所・名無し・骨拾い・写し・飢えの列は、裏返さない。それぞれの地域の話として重いまま残す。

### 3.6 生き残り 7 人（砦に来る人）

## 4. 地域ごとの一話
その地域だけで読んでも心に残る短編の筋。「昔」は滅びの前の夜、「今」は二百年後。夜の戸の声は、その地域で読んだ死者のうち一人。「頂のあと」は三つの地域だけに書く。

### 4.0 砦（序）：伏せた椀
**今**：三度叩く音で目を覚ます。床の鈴が揺れている。棺の中の父親が「娘の婚礼の歌の続きを聞いといてくれ」。壁に字。大広間の食卓は十四席、いちばん奥に伏せた椀が一つ。炉に火を入れると猫の獣人の拾い屋が出てきて、鈴を蹴ったと謝り、「夜は戸ぇ開けんなよ」と言う。触れ書き「夜、戸を叩かれても開けぬこと」の下に別の手で「油、もう無い」。井戸の女の思念「門の方で、誰かが『入れておくれ』って」。門の内側に拳の凹みが三つ。
**泣かせ所**：まだ泣かせない。老人の薄い思念で主人公が「……覚えている。この人の葬式を出した」。
**驚き**：名の壁の「墓守」の欄だけ、削られては彫り直されて読めない。
**頂のあと**：鈴を蹴ったのはシャノではなかった。凹みは三度叩いた跡。椀の底の印と壁の字が同じ手。

### 4.1 地域一：巻かれた鐘（霧の森・鉄の坑道・営倉。必ず最初）
**昔**：鐘の騎士団の最後の行軍。隊長は「戻るに及ばず」を読み上げず「夕べには戻る」とだけ言った。一人倒れるたび、残った者がその鐘を布で巻いた。最後の一人の鐘は、誰にも巻かれなかった。営倉では捕らえた信徒の一人が、夜、門を開けた。九番の房の錠に傷は無い。
**今**：巡礼が「騎士さまの鐘を集めに。布で巻いたまま。鳴らしてはいけないそうです」と言いながら鋏を三本折っている。マルゴが営倉の鐘を買い取りに来る。鳴らしてしまえば売れない。牢番は二百年「誰も、出すな」。鐘番の思念「頂が鳴らないときは、こちらも三十で止める。三十一を数えかけて、やめた」。
**夜の戸**：霧の奥の木樵の小屋。女房の声「薪、三束。戸の脇に置いといたよ」。答えて倒すと、その一行が言い残しとして残る。
**泣かせ所**：礼拝堂の騎士の列の最後。「隊長。最後の一つ、巻いてくれる人がいません」。営倉の鐘のあと、ブルーノと並んで三十を数える。
**驚き**：営倉の鐘を鳴らして間を出ると、敵が追ってこない。全部が東を向いて止まっている。主人公「……東を向いている」。
**頂のあと**：騎士の鐘は、境で死んだとき音で行くためのもの。仲間が布で巻いたのは、行かせないため。巻かれなかったブルーノだけが行けた。礼拝堂の列は、二百年座っている。

### 4.2 地域二：印、無し（焼けた村・記録院・森の療養小屋）
**昔**：生贄の村はくじで一人を差し出した。逃げた娘の代わりに下の妹が出た。帳面の妹の行は「印、無し」。娘は見張り台で山の方へ火を上げた。記録院では学者が真名を読んで狂い、写字生が教会へ渡す写しを二通り写した。
**今**：村の跡に灰の信徒の集落。アンネリーゼの弟が司祭の隣にいる。アンネリーゼの家は夜の火を落とさない（「帰ってくるのがいる」「誰が」「知らねえ」）。書庫番イスメネが二百年「記録します」。読み比べのときディルは席を外し、イスメネは二つ目の書見台をしまわない。療養小屋のピピネルは袖の下を見せない。
**夜の戸**：焼けた村の入口の家（戸板の盾を外した家）。子どもの声「おかあ、戸、こたえていい？」。
**泣かせ所**：祠の番の前。帳面の最後の名を読み上げる。ノラが一度だけ同じ名を言う。
**驚き**：二通りの写しは一行だけ違う。「鳴る音に、その日の者を乗せよ」。読んだときは意味が取れない（取れなくてよい。頂でこの一行だけが銘に残っている）。札が二枚そろうと主人公「同じ日だ」。
**頂のあと**：山へ向けた火は、妹の行く道を照らしていた。「こたえない」の戸板には凹みが三つ。

### 4.3 地域五：一晩と三晩（麦の街道と関所・鐘守の修道院）
**昔**：飢えの年、関所は麦を一握りずつ取った。列の女は一握り余分に納めて、子の名を役人の帳面に書かせた。修道院は「西の飢えを救うため、境を東へ」と決めた。王家の金は会議より先に着いていた。反対した修道士は名を線で消し、納骨堂の当番になった。石工の頭は「一晩のみ」と言われ、木は三晩分と書いた。
**今**：麦の村は夕べの会の集落。ソレンヌの詰め所。ヴォルフラムの家の帳面「舟で着いた。十四」の下に、別の手で「ゼリナ（舟代）」。ゼリナが勘定の声で十四を数え、十五で止まる。「……うちの名、勝手に書きなや」。それだけ。修道院でテオが写しを続け、「読み比べは、好きです」。院長の成れの果てが空の鐘架に「東へ、東へ」。崖の小道で、巡礼が運んだ小鐘。
**夜の戸**：関所の塔の裏の番小屋。収税吏の声「通る者。一握り」。答えて倒すと「一握りは、わしのぶんだった」の一行。
**泣かせ所**：列に並んだ女の思念（4 行）。
```
札は家に一枚。この子は、札のあとに生まれた。
一握り、余分に納めた。この子の名を書いてもらうために。
役人は書いた。読み上げもした。
名を呼ばれて、この子が笑った。初めてだ。
```
反対した修道士の「金が先に来た。飢えは後から書かれた」。名を線で消したのは自分。
**驚き**：修道院の鐘架は空。主人公「鐘架だけだ。鐘は、四つにしか無い」。崖の上から東を見ると、頂の灯が鳴らした鐘の数より一つ多い（シャノが一度だけ言う。理由は最後まで誰も言わない）。
**頂のあと**：裏返さない。この地域は「一晩と三晩」のまま重く残る。

### 4.4 地域三：扉の外の歌（霧の湖・地下水道と地下都市）
**昔**：砦の酒保が舟を買い、大人を降ろして子ども十四人を乗せ、桟橋で灯が見えなくなるまで数えた。王国は民を地下へ送り、日没に扉を閉めた。司祭は札を子どもに渡して外に残り、残された民の弔いの歌を歌い続け、途中で止まった。
**今**：湖の家でミルレーネが二百年灯を点け、三つ目の節を歌わない。扉の内の村は外の話をしない。長だけが「戸を叩く音が増えた」と言う。扉の内側から子どもの数え歌「ひとつ、戸の外。ふたつ、扉の前」。
**夜の戸**：地下都市の閉じた扉そのもの。外からではなく、内から叩かれる。子どもの声「そとのひと、まだいる？」。答えると影は出ない。扉の内側で閂が一つ動く音だけ。
**泣かせ所**：外の子の思念「中で、だれかがぼくの名前で泣いてる」。アンセルモが冗談をやめる。
**驚き**：ミルレーネの歌の四つ目の節「戸を内より　ひらくときは／この歌も　とどかぬ」が、営倉で聞いた「門は内から開かれた」と同じことを言っている。井戸番の薄い思念 F09（桶が上がるまで三十を数える。墓守の指は一つ多い）のあと、主人公「……一つ多い」。
**頂のあと**：アンセルモの歌は鐘の代わりだった。声で送ろうとした。届いたかは書かない。扉の内の村が内から閂を外すのは、頼みごとの結果のまま。

### 4.5 地域四：かえりは かるい（境山の古道・鋳物場と研究所）
**昔**：帝国の古言兵は名を払った。研究所は骨拾いから買った骨を人に移した。坑夫の長女トゥーラは檻の小さい子らの世話を焼き、檻を曲げ、親鐘の舌を背負子に載せて「かえりは かるい」と彫った。ベルトランは骨拾いの洞の前で剣を杖に立ったまま止まった。
**今**：烽火台のグィドが数え歌で山を数える。骨拾いが誰とでも取り引きする。名無しが書き付けで話す。
**夜の戸**：帝国の陣跡の天幕。名無し兵の声。名は無い。「……おまえ。名前を、書こうとして」。答えて倒すと、宛名の無い手紙の一行「顔は覚えている。たぶん」。
**泣かせ所**：トゥーラの遺骸と背負子。檻の戸は内側から曲げてある。砦に戻った最初の夜：
```
シャノ「見てた？　今日は留め金が五つ。重かった」
シャノ「帰りは軽い、って頭が言うんだ。拾い屋はみんな言う。意味は知らねえ」
```
```
トゥーラ「……誰に教わった、それ」
```
```
シャノは梁へ登る。飯を食っていない。
```
```
トゥーラ「兄貴。あいつ、飯食ってない」
```

```
「……背負子の字と、同じだ」
```
以後、トゥーラは聞こえない相手に毎晩「寝ろ、馬鹿」と言う。シャノは毎晩、梁の上で寝る。結末の朝まで。
**驚き**：骨拾いが主人公に頭を深く下げる。帳面「問い：年を取らぬ者はいるか。答え：砦に一人」。舌を持ったとき主人公「舌だ。頂の鐘の」。
**頂のあと**：裏返さない。研究所も名無しも骨拾いも、そのまま重い。

### 4.6 門叩きの縄張り：呼んでやろうか
三つ目の鐘のあと、鳴っていない地域の色調が暗くなり、声だけの影が増える。縄張りの縁で門叩きがその地域の死者の声を替えて話し、最後に相棒の声で「呼んでやろうか。……三十一。お前は、いつも一つ多い」。名は来ない。廊下で塊から一行ずつ漏れる。漏れるのは、その地域でプレイヤーが読んだ思念と、夜の戸で拾った言い残しだけ。
**泣かせ所**：塊を崩したあとの司祭の場面（7 章の②）。
**驚き**：使徒の力を初めて自分の意志で使う。呑まれが溜まると、仲間が旅の呼び方で呼ぶ（「あなた！」「あんた！」「兄貴！」）。名を知らないまま呼ぶ。
**頂のあと**：「お前の分」は砦の三十人と相棒。門叩きは相棒を喰った。それは変わらない。

### 4.7 終盤：三十（境山の高み・頂）
**昔**：彫り直しの隊の最後の夜。宿帳「一晩のみ」。氷室の橇は舌を運んで戻らなかった。砦の鐘守の交代で泊まった墓守は、鐘守と向かい合って数える指の形を合わせ、「三十で止めろ」と言われた。指は三十一まで動いた。
**今**：灰の斜面でソレンヌが足場の木を担いでいる。「きみは、鳴らしに来たのか」。頂でルシアンが「鳴らしてくれて、ありがとう。あとは、私が彫ります」。足場の板には砦の倉の焼き印。
**泣かせ所**：「まだ」と三十（7 章の③）。
**驚き**：親鐘の銘。古い字は読めない。一行だけ、写しで見た字と同じ形が残っている。「鳴る音に、その日の者を乗せよ」。その上に新しい字が彫りかけてあり、「果て」の次で鑿が止まっている。主人公「ここで、止まっている」。
**頂のあと**：山を下りた夜、砦の戸を叩く音。

## 5. 三つの山

### 5.1 三つ目の鐘のあと：自分の記憶の場面
鐘番の思念の 2 ページ目。画面を暗くして文章だけ。地の文の主語は「自分」。
```
鐘が黙った。墓所の戸が、外から叩かれている。三度。
運びこまれてくる。外門の番、帳場の娘、教官。一人ずつ、まだ息がある。
息が止まるたび、思いが流れこんでくる。喰えば、楽になる。体がそう言う。
喰わない。代わりに、自分のものを一つ渡す。
```
```
外門の番には、一緒に数えた夜を。帳場の娘には、つけの帳面の夜を。
渡すたびに、喰いたいと言う自分が薄くなる。数える。二十八、二十九、三十。
相棒が、壁に向かって何かを彫りはじめた。刃の音が、戸を叩く音に混ざる。
三十一人目は、まだ来ない。目を閉じた。
```
```
「……喰わないために、預けたのか」
```
- 仲間も生き残りも何も変わらない。ただしこの夜から、食卓の奥の伏せた椀にヴォルフラムが飯を盛る。「先に盛る。家の決まりだ」。墓守の席に、初めて飯が来る。
- 「三十一人目は、まだ来ない」は、このときは分からない。縄張りで相棒の声が「三十一」と言い、頂で分かる。

### 5.2 塊の間（172）
1. 縁（170）：門叩きの声（3.3）。選択肢は無い。
2. 廊下（171）：声だけの影。塊から漏れる一行は、読んだ思念と拾った言い残し。彫り刀の音が近づく。
3. 塊の間（172）：ボス。使徒の力を自分の意志で使う。呑まれを仲間の呼びかけで戻す。崩すと、中の明かりが東の壁を抜けていく（頂の群れになる者を、ここで一度見せる）。
4. 司祭の最後の記憶（7 章の②。A の場面をそのまま）。「ルカ」。無音。名前の欄が変わる。床に刃の欠けた彫り刀。主人公は何も言わない。
5. 門叩きの声、遠く。「呼ばれてしまったか」。戻りの戸口から鐘の間へ。四つ目を鳴らす。

### 5.3 頂（180–183 → 015）
1. **灰の斜面**：ソレンヌ。**宿坊**：宿帳・氷室・F11「三十で止めろ」。**足場の番**：指図の写しで手が止まり「三晩」。**鐘楼の根**：綱を直す。根に結界を置く（頂は長い）。
2. **頂**：ルシアン。「あなたの連れは、何人です」。止める選択肢。ソレンヌ「ここからは、わたしが」「木は、下ろす」。ルシアンは座りこむ。
3. **銘**：一行だけ。「鳴る音に、その日の者を乗せよ」。彫りかけの新しい字が「果て」で止まる。説明はこれ以上しない。
4. **舌を吊る**。斜面の下から、鳴らした地域で東を向いて止まっていた者たちが上ってくる。二百年ぶんの思い。
5. **耐える戦い**「夜の思い」：倒す戦いではない。命令は「耐える」「呼ぶ（仲間）」の二つだけ（数えるのは綱の側だけにする）。ターンごとに、まだ見ていない薄い思念が群れから浮かんで記憶を返す。最後のターン、仲間が名で呼ぶ。ブルーノ「……ルカさん、で、合ってますか」。トゥーラ「ルカ兄貴！　戻ってこい！」。
6. **綱の前**：「引く」「まだ」。「まだ」で仲間が一人ずつ一言（7 章の③）。何度でも。引くのはプレイヤー。
7. **三十**：一回ごとに誰かが行く。画面を切り替えるのは二度だけ（稽古場のアデル、梁の上のシャノ）。残りは頂の文だけ。三十で相棒が手ぶらで立つ。
8. **三十一**：「もう一度、引く」「手を離す」。一人で引くと、音は山の向こうで消える。ミルレーネが来ていれば「わたしの民は、三十一まで数えるの」と言って一緒に引き、遠い山から知らない鐘が一つ応える。

### 5.4 結末（二つ）
| 結末 | 条件 | 中身 |
|---|---|---|
| **夕べの数** | 親鐘を鳴らす | 四つの地域の鐘が一つずつ応える。灰が止む。山を下りた夜、砦の食卓は仲間の席が七つ空いている。外門を三度叩く音。声は無い。開けても開けなくても、朝の段に小さな真鍮の鈴。朝、ピピネルが壁に立たせて背比べの刻みを一つ。椀が十四、伏せて干してある。中庭から「ルカ！　爺ちゃんが、飯だって！」。答えた |
| **遠い鐘** | 仲間 7 人完全体＋生き残り 7 人＋ミルレーネが砦にいる（〔秘〕） | 夕べの数に足す：三十一をミルレーネと一緒に引き、遠い山の鐘が応える。砦に戻って、墓所の壁の書き付けの最後の一画を、刃の欠けた彫り刀で彫り足す。名の壁の「墓守」の欄に名を彫り、削らない |

**仲間の別れ**は頂の三十の中で一人ずつ（7 章の③）。砦に戻ってからの別れの場面は作らない（七連続の型を避ける）。生き残りが何かに気づく一行は、三十の中の二度の切り替えと、結末の夜の食卓に散らす。

**後日談の一行**（頼みごと 8 本の結果ごと）
- 弟：アンネリーゼの鍛冶小屋の戸板の盾の裏に、新しい字が一行（ルッツの字。中身は読めない）。

- 夕べの会：ルシアンは修道院の空の鐘架の前に座っている。麦の村で、夕べの数のあとに戸を開けておく家が出てきた。

- マルゴとシャノ：マルゴは営倉の鐘を売るのをやめ、鐘守の名札を売りはじめる。
- 外に残されたエルフ：湖の灯の帳面の点の横に、開いた門の絵。
- 扉の内の村：大扉が、夕べの間だけ開く。

### 5.5 頂のあとに歩ける時間
決め：**結末のあと、朝の砦から歩ける**（記録「朝の砦」を自動で作る。頂の手前の記録はそのまま残る）。
- 灰は降らない。鳴らした地域の東を向いていた者たちはいない。四つの鐘の間は静か。
- 砦の食卓は生き残りだけ。仲間の席は空いていて、椀が置いてある。
- 書庫の「読んだ思念」の見出しが「送った人」になる。薄い思念はもう一度見られる。夜の戸で拾った言い残しも読み返せる。
- 礼拝堂の騎士の列、見張り台のノラの薪、扉の外の爪の跡は、そのまま。文は変えない。読み直す人にだけ、別の顔になる。
- 真の結末なら、名の壁と墓所の壁の字が変わっている。
- 新しい出来事は置かない（一つだけ：中庭で子どもが三十まで数え、「三十のつぎって、なんだっけ」と聞く。主人公は答えない）。

## 6. 見せ方の核（文章以外で心を動かす仕掛け）

1. **数える（夕べの数をプレイヤーの手で）**
   人が三十まで数えるのを見せつづけ（巡礼、像の輪、子ども、アデル）、頂で初めて綱を三十回引かせる。一回ごとに一行、誰かが行く。三十で指が止まらず「もう一度、引く」が出る。耐える戦いでは数えない（数えるのは綱だけ。二度続けない）。二度目の周回からは早送りを許す。
2. **夜の戸（序盤から選ばせ、最後に自分で開ける）**
   地域ごとに一つ、暗い所の戸で三度叩く音と声。「答える」「答えない」。答えると声だけの影が出て、倒すとその人の言い残しが一行残る（書庫に溜まる。頂の三十で、その人が群れから浮かぶ）。答えなくても何も失わない。結末の夜、砦の外門で初めて「開ける」。開けると段に鈴。
3. **東を向く敵**
   鐘を鳴らした地域の敵は、以後、追わない。全部が東を向いて止まる。触れると戦闘になるが動かない。説明は無い。塊を崩したとき中の明かりが東の壁を抜け、頂で止まっていた者たちが斜面を上ってくる。「止まった者が頂の群れになる」を、文ではなく絵で一度見せる。
4. **食卓の両側と伏せた椀**
   大広間の食卓は十四席。生き残りが来るたび片側が埋まり、仲間を呼ぶたび反対側が半透明で埋まる。生き残りのイベントは仲間の席を素通りする。プレイヤーだけが十四人を見る。始まりに伏せた椀が一つ、三つ目の鐘の夜にその椀に飯が盛られ、結末に十四が伏せて干してある。
5. **読んだ分だけ集まる（罰にしない）**
   塊から漏れる一行と、頂の群れに浮かぶ顔は、読んだ思念・見た薄い思念・拾った言い残しだけ。読んだ人ほど見送る人が多い。読まなかった人の頂は静かで短い。それだけ。呑まれにも弾にもしない。

ほかに小さく効く所：音楽を置かない（音は足音・戸を叩く音・鐘だけ。結末の朝に初めて短い曲）。縄張りで門叩きの声が替わるたび、窓の名前の欄がその死者の名になる。「見てた？」は道中三回まで。

### 8.4 講評の三人の目で読み直して、直した所
- **編集者**：銘を四行から一行にした。研究所・名無し・骨拾いを裏返しから外した。「届けるは行かせないでもある」を 1 章の要約にだけ残し、ゲームの文からは消した。縁は三組。司祭の名をテオと揃えるのをやめた。アンセルモの「向こうで歌う。ちゃんと最後まで」を数え歌の一行に替えた。ヴォルフラムの「十四人ぶん多い」を消した。「炉の火は、まだ燃えている」で終えず「答えた」で終える。主人公の「……戸には、答えなかったのか」は置かない。
- **演出家**：中盤の問いを地域ごとに一言。頂のあとに歩ける記録。「呼んでやろうか」は声だけ一回。名前の欄は無音と窓で一度見せる。足音は作らない。二文字の空白は使わない。耐える戦いで数えない。切り替え二度。
- **初めて遊ぶ人**：冒頭に戸を叩く音と伏せた椀。中盤の仲間の薄さは、食卓の対（アデルの講義、毎晩の小言、先に盛る一椀）で埋める。「乗せよ」の一行は意味が取れなくてよい、と割り切る代わりに、夜の戸で「声は本当にその人だった」を手で知らせる。灯の数は結末で「もう無い」とだけ書いて、五つと言わない。頂は「まだ」で一度息をさせてから三十。

**いちばん弱かった所と書き直し**：三案を混ぜると、結末に「仲間の別れ（頂の三十）」「夜の戸」「背比べ」「椀」「答えた」が並び、長くなる。七人の別れを砦でもう一度やらないことに決め、三十の中の切り替えを二度に絞り、結末の夜の食卓はアデルとイスメネの二行だけにし、朝はピピネルの一言・椀の一行・シャノの二行・子どもの一行で止めた。書き直す前は朝に主人公の「三十一」があったが、「答えた」に負けるので消した。三十一は頂にだけある。
