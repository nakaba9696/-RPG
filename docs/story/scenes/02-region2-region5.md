原作 [docs/story/novel/02-region2-region5.md](../novel/02-region2-region5.md) の二十九の節を、マップのイベントに起こす台本。骨子は [original.md](../original.md) 4.2・4.3・8.2、決めは #225 の「持ち主の決め」。今のイベントの文は `data/MapNNN.json` から読んだ（データは触っていない）。

**読み方**
- 一つの節に、表が一つ（場所・出る条件・した後・出典・今の文との差）と、その下に「文」の塊。文は 1 行を全角 26 字までで切った。行の頭の〔〕は器：〔文〕文章の表示（話し手なし）、〔名〕文章の表示（101 の 5 つ目が話し手）、〔思〕残留思念（`<hai_thought>`）、〔薄〕薄い思念（`<hai_faint>`。あとに共通イベント 201）、〔記〕記憶の断片（`<hai_memory>`）、〔選〕選択肢、〔演〕演出（文は出ない）。
- 「今」＝今のイベントの文のまま。「差し替え」＝今の文をこの文に。「追加」＝イベントか行を足す。「新」＝イベントを新しく作る。
- 旗の帯：W8（地域二）はスイッチ 412 から、W12（地域五）はスイッチ 1060 から、砦（010・014）は W6 の帯の空き（175 から。配り役が確かめる）。新しく要る物の一覧は末尾の 1。
- 前提：鐘の順は 営倉 → 記録院（二つ目）→ 水底 → 鋳物場。ノラの妹は「イーダ」。写しは、砦の書庫（014）の読み比べ → テオの三通り目（121）→ イスメネへ返す（014 か 080）。夜の戸の言い残しは四つとも頂の三十で浮かぶ（N4-4 が同じ文を使う。ID は N4-1 の付け方で `L2-01`・`L5-01`）。N4-1（#226）・N4-3（#227）・N4-4（#228）の章末の一覧と帯を突き合わせた。
- 主人公の台詞は `\N[1]`（名前の欄は「墓守」）。「乗せよ」は 014 だけ（082・121・015 は書かない）。

## 末尾 3. 小説から落とした場面と理由

| 小説の節 | 落とした所 | 理由 |
|---|---|---|
| 一 | ピピネルが袖を下ろす（墓守の目線に気づく） | 絵が無い。文の二行（1-1）に縮めた。「傷」は言わない |
| 五 | 墓守が右の手で三つ数え、四つ目を折る | 一行の文（1-5）に。手の絵は作らない |
| 六 | ノラが「ブルーノの隣に腰を下ろして、すぐ立って、また座った」 | 食卓の席の絵は N4-1 の仕組み。ノラの二行だけ残した |
| 七 | ノラが先を走る、井戸の底を覗く、ブルーノが「何か言おうとした」 | 歩き方・目線の演出は作らない |
| 八 | 「麦の匂いの風」以外の戦闘の描写（ノラが二度動く、ブルーノが盾を構える） | 戦闘はシステムが見せる |
| 十 | ブルーノが戸板の脇で三十を数える、女の思念が顔を埋める | 夜を待つ時間が無い。夜の戸は戸を調べたときに始まる |
| 十一 | アデルが見張り台の上から言う | アデルは中庭の火の脇に立たせる（位置は W）。S307 が無いときは問いを地の文に |
| 十三 | 「ノラは数えなかった。井戸の桶の縁の、鐘の印を見ていた」 | 絵が無い。夕べの数の文に入れなかった |
| 十四 | 荷車の小屋で夜を過ごす、ブルーノが三十を数える | 同上。夜の戸は戸を調べたときに始まる |
| 十六 | シャノが鉤を外す絵、「縄では下りない」のあとに歩いて帰る | シャノは台詞のあと一時消去。砦に戻れば梁の上にいる |
| 十七 | 「墓守は束を、革ごと懐に入れた」「墓守は、手を下ろした」 | 物を手に入れる文で足りる。手の絵は無し |
| 十九 | 王家の使いの部屋を削った（小説） | ゲームには残す（金の箱の跡・机は今のまま。文は変えない） |
| 二十一 | 「前庭の床に刻んだ輪の中に立つと、麦の村の井戸の脇に」 | 結界の移動そのもの。文は要らない |
| 二十三 | 「墓守は壁に手をついて歩いた。ノラが先に走って、戻ってきて」 | 迷路の歩き方は遊び。R2-20 で足りる |
| 二十五 | ディルが「席を見て回った。奥の伏せた椀の前で止まって、起こさなかった」 | 席の絵は N4-1。一行「向かいに座った」に |
| 二十七 | 「綱は太く、二百年ぶんの硬さだった」「ブルーノが数えた。いち」 | 綱の文は今のまま（一度引いて長く鳴る）。頂の三十と重ねない |
| 二十八 | 「三度読んで、三度とも、同じ所で止まった」 | 「意味は、取れなかった」の一行で足りる |
| 二十九 | 「写しは、三日、二つの書見台の上にあった。四日目の朝」、ノラが呼びに行く | 日数はゲームに無い。持ち出しの選択肢に。ノラの往復は絵が要る |
| 全体 | 「灰色で、薄い」「透けていた」などの思念の見え方 | `Hai_Thoughts` の見せ方（半透明の歩行グラ）のまま |
