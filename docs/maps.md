# マップの一覧（W レーン）

製品のマップの ID・名前・下書き（文字マップ）・持ち主の仕上げの状態と、入口と出口の表。
**追記だけ**（[docs/ROADMAP.md](ROADMAP.md) の「エディタとクラウドの行き来の約束」）。

- 下書きは `tools/maps/src/<名前>.txt`（地図）と `.json`（設定・イベント）。`node tools/maps/build.mjs <名前>` で `data/MapNNN.json` を作る（[tools/maps/README.md](../tools/maps/README.md)）。
- 持ち主が MZ のエディタで仕上げたら「仕上げ済み」に日付を書く。**仕上げ済みのマップは JSON が正本**（#5）。子は文字マップから作り直さず、イベントと欄だけを直す。
- データベースの項目（敵・宝箱の中身・鍵）は `tools/maps/src/w1_data.mjs` が書く（W1 の帯 201–300。何度走らせても同じ結果）。
- 座標は `(x, y)`、0 始まり（文字マップの列が x、行が y）。
