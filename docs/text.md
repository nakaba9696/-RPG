# 文の構成表 — 何を・どの順で・誰の口から出すか（D12）

プレイヤーが読む文（日記・手紙・帳面・布告・碑文・思念の声・来歴・ボスの言葉・生き残りの会話）を、**どの断片が、どの順で、誰の言い分として**真相を運ぶかを決める表。
文を書く人（地域ごとの文の担当、W、P、D）が、**本文を書く前に読む**。設定の正本は [docs/world.md](world.md)、書き方の決まりは [docs/knowhow.md](knowhow.md)。このファイルは設定を足さない。足したくなったら決定待ちの issue（#162）に書く。

- 持ち主の希望：「テキストの構成をちゃんとやりたい。読ませる面白い文章にしたい」（#158）。
- **この表は設計の文書で、マップやデータは触らない。** 本文の書き直しは、持ち主の OK のあと、地域ごとの文の担当（後の issue）がする。地域一（W6・W7）の文は main にある。地域二〜四（W8・W9・W10）の仮置きの文は、この表を指示書にして書き直す。
- 段階の印〔知〕〔噂〕〔進〕〔秘〕は [knowhow.md 2.1](knowhow.md#21-設定の段階の印)。禁止語は [world.md 10 章](world.md#10-禁止語の表)、口調は [11 章](world.md#11-口調の表)。この表の例文もその決まりで書いた。
- 「断片」＝プレイヤーに見える文の一つ（思念一つ、物一つ、会話一つ）。「芯」＝その断片が運ぶ一行。「引っかかり」＝読んだ人が引っかかる、数・欠け・ずれ・削り。
- **D14（#168）で 40 時間の構成に合わせた。** 足した地域（五 麦の街道と修道院・六 雪の峠と国境・七 歌の森・門叩きの縄張り・終盤 境山の高み）と寄り道のダンジョンの割り当ては 5.7〜5.11。段の表（1 章）は段を増やさず、新しい地域の言い分を段 3〜5 の中に入れた。#162 で持ち主が OK した推し（薄い思念 F08・F09、当番の札、口調の表の人物）は world.md に反映済み。

## 0. 三つの約束と、読ませる文の作り

### 0.1 三つの約束（world.md の「持ち主が決めたこと」から）
1. **言い分は増える。答えは増えない。** 段が進むほど、勢力ごとの言い分が増えて食い違う（world.md 8.2）。どの段でも「一つの真実」に近づかない。決め手・写しの真偽・エルフは知っていたか・騎士長の理由・信徒の気持ち（1.5）は、最後まで誰も書かない。
2. **墓守の糸は、他人の用事の中の一行だけ。** 正体は 3 つ目の鐘のあと、主人公自身の記憶の場面で分かる。それまでも、そのあとも、誰も指さして話さない（3.2）。仲間は墓守を知らない。
3. **人も文書も思念も、自分の暮らし・思惑・後悔のことだけ。** 世界の説明をする人はいない。用語は、暮らしの言葉の中で開く（knowhow 2.2）。

### 0.2 読ませる文の作り（この表の全部に当てる）
| 作り | 中身 | 例 |
|---|---|---|
| 引っかかりを一つ | 一つの断片に、数が合わない・名が無い・線で消してある・最後の一画が無い、を**一つ**置く。二つ置くと薄まる | 札の釘は四本、札は一枚（036） |
| 終わりは物 | 最後の行は物・数・動作。感想・余韻・抽象語で終えない（knowhow 4.2） | 「賭けは、干し杏が三つ」 |
| 長さを変える | 2 行の思念、刻みだけの文、4 行×2 ページの手記を混ぜる。同じダンジョンで同じ型を続けない | 牢番の思念（R1-26）は 3 行の数だけ |
| 隣に置く相手を決める | どの断片にも「並べると見える相手」を一つ決める（この表の「並べる相手」の欄）。並べても一つの答えにはならない | 営倉の札（036）と頂の指図書（015）の日付 |
| 声を変える | 勢力ごとに文の声が違う。教会は祈りの文句、帝国は報告の体言止め、王国は布告の硬い言葉、エルフは歌、記録院は言い訳の混ざる丁寧語、信徒は経典の呼びかけ、傭兵は値段と重さ | 2 章の表 |
| 用事の途中 | 文は「用事の途中」の形で書く。報告の一行、つけの帳面、配給の札。世界について語ろうとした文は捨てる | 「水を汲んでおいてって言われたの。桶に三杯」（K04） |
| 察しの一歩先を渡さない | 読んだ人が察せる所で止める。「つまり」「だから」「本当は」を書かない。断片が言うのは事実と数だけ | 「門は内から開かれた」と経典は書く。誰が開けたかは経典に無い |

### 3.2 正体を直接言わない書き方の型
| 型 | 書き方 | 例 | 書かない形 |
|---|---|---|---|
| 数のずれ | 年を取らないことを、年数・代・つけの月数で示す | 「五冊とも、書いた手は同じ」「つけは二百年分」 | 「墓守は二百年生きている」 |

## 4. 文の種類ごとの型

長さは「1 ページ 4 行、1 行は顔なし全角 46 字・顔あり 40 字」（knowhow 7.2）。来歴は 1 行 40 字。例は**この表のために書き下ろした**。地域二〜四の担当はこの温度で書く（例をそのまま使ってもよい。使ったら 5 章の表に印を付ける）。

### 4.1 残留思念
**4 行の例**（070 葦原の舟着き「降ろされた男」。方舟の、乗れなかった側）
```
籠を担いで舟に乗った。酒保の女が、籠だけ受け取って、俺を降ろした。
子どもが十四。大人は漕ぎ手の二人だけだと。
籠には、俺の娘の靴が入っていた。娘は乗っていた。
岸で数えた。灯が見えなくなるまでに、三十を九回。
```
- 言い分：乗せた側（ゼリナの記憶 3「大人を降ろした」）と降ろされた側。どちらも責めない。
- 引っかかり：籠だけ受け取った。並べる相手：ゼリナの臨終（灯が見えなくなるまで数えた）。同じ夜を、岸と桟橋で二人が数えた。

**2 行の例**（102 扉の外に残された民。年寄り）
```
札を持っとる子から順だと。わしの札は、朝に孫に持たせた。
戸の内で、孫が泣いとる。泣くな。戸は、もう叩かん。
```
- 引っかかり：自分の札を渡した。並べる相手：アンセルモの記憶 3（札を外の子に渡した）。王の布告「札を持つ者から順に」。

```
見張り台から村の門まで、墓守と駆けっこをした。
墓守は途中で転んだ。転ぶと決めてあった転び方だった。
ぼくが勝った。賭けは、干し杏が三つ。
```
