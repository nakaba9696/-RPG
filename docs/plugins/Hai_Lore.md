# Hai_Lore — アイテムの来歴と「遺物の記録」（U4）

MZ の説明欄（2 行）に入らない長い来歴（3〜6 行）を読む窓と、一度手に入れた物の来歴をあとで読み返せる「遺物の記録」（#96）。
D7 の方針「アイテムの配置と説明文で真相を語る」の器。来歴の文の決まりは [docs/lore.md](../lore.md) 1 章と [docs/knowhow.md](../knowhow.md) 5.1。

## 来歴の書き方（W が書くとき）
アイテム・武器・防具の**メモ欄**に書く。
```
<hai_max:2>
<hai_lore>
帝国の工兵隊の鍵。輪に、木の札が一枚下がっている。
札の字は「下層　四十二」。四十二を削って三十九。
札の裏に、爪で引いた線が三本ある。
</hai_lore>
```
- `<hai_lore>` と `</hai_lore>` はそれぞれ**1 行に置く**。間の 1 行が画面の 1 行。**3〜6 行**、1 行は**全角 40 字まで**（`tests/t_words.mjs` が数える）。
- 本文に `<` `>` を使わない（メモ欄の読み取りが壊れる）。制御文字も使わない。行の頭に「」を付けない。
- 禁止語は**全部**使わない（マップ限定の語も。持ち歩けてどのマップでも読めるため）。説明欄も同じ（`t_words` が当てる）。
- ほかのタグ（`<hai_max:2>`・`<hai_unique>`・`<hai_craft:…>`）と同じメモ欄に並べてよい。順はどれでもよい。
- 説明欄（2 行）の 1 行目は効果、2 行目は来歴の一行（lore.md 1.1）。来歴の窓には説明欄は出ない（名前と種類と来歴だけ）。

## 画面
| どこで | 中身 |
|---|---|
| アイテムの画面・装備の画面（欄と候補の一覧）・店の売る一覧・戦闘のアイテム | 来歴のある物の数の左に小さな印（`◆`） |
| アイテムの画面・装備の画面 | 来歴のある物を選んでいる間、説明の窓の右下に「◆来歴を読む（R）」。**R キー**（ゲームパッドは RT）か、**説明の窓を押す**と来歴の窓 |
| 来歴の窓 | 上に名前と種類、下に 4 行ずつ（パラメータ `linesPerPage`）。決定・→・W で次のページ（最後のページで閉じる）、←・Q で前、キャンセル・R で閉じる。押しても次へ |
| メモの画面（Hai_Notes）の 4 つ目の種類「遺物（N）」 | 遺物の記録。手に入れた順（Q・W か説明の窓を押すと種類別：道具 → 大事なもの → 武器 → 防具）。今は持っていない物（使った・売った）は薄く「手放した」。決定で来歴の窓 |

- 説明の窓には、選んだ物を手に入れた所（マップの表示名 x,y）と時刻（プレイ時間）。
- 来歴の窓の間は、ほかの窓とタッチのボタン（戻る・前後の人）を止める。
- パラメータ `recordsPlace` を `menu` にするか、`Hai_Notes` が無いときは、メニューの「遺物の記録」（`Scene_HaiLoreBook`）になる。

## 遺物の記録に載るとき
- `Game_Party.gainItem` で増えたとき（宝箱・イベントの増減・戦闘の報酬・店で買う・合成）。**倉庫へ送られた分も**（`Hai_Items` の後に読むので、袋の数が増えなくても拾う）。
- 来歴の窓で読んだとき（`open(item)` を含む）。
- 初めて載ったときは「`\I[n]名前`の来歴を読める。」と知らせる（`noticeText`）。マップと戦闘ではその場で文章、メニュー・店の中ではマップに戻ってから。
  装備の付け替えで袋に戻ったときは載せるが知らせない。
- 使っても売っても消えない。記録の並びは手に入れた順のまま。

## キー
`haiLore`：キーボード **R**（82）、ゲームパッド **RT**（7）。パラメータ `loreKey`・`loreButton` で変えられる。[keys.md](keys.md)。

## パラメータ
| 名前 | 既定 | 中身 |
|---|---|---|
| `recordsPlace` | `notes` | 遺物の記録の置き場所（`notes` メモの画面の種類 / `menu` メニューの項目） |
| `tabText` | `遺物` | メモの画面の種類の名前 |
| `menuText` | `遺物の記録` | メニューの項目名（`menu` のとき。空で出さない） |
| `linesPerPage` | `4` | 来歴の窓の 1 ページの行数 |
| `loreKey`・`loreButton` | `82`・`7` | 来歴を読むキー（0・-1 で足さない） |
| `mark` | `◆` | 一覧の印 |
| `hintText` | `来歴を読む（R）` | 説明の窓の案内 |
| `noticeText` | `%1の来歴を読める。` | 初めて手に入れたときの知らせ（空で出さない） |
| `releasedText` | `手放した` | 記録の一覧で、今は持っていない物の印 |

## プラグインコマンド
| コマンド | 中身 |
|---|---|
| `open`（来歴を読む） | 種類と ID の物の来歴の窓を開く（記録にも載せる）。イベントで「拾った物をその場で読ませる」とき |
| `openRecords`（遺物の記録を開く） | 遺物の記録（メモの画面の「遺物」） |

## 窓口（`window.Hai.Lore`）
| 関数 | 中身 |
|---|---|
| `has(item)` | 来歴があるか |
| `text(item)` / `lines(item)` | 来歴（行を `\n` でつないだ文字列 / 行の配列） |
| `records()` | 遺物の記録（手に入れた順）`[{ kind, id, time, mapId, x, y, item }]`（`kind` は `item`/`weapon`/`armor`） |
| `isRecorded(item)` / `record(item)` | 記録に載っているか / 載せる（初めてなら true） |
| `isOwned(item)` | いま持っているか（袋・装備・倉庫） |
| `open(item)` | 来歴の窓。来歴の窓のある画面ならその場で、ほかは来歴だけの画面を重ねて閉じたら戻る |
| `openRecords()` | 遺物の記録を開く |

## 状態（セーブに入る）
```js
$gameSystem._hai.lore = { list: [{ kind: "item", id: 941, time: 2, mapId: 914, x: 3, y: 4 }] };
```
古いセーブで無ければ、読むときに `{ list: [] }` を入れる。

## 中身（alias したところ）
- `Game_Party.prototype.gainItem`：記録・知らせ。`Game_Actor.prototype.tradeItemWithParty`：付け替えの間は知らせない。
- `Window_ItemList.prototype.drawItem`・`Window_EquipSlot.prototype.drawItem`：印。
- `Window_Help.prototype.setItem`・`setText`・`refresh`：説明の窓の案内（アイテム・装備の画面の説明の窓だけ）。
- `Scene_Item`・`Scene_Equip` の `create`・`update`：来歴の窓と R キー・説明の窓を押したとき。
- `Scene_HaiNotes`（Hai_Notes）の `create`・`update`・`onCategoryOk`：4 つ目の種類。**Hai_Notes の中身は変えていない**（シーンの窓に、外から種類を 1 つ足す）。
- `Scene_Map.prototype.update`：メニューの中で起きた知らせを、マップに戻ってから出す。
