# Hai_SymbolEnemy（シンボル敵）

VISION.md の核 2「戦闘は原則すべて任意」のためのプラグイン（P1、#10）。
敵はマップ上を動くイベントで、色で強さが分かり、近づくと弱く追ってくる。ぶつかると戦闘。動きは単純なので、見切って避けられる。
ランダムエンカウントは使わない（マップの `encounterList` は `[]` のまま）。

## メモ欄（イベントのメモ欄。ページではなくイベント全体に書く）
| タグ | 意味 |
|---|---|
| `<hai_enemy:101,green>` | シンボル敵にする。`101` は戦う敵グループ（`Troops.json` の ID）、`green` は強さ（`green` 弱い／`yellow` 中くらい／`red` 強い）。強さの綴りが違えば `green` |
| `<hai_enemy_once>` | 勝ったら二度と出ない（ボス・一点ものの強敵）。無ければ、マップを出入りすると復活する |
| `<hai_enemy_chase:6>` | この敵だけ追い始める距離を変える（`0` で追わない）。省略でパラメータの「追い始める距離」 |
| `<hai_enemy_hesitate>` | 弱い化け物のためらい（P12、world.md 3.2）。主人公を見つけると、こちらを向いて一瞬止まってから追う。理由は出さない。`<hai_enemy_hesitate:40>` で止まるフレーム数を変える（省略でパラメータ「ためらう時間」） |
| `<hai_enemy_shade:一行>` | 声だけの影（P13、world.md 3.7・mapdesign.md 7 章）。下の「声だけの影」 |
| `<hai_enemy_bell:103>` | 東を向いて止まる（P14）。下の「東を向いて止まる」。マップのメモ欄にも書ける |

## 声だけの影（`<hai_enemy_shade>`。P13 #189）
門叩きの縄張り（170–173）と最後の地域の鐘の間の手前に置く敵。`<hai_enemy:…>` と一緒に書く。
- **姿が薄い**：絵の不透明度をパラメータ「影の不透明度」（既定 96）にする（ページが変わるたびに付け直す）。色（緑・黄・赤）はふつうの敵と同じに重なる。
- **追わない**：追い始める距離を 0 にする（`<hai_enemy_chase>` があっても）。自律移動は動く（固定にしておけば動かない）。
- **触れると戦闘**：ふつうの敵と同じ（どちらからぶつかっても。逃げたらすり抜け）。
- **倒すと一行の声を残す**：勝ったあと、タグの値の一行を窓なし・画面の真ん中に出す（`["", 0, 2, 1, ""]` の文章の表示。制御文字は使える。`>` は書けない）。値を省く（`<hai_enemy_shade>`）と何も出さない。
  何を言わせるかは W11（text.md 5.5 の c：その地域で読んだ思念の一行）。読んだかどうかで声を変えたいときは、影を出す・出さないをページの出現条件で分ける（影ごとに別のイベント）。
- 復活はふつうの敵と同じ（`<hai_enemy_once>` が無ければマップに入り直すと戻り、倒すとまた同じ声を出す）。

## 東を向いて止まる（`<hai_enemy_bell>`。P14 #230）
鐘を鳴らした地域の敵は、追わずに東（右）を向いて止まる（world.md 8.2、scenes/01 の十四、04-climax 章末 1）。
- 書く所：敵イベントのメモ欄に `<hai_enemy_bell:スイッチ ID>`（その地域の鐘のスイッチ。営倉 101 など）。
  **マップのメモ欄**に書くと、そのマップのシンボル敵すべてに付く。両方にあればイベントのほうを使う。
- スイッチが **ON の間**：追わない（見えても）・ページの自律移動もしない・右を向いたまま・絵の不透明度は「影の不透明度」。
  ページを替えずに毎フレーム見るので、鐘を鳴らしたその場でも止まる。OFF に戻れば元の動きと濃さに戻る。
- 触れると戦闘（ふつうの敵と同じ。逃げたらすり抜け）。説明の文は出さない。
- **朝の砦**：パラメータ「朝の砦のスイッチ」（既定 1165。W14 が作る）が ON の間、この旗の敵はどのページも出さない（絵も当たりも無い）。

## 動き
- ふだんはページの「自律移動」のとおり（固定・ランダム・近づく・カスタムの巡回）。
- プレイヤーが**追い始める距離以内**（縦と横の歩数の和）にいて、**間に通れないマス（壁・岩）が無くまっすぐ見える**ときだけ、プレイヤーへ 1 歩ずつ向かう。
  速さは「追う速さ」（既定 3。プレイヤーの歩きは 4）。回り道はしないので、角を曲がって見えなくなれば追うのをやめる。
- 見えなくなる・離れると、その場から元の自律移動に戻る（元の位置へは帰らない）。
- 他のイベントは視線をさえぎらない。
- `<hai_enemy_hesitate>` の敵は、見つけた（追い始めた）とき、プレイヤーの方を向いて「ためらう時間」（既定 30 フレーム）止まり、そのあと追う。
  止まっている間は自律移動の待ちも数え直すので、実際に動き出すのは、ためらう時間＋自律移動の頻度の待ちのあと。
  見失ってから見つけ直すと、もう一度ためらう。逃げたあと・ページが変わったときは数え直す。フキダシや文は出さない。

## 接触で戦闘
- トリガーが「プレイヤーから接触」（1）でも「イベントから接触」（2）でも、**どちらからぶつかっても**戦闘になる（MZ の既定では 1 は敵の側からぶつかっても始まらないので、プラグインで足している）。
- 戦闘は「戦闘の処理」（301）と同じで、**逃走可・敗北不可**（負けたらゲームオーバー。全滅の扱いは P5 で変える）。
- ページの実行内容に命令があれば、それを先に実行してから戦闘する（ボスの台詞など）。戦闘の命令は書かなくてよい（書くと 2 回戦う）。
- **勝ったら**：そのイベントのセルフスイッチ **A** を ON にし、どのページも出さない（絵も当たりも消える）。
  マップに入るとき（別のマップから移ってきたとき）に、`<hai_enemy_once>` の無い敵のセルフスイッチ A を OFF に戻す＝復活。同じマップの中の場所移動・戦闘からの戻り・ロードでは復活しない（ただしゲームを更新してマップが変わったあとのロードでは MZ がマップを読み直すので復活する）。
- **逃げたら**：「すり抜ける時間」（既定 180 フレーム＝3 秒）のあいだ、その敵はすり抜け（プレイヤーと重なれる）になり、追わず、ぶつかっても戦闘にならない。
  時間はマップでイベントが動いていない間に数える。終わるときにプレイヤーと重なっていれば、離れるまで待つ。

セルフスイッチ A はこのプラグインが使うので、シンボル敵のイベントでは A を別の用途に使わない（B〜D は自由）。

## 色
- 強さごとに、キャラの絵に色を重ねる（`Sprite.setBlendColor`）。既定は 緑 `48,224,64,144`、黄 `255,208,0,144`、赤 `255,32,32,176`（赤,緑,青,強さ）。
- 絵はどれでもよい。暗い絵ほど色がはっきり出る。試験場（Map901）は `Monster` の 5 番（フードの影）を使っている。

## パラメータ
| 名前 | 表示名 | 既定 | 中身 |
|---|---|---|---|
| `chaseRange` | 追い始める距離 | 4 | この歩数以内（縦＋横）でまっすぐ見えると追う |
| `chaseSpeed` | 追う速さ | 3 | 追っている間の移動速度（1〜6）。プレイヤーより遅くする |
| `fleeFrames` | すり抜ける時間 | 180 | 逃げたあとすり抜けるフレーム数 |
| `hesitateFrames` | ためらう時間 | 30 | `<hai_enemy_hesitate>` の敵が見つけてから止まるフレーム数 |
| `shadeOpacity` | 影の不透明度 | 96 | `<hai_enemy_shade>` の敵と、止まっている `<hai_enemy_bell>` の敵の絵の不透明度（0〜255） |
| `morningSwitch` | 朝の砦のスイッチ | 1165 | ON の間、`<hai_enemy_bell>` の敵を出さない（0 で使わない） |
| `greenColor`・`yellowColor`・`redColor` | 緑・黄・赤の色 | 上の「色」 | `赤,緑,青,強さ`（0〜255） |

プラグインコマンド `defeated`（勝ったとき）・`escaped`（逃げたとき）は、接触の戦闘のあとに自動で実行される。手で使う必要はない。

## 状態とセーブ
- 追っているか・すり抜けの残り・ためらいの残りは、イベント（`Game_Event` の `_haiSymbol`）に持つ。`$gameMap` ごとセーブに入るので、`$gameSystem._hai` は使っていない。
- 勝った・まだ、はセルフスイッチ A（セーブに入る）。

## 窓口（`window.Hai.SymbolEnemy`）
| 関数 | 返すもの |
|---|---|
| `isSymbolEnemy(event)` | シンボル敵か |
| `rankOf(event)` | `"green"`・`"yellow"`・`"red"`（シンボル敵でなければ `null`） |
| `troopOf(event)` | 敵グループの ID |
| `state(event)` | `{ chasing, flee, through, defeated, hesitate }`（`hesitate` はためらいの残りフレーム。古いセーブで欄が無ければ 0） |
| `hesitateOf(event)` | その敵のためらう時間（`<hai_enemy_hesitate>` が無ければ 0） |
| `isShade(event)` / `shadeVoice(event)` | 声だけの影か / 倒したときの一行（無ければ `""`） |
| `canSeePlayer(event)` | 今プレイヤーを追える（距離の内で、まっすぐ見える）か。東を向いて止まっている間は false |
| `bellSwitchOf(event)` / `isBellStopped(event)` | 東を向いて止まる旗のスイッチ ID（無ければ 0）/ 今止まっているか |
| `colorOf(rank)` | その強さの色 `[赤, 緑, 青, 強さ]` |
| `params` | `{ chaseRange, chaseSpeed, fleeFrames, hesitateFrames, shadeOpacity, morningSwitch }` |

## W レーンが敵を置く手順
1. **敵グループ**を自分の帯の `Troops.json` に作る（P1 の 101〜103 は試験場用。製品の敵は W の帯で）。
2. マップにイベントを置く。**メモ欄**に `<hai_enemy:敵グループ ID,強さ>`（ボスなら `<hai_enemy_once>` も）。
3. ページ 1 つ（条件なし）：
   - 画像：敵の歩行グラフィック（W・V が決めるまでは `Monster` などの同梱素材でよい）。
   - 自律移動：巡回なら「カスタム」（移動ルートの「スキップ」を ON にすると壁で止まらない）、うろつくなら「ランダム」、待ち伏せなら「固定」。
     速さは 3（プレイヤーより遅く）。頻度は巡回 5、ランダム 3 くらい。
   - プライオリティ：「通常キャラと同じ」。トリガー：「イベントから接触」（または「プレイヤーから接触」）。
   - 実行内容：空でよい（戦闘はプラグインが足す）。台詞を出したいボスだけ書く。
4. 文字マップ（`tools/maps/src/*.json`）で置くときは `type: "raw"` を使う。例は `tools/maps/src/p1_symbols.json`。
5. 置き方の目安：巡回の道は、プレイヤーが**待てる場所**（敵の通り道から追い始める距離より遠い所、または壁の陰）を作ってから横切らせる。
   1 マス幅の通路で巡回させると避けられない（核に反する）。
