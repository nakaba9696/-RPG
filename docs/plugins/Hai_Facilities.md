# Hai_Facilities — 砦の部屋：生き残りが来たら開く（P8・P11）

VISION.md 核 6「拠点と、そこで開く部屋」のためのプラグイン（#82、新しい世界に合わせたのは #134）。
部屋が開く順と条件は [docs/world.md](../world.md) 4.3（黒鉄の砦）。**叡智のオーブはやめた**。部屋は**生き残りが砦に来ると開く**。
合成は [Hai_Craft](Hai_Craft.md)、倉庫は [Hai_Items](Hai_Items.md)、控えの仲間は [Hai_Companions](Hai_Companions.md) の窓口を使う。
並びは `Hai_Companions` の後・`Hai_Comfort` の前（`js/plugins.js`・`tools/data/check.mjs` の `PLUGIN_ORDER`）。

## 部屋が開く
| 部屋 | 鍵 | マップ | 開く人（world.md 4.3） | スイッチ |
|---|---|---|---|---|
| 稽古場 | `soul` | 011 | アデル | 121 |
| 食堂 | `kitchen` | 012 | ヴォルフラム | 122 |
| 倉 | `gate` | 013 | シャノ | 123 |
| 書庫 | `lore` | 014 | イスメネ | 124 |

（鍵の名前 `soul` ほかは前の世界の名残り。セーブと W の既存のイベントを壊さないために変えない。）

- 生き残りが砦に来た場面のイベント（W が書く）の中で、プラグインコマンド「**部屋を開く**」（`open`）を呼ぶ。開く順は決まっていない。
  - 開いたらその部屋のスイッチ（121〜124）を ON。効果音（Open2）だけ鳴らし、文は出さない（場面の文は W が書く）。
  - 開いている部屋に二度呼んでも何もしない。
- 生き残りが来ないときの別の手（world.md 4.3 の「来ないとき」：鍋だけ残る・稽古の札を自分で読む…）も、そのイベントで同じ `open` を呼ぶ。
- 010 の崩れた扉のイベントは、1 ページ目にプラグインコマンド「**崩れた扉**」（`door`）を置く。閉じていれば「扉が崩れて、瓦礫で塞がっている。」。
  2 ページ目は出現条件がその部屋のスイッチ。開いた扉の絵で、**触れると部屋のマップへ**（011〜014）。部屋の出口で扉の前に戻る。
- 古いマップの「台座」（`pedestal`）は「崩れた扉」と同じに動く（叡智のオーブは使わない。はめる選択肢は出ない）。
- 新しい 3 部屋（療養所 016・見張り台 018・鍛冶場 017）は、この PR の外（P の後の issue）。

### W レーンが生き残りの場面に書く例
```json
[
  { "code": 101, "indent": 0, "parameters": ["", 0, 0, 2, "シャノ"] },
  { "code": 401, "indent": 0, "parameters": ["……ここ、ちょっといていい？"] },
  { "code": 357, "indent": 0, "parameters": ["Hai_Facilities", "open", "部屋を開く", { "facility": "gate" }] },
  { "code": 657, "indent": 0, "parameters": ["部屋 = gate"] },
  { "code": 0, "indent": 0, "parameters": [] }
]
```
- 「生き残りの数」（変数 103、world.md 4.4）は W のもの。このプラグインは数えない（部屋は別の手でも開くので、開いた部屋の数と生き残りの数は同じでない）。

## 魂
- 戦闘に勝つと、倒した敵 1 体につき魂 **1**。`<hai_boss>` の敵はパラメータ `bossSouls`（既定 **10**）。敵のメモ欄に `<hai_soul:5>` と書くとその数。
- 稽古場が開く前から数は増える。勝利の文「魂を N 手に入れた。」は**稽古場が開いてから**出す。
- 魂の数は `$gameSystem._hai.facilities.souls`（変数には写さない）。

## 部屋（プラグインコマンド「部屋を使う」）
| 部屋 | マップ | 調べる物 | 画面 |
|---|---|---|---|
| 稽古場 | 011 | (8,4) | `Scene_HaiSouls`：パーティの一覧。決定で魂を与えてレベルを 1 つ上げる。要る魂は「今のレベル × `soulCostRate`（既定 1）」。上限は**前に出ている仲間（戦闘に出る 4 人）の最高レベル**（`soulCapByBattle`。控えを追いつかせる部屋） |
| 食堂 | 012 | (8,3) | `Hai_Craft` の合成の画面（`Scene_HaiCraft`）をそのまま開く |
| 倉 | 013 | (8,7) | `Scene_HaiGate`：上で「引き出す／預ける」を選び、下の一覧で決定するたびに 1 つ動かす。引き出すのは袋の上限に空きがあるときだけ。預けられるのは袋のふつうのアイテム・武器・防具（大事なものは預けない） |
| 書庫 | 014 | (8,7) | `Scene_HaiLore`：倒したボス（名前と、属性・状態の「弱い／強い」）、読んだ思念・戻った記憶（薄い思念。`Hai_Thoughts.faintCount`）・メモの数。「写しの読み比べ」は名前だけ（中身は後の issue） |

- 倉が開くまでは、倉庫（`Hai_Items`）には**入るだけで取り出せない**（あふれた物は自動で倉庫へ行く。取り出す画面は倉だけ）。
- 閉じた部屋を「部屋を使う」で呼ぶと「扉が崩れて、瓦礫で塞がっている。」（ふつうは扉が塞がっているので来られない）。
- 011〜014 のマップの中の物の名前（魂の器・創作者の調理台…）は前の世界のまま。W が作り直す。

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `open`（部屋を開く） | `facility`（soul/kitchen/gate/lore） | 部屋を開き、スイッチを ON。新しく開いたときだけ効果音 |
| `door`（崩れた扉） | `door` | 閉じていれば「扉が崩れて、瓦礫で塞がっている。」。開いていれば何もしない |
| `use`（部屋を使う） | `facility` | その部屋の画面を開く |
| `pedestal`（古いマップの台座） | `door` | `door` と同じ（エディタの一覧には出ない） |

## 窓口（`window.Hai.Facilities`）
| 関数 | 戻り値・中身 |
|---|---|
| `KEYS` | `["soul", "kitchen", "gate", "lore"]`（稽古場・食堂・倉・書庫） |
| `isOpen(key)` / `opened()` / `closed()` | 開いたか / 開いた部屋の一覧（`KEYS` の順） / 閉じている部屋の一覧 |
| `open(key)` | 開く（演出なし）。新しく開いたら `true` |
| `souls()` / `addSouls(n)` / `soulsOf(enemyId)` | 魂の数 / 足す（戻り値は足した後の数） / その敵を倒して得る魂 |
| `soulCost(actorId)` / `soulCap(actorId)` / `canRaise(actorId)` / `raise(actorId)` | 稽古場：要る魂 / 上げられる上限のレベル / 上げられるか / 上げる（上げたら `true`） |
| `bosses()` / `recordBoss(enemyId)` | 倒したボスの敵 ID の一覧 / 足す |
| `loreLines(symbol)` | 書庫の右の窓に出す行（`bosses`・`thoughts`・`copies`） |
| `openScene(key)` | 部屋の画面を開く（開いているかは見ない） |
| `nameOf(key)` | 部屋の名前 |

P8 の `nextFacility`・`orbs`・`insertOrb`・`doorOf` は消した（叡智のオーブをやめたため）。

## 状態（セーブに入る）
```js
$gameSystem._hai.facilities = {
  opened: { gate: true, kitchen: true }, // 開いた部屋
  souls: 12,                             // 魂の数
  bosses: [5],                           // 倒したボスの敵 ID（倒した順）
};
```
古いセーブで無ければ、読むときに作る。そのとき**スイッチ 121〜124 が ON なら開いた扱い**にする（魂と倒したボスは 0 から）。
前の世界のセーブ（オーブで開けた部屋）も、開いた部屋はそのまま開いている。

## 試験場（Map913「T_施設」、`tools/maps/src/p8_facilities.*`）
上の壁に Map010 と同じ崩れた扉が 4 つ（左から稽古場 (3,2)・食堂 (6,2)・倉 (10,2)・書庫 (13,2)）、その 2 マス下に部屋を開く生き残り（アデル・ヴォルフラム・シャノ・イスメネ）、開始地点 (8,5)。
開いた扉に触れると本物の部屋（011〜014）へ行く。テストは `tests/p_facilities.mjs`。
