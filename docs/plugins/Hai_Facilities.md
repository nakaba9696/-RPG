# Hai_Facilities — 砦の部屋：生き残りが来たら開く（P8・P11・P13）

VISION.md 核 6「拠点と、そこで開く部屋」のためのプラグイン（#82、新しい世界に合わせたのは #134）。
部屋が開く順と条件は [docs/world.md](../world.md) 4.3（黒鉄の砦）。**叡智のオーブはやめた**。部屋は**生き残りが砦に来ると開く**。
合成は [Hai_Craft](Hai_Craft.md)、倉庫は [Hai_Items](Hai_Items.md)、控えの仲間は [Hai_Companions](Hai_Companions.md) の窓口を使う。
並びは `Hai_Companions` の後・`Hai_Comfort` の前（`js/plugins.js`・`tools/data/check.mjs` の `PLUGIN_ORDER`）。

## 部屋が開く
| 部屋 | 鍵 | マップ | 開く人（world.md 4.3） | スイッチ |
|---|---|---|---|---|
| 稽古場 | `soul` | 011 | アデル | 121 |
| 食堂 | `kitchen` | 012 | ヴォルフラム | 122 |
| 倉 | `gate` | 013 | シャノ | 123 |
| 書庫 | `lore` | 014 | イスメネ | 124 |
| 療養所 | `infirmary` | 016 | ピピネル（023） | 125 |
| 鍛冶場 | `smithy` | 017 | アンネリーゼ（061） | 126 |
| 見張り台 | `watch` | 018 | グィド（052） | 127 |

（鍵の名前 `soul` ほかは前の世界の名残り。セーブと W の既存のイベントを壊さないために変えない。）

- 生き残りが砦に来た場面のイベント（W が書く）の中で、プラグインコマンド「**部屋を開く**」（`open`）を呼ぶ。開く順は決まっていない。
  - 開いたらその部屋のスイッチ（121〜127）を ON。効果音（Open2）だけ鳴らし、文は出さない（場面の文は W が書く）。
  - 開いている部屋に二度呼んでも何もしない。
- 生き残りが来ないときの別の手（world.md 4.3 の「来ないとき」：鍋だけ残る・稽古の札を自分で読む…）も、そのイベントで同じ `open` を呼ぶ。
- 010 の崩れた扉のイベントは、1 ページ目にプラグインコマンド「**崩れた扉**」（`door`）を置く。閉じていれば「扉が崩れて、瓦礫で塞がっている。」。
  2 ページ目は出現条件がその部屋のスイッチ。開いた扉の絵で、**触れると部屋のマップへ**（011〜014・016〜018）。部屋の出口で扉の前に戻る。
- 古いマップの「台座」（`pedestal`）は「崩れた扉」と同じに動く（叡智のオーブは使わない。はめる選択肢は出ない）。
- 新しい 3 部屋（療養所 016・鍛冶場 017・見張り台 018）は P13（#189）で足した。010 の扉は療養所 (44,8)・鍛冶場 (42,36)・見張り台 (17,8)（`tools/maps/src/w6_data.mjs` の `P.doors`）、019 城壁の上の見張り台の扉 (16,6) からも 018 へ入れる（出口はどれも 010 の扉の前）。
  開く場面の `open` は、023 ピピネル・061 アンネリーゼ・052 グィドのイベント（`w8_maps.mjs` の `toFort`・`w10_data.mjs`）に足した。来ないときは開かない（world.md 4.3）。
- プラグインのパラメータ `switches`・`names` が 4 部屋の頃の値（`121,122,123,124`）のままでも、足りない分は既定（125〜127、療養所・鍛冶場・見張り台）で埋める。

### W レーンが生き残りの場面に書く例
```json
[
  { "code": 101, "indent": 0, "parameters": ["", 0, 0, 2, "シャノ"] },
  { "code": 401, "indent": 0, "parameters": ["……ここ、ちょっといていい？"] },
  { "code": 357, "indent": 0, "parameters": ["Hai_Facilities", "open", "部屋を開く", { "facility": "gate" }] },
  { "code": 657, "indent": 0, "parameters": ["部屋 = gate"] },
  { "code": 0, "indent": 0, "parameters": [] }
]
```
- 「生き残りの数」（変数 103、world.md 4.4）は W のもの。このプラグインは数えない（部屋は別の手でも開くので、開いた部屋の数と生き残りの数は同じでない）。

## 魂
- 戦闘に勝つと、倒した敵 1 体につき魂 **1**。`<hai_boss>` の敵はパラメータ `bossSouls`（既定 **10**）。敵のメモ欄に `<hai_soul:5>` と書くとその数。
- 稽古場が開く前から数は増える。勝利の文「魂を N 手に入れた。」は**稽古場が開いてから**出す。
- 魂の数は `$gameSystem._hai.facilities.souls`（変数には写さない）。

### 書庫の「写しの読み比べ」（P15 #250）
文は場面表 `docs/story/scenes/02-region2-region5.md` の 3-28・3-29 のまま。スイッチを読むだけ（立てるのは W16 の 014・121 のイベント）。
| スイッチ | 出す行 |

| どちらも OFF | 「読み比べる写しは、まだ一冊もない。」 |

### 鉄切り鋏（mapdesign.md 4 章「錆びた鉄格子」）
- アイテム 1001「鉄切り鋏」（大事なもの。`p13_data.mjs` が書く）。鍛冶場で打つ。**どこで手に入れても**（拾い屋の頭の店で買っても）、持った時点でスイッチ 313（W7 の「道具:鉄切り鋏」。026・033・091 の鉄格子が見る）を ON にする（`Game_Party.gainItem` の alias）。
- アンネリーゼが来ないとき（鍛冶場が開かない）は、W が拾い屋の頭の店（302）に 1001 を並べればよい（world.md 4.3 の「来ないとき」）。

### 鍛え直した分
- `$gameSystem._hai.facilities.forged = { "w:196": 1 }`（`w:`／`a:` と装備の ID → 回数）。`Game_Actor.paramPlus` の alias で、装備している物の分を足す。名前は変えない（一覧の右に回数を出すだけ）。

- 倉が開くまでは、倉庫（`Hai_Items`）には**入るだけで取り出せない**（あふれた物は自動で倉庫へ行く。取り出す画面は倉だけ）。
- 閉じた部屋を「部屋を使う」で呼ぶと「扉が崩れて、瓦礫で塞がっている。」（ふつうは扉が塞がっているので来られない）。
- 011〜014 のマップは W6（#144）が新しい世界の部屋に作り直した（`tools/maps/src/w6_*`。入口はどれも南の (8,12)、着く所は (8,11)）。

## 状態（セーブに入る）
```js
$gameSystem._hai.facilities = {
  opened: { gate: true, kitchen: true }, // 開いた部屋
  souls: 12,                             // 魂の数
  bosses: [5],                           // 倒したボスの敵 ID（倒した順）
  forged: { "w:196": 1 },                // 鍛え直した一点もの（P13）
};
```
古いセーブで無ければ、読むときに作る。そのとき**スイッチ 121〜127 が ON なら開いた扱い**にする（魂と倒したボスは 0 から）。P13 より前のセーブで `forged` が無ければ空で作る。
前の世界のセーブ（オーブで開けた部屋）も、開いた部屋はそのまま開いている。

## 試験場（Map913「T_施設」、`tools/maps/src/p8_facilities.*`）
上の壁に Map010 と同じ崩れた扉が 4 つ（左から稽古場 (3,2)・食堂 (6,2)・倉 (10,2)・書庫 (13,2)）、その 2 マス下に部屋を開く生き残り（アデル・ヴォルフラム・シャノ・イスメネ）、開始地点 (8,5)。
開いた扉に触れると本物の部屋（011〜014）へ行く。テストは `tests/p_facilities.mjs`（9 で書庫の写しの読み比べも見る。P15）。
