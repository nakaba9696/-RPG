# Hai_Defeat（全滅と魔石）

VISION.md の核 2「全滅したら通貨（魔石）をその場に落として拠点に戻る。戻れば拾える」のためのプラグイン（P5、#29）。
戦闘で全滅しても**ゲームオーバー画面にしない**。所持金（＝魔石）をその場に落とし、拠点へ戻る。落とした場所へ戻れば拾える。

## 全滅したとき
戦闘の終わり（`BattleManager.updateBattleEnd`）の「ゲームオーバー画面へ進む」分岐だけを置き換える。
1. 所持金の**全額**を、戦った場所（マップ ID と、戦闘を始めたときのプレイヤーの座標）に落とす。所持金は 0 になる。
2. 戦闘不能のメンバーを **HP 1** で起こし、全員の**状態異常を解く**（生きていたメンバーの HP はそのまま）。
3. 全滅した戦闘を始めたイベントを止める（「戦闘の処理」の後ろの命令は実行しない。勝ったときの命令が負けたのに流れないように）。
   コモンイベントの呼び出しの中から始めた戦闘なら、呼び出した元のイベントごと止める。
4. 画面の明るさを 0 にしたまま**拠点へ場所移動**し、全滅の文章（パラメータ。既定「ユエルの魂は牢獄の間へ引き戻された……」）と、
   落とした額の 1 行を画面の中央に出す。文章を閉じると、画面を明るくする（既定 30 フレーム）。音・演出は V に任せる（ここでは暗転だけ）。

**発動しないとき**（MZ の既定のまま）
- イベントの「戦闘の処理」で**敗北可**にした戦闘。敗北の分岐（「負けたとき」）へ進む。
- 逃げたとき、戦闘テスト。
- 戦闘の外での全滅（マップでの床ダメージ・スリップダメージ・イベントの HP 操作）。MZ の既定では床とスリップでは死なない。
  イベントの「ゲームオーバー」（353）も既定のまま。

## 落とした魔石
- `$gameSystem._hai.defeat.drop = { mapId, x, y, amount }`（セーブに入る）。
- **1 か所だけ**：新しく落とすと、前に落とした魔石は消える（取り戻せない）。所持金 0 で全滅したときは何も落とさないが、前の魔石は消える。
  パラメータ「前の魔石を残す」を ON にすると、前の分も `kept` に残り、どれも拾える。
- そのマップに入ると、落とした座標に**光る印**が出る（既定 `!Crystal` の 0 番・上向き＝紫に光る結晶。足元の高さ、すり抜け）。
  印はマップのイベントではなく、プラグインが持つキャラ（`Game_Character`）なので、マップの JSON にもセーブのマップにも入らない。
- 印のマスを**踏む**か、印の前で**決定キー（調べる）**を押すと取り戻す。所持金に額が戻り、文章「落とした魔石（N G）を取り戻した。」が出て、印が消える。
  同じマスにイベントがあって、それが始まったときは取り戻さない（イベントが終わってから、もう一度踏むか調べる）。

### 印の絵の候補（同梱の素材）
| 絵 | 番号・向き | 見た目 |
|---|---|---|
| `!Crystal` | 0・上（8） | 紫の結晶、きらめく（**既定**） |
| `!Crystal` | 0・左（4） | 赤の結晶、きらめく |
| `!Crystal` | 2・上（8） | 水色の結晶、きらめく |
| `!Crystal` | 1・上（8） | 白い結晶、きらめく |
| `!Crystal` | 4〜7・下（2） | 色つきの光の玉（赤・黄・緑・青） |
| `!Other1` | 6・下（2）ほか | 台座の上の玉（赤・黄・緑・青） |

印は足踏み（3 コマ）で光る。向きは固定。

## 拠点（戻る場所）
- プラグインコマンド **「拠点を設定」（`setHome`）**：マップ ID・X・Y・向き。マップ ID を 0 にすると、そのイベントのあるマップ。
- 窓口 `Hai.Defeat.setHome(mapId, x, y, d)` でも同じ。`$gameSystem._hai.defeat.home` に入る（セーブに入る）。
- 決めていなければ、`System.json` の開始位置（`startMapId`・`startX`・`startY`）に戻る。

### W1 が拠点を設定する手順（牢獄の間 Map010）
1. 目覚めの場面（Map010 の自動実行。スイッチ 111 を ON にする所）の最後に、プラグインコマンド「Hai_Defeat → 拠点を設定」を足す。
   マップ ID は 0（Map010）、X・Y は戻ったときに立たせたいマス（例：中央の広間の、目覚めの独房の扉の前）、向きは下。
   文字マップの `raw` イベントで書くなら：
   ```json
   { "code": 357, "indent": 0, "parameters": ["Hai_Defeat", "setHome", "拠点を設定", { "mapId": "0", "x": "16", "y": "13", "direction": "2" }] },
   { "code": 657, "indent": 0, "parameters": ["マップ ID = 0"] },
   { "code": 657, "indent": 0, "parameters": ["X = 16"] },
   { "code": 657, "indent": 0, "parameters": ["Y = 13"] },
   { "code": 657, "indent": 0, "parameters": ["向き = 下"] },
   ```
   （引数の値はすべて文字列。657 はエディタの表示用で、無くても動く。）
2. 後で拠点を移す（転送結界・別の拠点）ときも、そのイベントから同じコマンドを呼ぶ。最後に呼んだ所が戻る場所になる。
3. 戻る場所は、通れる床のマスにする（そのマスにイベントを置かない）。

## パラメータ
| 名前 | 表示名 | 既定 | 中身 |
|---|---|---|---|
| `defeatMessage` | 全滅の文章 | ユエルの魂は牢獄の間へ引き戻された…… | 拠点に戻った暗い画面で出す（複数行可。空で出さない。`\N[1]` などが使える） |
| `dropMessage` | 落とした魔石の文章 | 倒れた場所に魔石（%1 %2）を落とした。 | 全滅の文章の次の行。`%1` 額、`%2` 通貨の単位（`System.json` の `currencyUnit`）。所持金 0 なら出さない |
| `recoverMessage` | 取り戻したときの文章 | 落とした魔石（%1 %2）を取り戻した。 | 拾ったとき。空で出さない |
| `keepOld` | 前の魔石を残す | false | false：新しく落とすと前のは消える。true：前のも残る |
| `fadeInFrames` | 明るくする時間 | 30 | 全滅の文章を閉じたあと、明るくするフレーム数 |
| `markerImage` | 印の絵 | `!Crystal` | `img/characters` の絵 |
| `markerIndex` | 印の絵の番号 | 0 | 絵の中のキャラの番号（0〜7） |
| `markerDirection` | 印の絵の向き | 8 | 向きの行（2・4・6・8） |

## 他のプラグインとの関係
- **P1 `Hai_SymbolEnemy`**：シンボル敵の戦闘は「逃走可・敗北不可」なので、負けるとこのプラグインが受け持つ。
  拠点が同じマップのときは、場所移動でもマップを作り直さないので、敵は復活せずその場に残る（勝っていないので消えてもいない）。
- **P4 `Hai_Battle`**：`BattleManager.setup` を alias して `<hai_boss>` の戦闘を逃走可にする。敗北可かどうか（`_canLose`）は変えないので、
  ボス戦で全滅してもこのプラグインが受け持つ（ボスは倒れていないので残る）。P4 は `updateBattleEnd`・`processDefeat` を触らないので干渉しない。
- `js/plugins.js` での順番は P4 の後ろ（`Hai_Battle` → `Hai_Thoughts` → `Hai_Defeat`）。

## 窓口（`window.Hai.Defeat`）
| 関数 | 中身 |
|---|---|
| `drop()` | いちばん新しく落とした魔石 `{mapId, x, y, amount}`（無ければ `null`） |
| `drops()` | 拾えるすべての魔石（「前の魔石を残す」が OFF なら 0〜1 個） |
| `home()` | 戻る場所 `{mapId, x, y, d}`（未設定なら開始位置） |
| `setHome(mapId, x, y, d)` | 戻る場所を決める |
| `markers()` | 今のマップに出ている印 `[{x, y, amount}]` |
| `recover()` | いちばん新しい魔石を、その場へ行かずに取り戻す（テスト用。額を返す） |
| `isReturning()` | 全滅して拠点へ戻る途中（暗転・文章）なら `true` |
