# Hai_Notes — メモの画面と入手ログ（U1）

`Hai_Thoughts`（P3）のメモ帳を読む画面と、手に入れたものを自動でメモ帳に残す「入手ログ」。`VISION.md` 核 9「快適さ」の手がかりと施錠扉の自動メモ・入手ログ。
メモ帳の中身（形・ID）は [Hai_Thoughts.md](Hai_Thoughts.md)。地図は [Hai_AutoMap.md](Hai_AutoMap.md)。

## メモの画面
- メニューの「**メモ**」（既定の項目の並びは変えない。「地図」の後ろ）。
- 上：種類のタブ「手がかり（N）」「扉（N）」「入手（N）」「頼みごと（N）」（U4 の Hai_Lore が後ろに「遺物」を足す）。←→ で切り替えると、下の一覧がすぐ変わる。
- 一覧：その種類のメモを**新しい順**に。文字は `drawTextEx` に通す（`\I[n]`・`\C[n]` が効く）。開けた扉（`done`）は薄く、右に「開けた」。
- 決定で一覧に入り、選んでいる行の**書き留めた場所（マップの表示名 x,y）と時刻**（プレイ時間）を下の窓に出す。キャンセルでタブへ、もう一度でメニューへ。
- マップの表示名は `Hai.AutoMap.mapName`（訪れたときに覚えた表示名）。`Hai_AutoMap` が無ければエディタの名前。

## 入手ログ
- `Game_Party.gainItem`・`gainGold` を alias し、**増えたとき**に `Hai.Thoughts.addNote({ kind: "item", text })` で一行足す。
  - アイテム・武器・防具：`\I[アイコン]名前を手に入れた（マップ名）`、2 つ以上は `名前×2を手に入れた（マップ名）`。
  - 所持金（魔石）：`魔石 100Ｇを手に入れた（マップ名）`（`Ｇ` は `System.json` の通貨の単位）。
  - 戦闘の報酬・宝箱・イベントの「アイテムの増減」・P5 の魔石の取り戻しはすべて記録する。
- **記録しない**：ショップの購入・売却（`Scene_Shop.doBuy`・`doSell` の間）、装備の付け替えで戻ってきたもの（`Game_Actor.tradeItemWithParty` の間）、減ったとき、上限で増えなかったとき、マップの外（戦闘テストなど）。
  ほかのプラグインが「入手」でない増減をするときは `Hai.Notes.suspend(() => …)` で包む。
- ID は `item:<プレイ時間の秒>`（同じ秒に 2 つ目からは `#2`…）。場所はプレイヤーの座標。
- **件数**：新しいものから `maxItemLog`（既定 50）件だけ残し、古い入手ログは `Hai.Thoughts.removeNote` で消す。手がかり・扉は消さない。

## 頼みごと（P12、world.md 7.3）
生き残り・今の勢力の人の連続した用事を、一つの筋につき一行で出す。文は W がイベントのプラグインコマンドで書く（プラグインは文を持たない）。
- **頼みごとを進める**（`errand`）：`key`（筋を見分ける英数字）、`title`（筋の名前）、`who`（頼んだ人）、`stage`（段。1 から）、`text`（今の一行）、`variableId`（段を写す変数）。
  - 同じ `key` があれば書き換える。空の欄（`title`・`who`・`text`、`stage` 0、`variableId` 0）は前のまま。
  - 書くたびに、一覧のいちばん新しい所へ動き、書いた場所（マップ・座標）と時刻が変わる。終えた印は消える（やり直し）。
  - **段は下げない**（P16 #253、R2 止まる 1）：`stage` が今の段より小さいと、このコマンドは**何もしない**（段・変数・文・終えた印・並び・場所と時刻のどれも変えない）。
    文も変えないのは、小さい段の文は先の段の文より古い出来事を書いているため（074 の思念の「段 2」の文が、水門を開けた「段 3」の文を上書きしない）。
    同じ段と `stage` 0（前のまま）はこれまでどおり書ける。段を下げる筋を作りたいときは、別の `key` にするか終えてから新しく始める。
    全部の呼び出し（マップ・コモンイベント・敵グループのプラグインコマンドとスクリプト）を見て、段を下げるのを前提にした所は無かった（2026-10-13）。
    下げていたのは 074 の思念 R3-09〜11（`outsiders` 3 → 2）と、036 の営倉の鐘の綱（010 のマルゴのあとの `prisonBell` 4 → 2）。
  - `variableId` を一度書けば、それからは段を書くたびにその変数にも入る（条件分岐の「変数」で段を見られる）。
    System.json の変数 161–166 に、world.md 7.3 の 6 つの筋の名前を付けてある（使うかは W が決める）。
- **古いセーブの救い**（読み込みのとき。`Game_System.onAfterLoad`）：終わった（`done`）のに段か変数が下がったままの筋を、終わったときの段までそろえる（`DONE_STAGE`）。
  - `outsiders`：段・変数 166 を 3 に（3 未満のとき）。010 の「ミルレーネが砦に来る」（ev72、変数 166 ≧ 3）が出るようになる。
  - ほかの筋は、終わったあとに段の変数で分ける所が無いので入れていない（`prisonBell` の変数 165 は終わったあとは見られない）。
- **頼みごとを終える**（`errandEnd`）：`key`、`result`（`done` 終わった／`failed` 途切れた／`dead` 亡くなった）、`text`（最後の一行。空なら今のまま）。
  終えたときも、一覧のいちばん新しい所へ動き、場所と時刻が変わる。
- 一覧：`筋の名前：今の一行`（パラメータ「頼みごとの一行」）を新しい順に。終えた筋は薄く、右に印（亡くなったは赤）。
  一行を選ぶと、下の窓に「頼んだ人：〜　場所：〜」と時刻。
- 状態：`$gameSystem._hai.errands = { list: [{ key, title, who, stage, text, result, variableId, mapId, x, y, time, order }], order }`（セーブに入る。古いセーブで無ければ空で作る）。
  Hai_Thoughts のメモ帳には入れない（手がかりのように数が増えるものではなく、一行を書き換えるため）。
- **筋の表**（P13 #189。パラメータ `errandBook`）：world.md 7.3 の 8 本。表にある `key` なら、初めて書くときに名前・頼んだ人・変数を表から入れる（コマンドに書いた欄が勝つ）。W は `key`・`stage`・`text` だけ書けばよい。

  | key | 筋 | 頼んだ人 | 変数 |
  |---|---|---|---|
  | `brother` | 弟を連れて帰る | アンネリーゼ | 161 |
  | `summitTools` | 頂の道具 | アデル | 162 |
  | `copies` | 本物の写し | イスメネ | 163 |
  | `name` | 名を返す | 名無し | 164 |
  | `prisonBell` | 営倉の鐘を売る | マルゴ | 165 |
  | `outsiders` | 外に残された者 | ミルレーネ | 166 |
  | `doorSong` | 扉の外の歌（W9） | 村の長 | 501 |
  | `scaffold` | 足場の木（W12 が中身を書く） | テオ | 176 |

  `brother`・`copies`・`name`・`outsiders`・`doorSong` は今あるイベントの key のまま。`summitTools`・`prisonBell`・`scaffold` は P13 で決めた（まだイベントが無い）。変数 176 の名前は「頼みごと:足場の木」（`p13_data.mjs`）。
- 例（アンネリーゼの「弟を連れて帰る」）：
  1. 頼まれたとき：`errand`（key `brother`、title「弟を連れて帰る」、who「アンネリーゼ」、stage 1、text、variableId 161）
  2. 帳面を見せたとき：`errand`（key `brother`、stage 2、text）
  3. 弟が戻らなかったとき：`errandEnd`（key `brother`、result `dead`）

## パラメータ
| 名前 | 既定 | 中身 |
|---|---|---|
| `menuText` | `メモ` | メニューの項目名。空でメニューに出さない |
| `maxItemLog` | `50` | 入手ログの件数 |
| `itemFormat` | `%1を手に入れた（%2）` | 1 つ。%1 アイコンと名前、%2 マップ名 |
| `itemsFormat` | `%1×%2を手に入れた（%3）` | 2 つ以上。%2 数 |
| `goldFormat` | `魔石 %1%2を手に入れた（%3）` | 所持金。%1 数、%2 通貨の単位 |
| `errandTab` | `頼みごと` | 頼みごとの種類の名前 |
| `errandFormat` | `%1：%2` | 頼みごとの一行。%1 筋の名前、%2 今の一行、%3 頼んだ人 |
| `markDone`・`markFailed`・`markDead` | `終わった`・`途切れた`・`亡くなった` | 終えた印 |
| `errandBook` | 上の筋の表（`key:筋の名前:頼んだ人:変数` をカンマ区切り） | 頼みごとの筋の表 |

## 窓口（`window.Hai.Notes`）
| 関数 | 中身 |
|---|---|
| `open()` | メモの画面を開く |
| `logItem(item, amount)`・`logGold(amount)` | 入手ログに一行足す（ふつうは自動）。足したらそのメモ |
| `suspend(fn)` | fn の間は入手ログを記録しない |
| `itemLog()` | 入手ログ（新しい順） |
| `errand(key)` | 頼みごと（写し）。無ければ `null` |
| `errands()` | 頼みごとの一覧（書いた順の写し。`text` は一覧の一行） |
| `setErrand({ key, title, who, stage, text, variableId })`・`endErrand(key, result, text)` | プラグインコマンドと同じ |
| `CATEGORIES` | `["clue", "door", "item", "errand"]`（タブの並び） |
| `ERRANDS` / `errandBook(key)` / `stageOf(key)` | 筋の表（8 本。写し） / その 1 本（無ければ `null`） / 今の段（まだなら 0） |
| `repairErrands()` / `DONE_STAGE` | 古いセーブの段をそろえる（読み込みで自動。そろえた key の配列） / 終わったときの段の表（`{ outsiders: 3 }`） |

シーンのクラスは `window.Scene_HaiNotes`。

## Hai_Thoughts に足したもの（最小限）
- 窓口 `Hai.Thoughts.removeNote(id)`：入手ログを 50 件に詰めるため（P3 の窓口には消す手段が無かった）。
