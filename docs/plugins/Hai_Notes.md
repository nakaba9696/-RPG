# Hai_Notes — メモの画面と入手ログ（U1）

`Hai_Thoughts`（P3）のメモ帳を読む画面と、手に入れたものを自動でメモ帳に残す「入手ログ」。`VISION.md` 核 9「快適さ」の手がかりと施錠扉の自動メモ・入手ログ。
メモ帳の中身（形・ID）は [Hai_Thoughts.md](Hai_Thoughts.md)。地図は [Hai_AutoMap.md](Hai_AutoMap.md)。

## メモの画面
- メニューの「**メモ**」（既定の項目の並びは変えない。「地図」の後ろ）。
- 上：種類のタブ「手がかり（N）」「扉（N）」「入手（N）」。←→ で切り替えると、下の一覧がすぐ変わる。
- 一覧：その種類のメモを**新しい順**に。文字は `drawTextEx` に通す（`\I[n]`・`\C[n]` が効く）。開けた扉（`done`）は薄く、右に「開けた」。
- 決定で一覧に入り、選んでいる行の**書き留めた場所（マップの表示名 x,y）と時刻**（プレイ時間）を下の窓に出す。キャンセルでタブへ、もう一度でメニューへ。
- マップの表示名は `Hai.AutoMap.mapName`（訪れたときに覚えた表示名）。`Hai_AutoMap` が無ければエディタの名前。

## 入手ログ
- `Game_Party.gainItem`・`gainGold` を alias し、**増えたとき**に `Hai.Thoughts.addNote({ kind: "item", text })` で一行足す。
  - アイテム・武器・防具：`\I[アイコン]名前を手に入れた（マップ名）`、2 つ以上は `名前×2を手に入れた（マップ名）`。
  - 所持金（魔石）：`魔石 100Ｇを手に入れた（マップ名）`（`Ｇ` は `System.json` の通貨の単位）。
  - 戦闘の報酬・宝箱・イベントの「アイテムの増減」・P5 の魔石の取り戻しはすべて記録する。
- **記録しない**：ショップの購入・売却（`Scene_Shop.doBuy`・`doSell` の間）、装備の付け替えで戻ってきたもの（`Game_Actor.tradeItemWithParty` の間）、減ったとき、上限で増えなかったとき、マップの外（戦闘テストなど）。
  ほかのプラグインが「入手」でない増減をするときは `Hai.Notes.suspend(() => …)` で包む。
- ID は `item:<プレイ時間の秒>`（同じ秒に 2 つ目からは `#2`…）。場所はプレイヤーの座標。
- **件数**：新しいものから `maxItemLog`（既定 50）件だけ残し、古い入手ログは `Hai.Thoughts.removeNote` で消す。手がかり・扉は消さない。

## パラメータ
| 名前 | 既定 | 中身 |
|---|---|---|
| `menuText` | `メモ` | メニューの項目名。空でメニューに出さない |
| `maxItemLog` | `50` | 入手ログの件数 |
| `itemFormat` | `%1を手に入れた（%2）` | 1 つ。%1 アイコンと名前、%2 マップ名 |
| `itemsFormat` | `%1×%2を手に入れた（%3）` | 2 つ以上。%2 数 |
| `goldFormat` | `魔石 %1%2を手に入れた（%3）` | 所持金。%1 数、%2 通貨の単位 |

## 窓口（`window.Hai.Notes`）
| 関数 | 中身 |
|---|---|
| `open()` | メモの画面を開く |
| `logItem(item, amount)`・`logGold(amount)` | 入手ログに一行足す（ふつうは自動）。足したらそのメモ |
| `suspend(fn)` | fn の間は入手ログを記録しない |
| `itemLog()` | 入手ログ（新しい順） |
| `CATEGORIES` | `["clue", "door", "item"]`（タブの並び） |

シーンのクラスは `window.Scene_HaiNotes`。

## Hai_Thoughts に足したもの（最小限）
- 窓口 `Hai.Thoughts.removeNote(id)`：入手ログを 50 件に詰めるため（P3 の窓口には消す手段が無かった）。
