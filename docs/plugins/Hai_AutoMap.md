# Hai_AutoMap — オートマップ（U1）

プレイヤーが通った所をマップごとに覚え、地図の画面に描く。`VISION.md` 核 9「快適さ」のうちオートマップ。
メモの画面と入手ログは [Hai_Notes.md](Hai_Notes.md)。

## 開き方
- メニューの「**地図**」（`Window_MenuCommand.addOriginalCommands` に足す。既定の項目の並びは変えない。「並び替え」と「オプション」の間に入る）。
- マップの上で **M キー**（ゲームパッドは Back／View。キーの一覧は [keys.md](keys.md)）。メニューと同じ条件（メニュー禁止・イベントの最中は開かない。歩き終えてから開く）。
- 閉じる：キャンセル（Esc・X・右クリック）か M キー。

## 記録のしかた
- プレイヤーが立ったマスと、その**上下左右 1 マス**を記録する（壁ぎわを歩けば壁が描かれる）。
- 毎フレーム、プレイヤーの座標が変わったときだけ記録する（場所移動・ジャンプ・移動ルートでも同じ）。
- 状態（セーブに入る）：
  ```js
  $gameSystem._hai.automap = {
    906: { w: 32, h: 16, v: "AAAAAAAAg_D…", n: "オートマップの試験場" },
  };
  ```
  | 欄 | 中身 |
  |---|---|
  | `w`・`h` | 記録したときのマップの大きさ |
  | `v` | 通ったマスのビット列。左上から横へ `y * w + x` 番目。6 ビットを 1 文字（`A–Z a–z 0–9 - _`）にし、後ろの 0 は省く |
  | `n` | マップの表示名（ほかのマップにいてもメモの画面で名前を出すため） |
- **大きさ**：`w × h / 6` 文字が上限。32×16 で 86 文字（記録全体で 125 バイト）、**60×60 で 600 文字（700 バイトほど）**。100×100 だと 1.7KB になる（そこまで大きいマップは W レーンで作らない想定）。
- エディタでマップの大きさを変えたら、次に入ったときに座標どおり写し直す（はみ出た所は捨てる）。

## 地図の描き方
| もの | 描き方 | 決め方 |
|---|---|---|
| 床 | 明るい砂色 `#cfc6ad` | 通ったマスで、壁のタイル（A3・A4）でなく、どれかの向きに通れる |
| 壁 | 暗い灰色 `#4d4840` | 通ったマスで、上のどれでもない |
| 見つけた隠し通路 | 水色 `#4fc3f7` | リージョン 251–254 で `Hai.HiddenPassage.isFound` が真。**見つけるまでは壁**（254 の隠し階段は床）に描く |
| 残留思念 | 未読は金の丸、既読は灰色の丸 | `Hai.Thoughts.thoughts(mapId)`。**通ったマスにあるものだけ** |
| 施錠扉 | 閉じていれば橙の四角に鍵穴、開けたら灰色 | 今のマップのイベントでメモ欄に `<hai_locked>` があり、通ったマスにあるもの。開いたかはセルフスイッチ A |
| 落とした魔石 | 紫のひし形 | `Hai.Defeat.drop()`（P5）が今のマップなら、いつも描く。`Hai.Defeat` が無ければ描かない |
| プレイヤー | 赤い丸が点滅 | |
| まだ見ていないマス | 描かない（暗い板のまま） | |

- 見出し：マップの表示名と「未読の思念 N」（`Hai.Thoughts.unreadCount`、通っていない所の思念も数える）「見つけた隠し通路 N」（となり合うマスは 1 本と数える）。
- 下の段に凡例。
- **縮尺**：見出しと凡例の間の領域に収まる最大の整数（1 マス 2〜24 ピクセル）。1280×720 では 60×60 のマップで 1 マス 8 ピクセル、32×16 で 24 ピクセル。
- 地図は不透明に近い暗い板（`rgba(8,8,12,0.88)`）の上に描くので、暗い色調のマップ（V1）の上でも読める。
- 地図の画面は**今のマップだけ**を描く（ほかのマップを選んで見る画面はまだない）。

## パラメータ
| 名前 | 既定 | 中身 |
|---|---|---|
| `mapKey` | `77`（M） | 地図を開くキーのキーコード。0 で使わない |
| `mapButton` | `8`（Back／View） | ゲームパッドのボタン。-1 で使わない |
| `menuText` | `地図` | メニューの項目名。空でメニューに出さない |
| `maxTile` | `24` | 1 マスの最大のピクセル |
| `floorColor`・`wallColor`・`hiddenColor` | 上の表 | 色（CSS の色） |

## 窓口（`window.Hai.AutoMap`）
| 関数 | 中身 |
|---|---|
| `visited(mapId?)` | 通ったマスの一覧 `[{ x, y }]`（省略で今のマップ。記録の無いマップは `[]`） |
| `visitedCount(mapId?)` | 通ったマスの数 |
| `isVisited(x, y, mapId?)` | そのマスを通ったか |
| `markVisited(mapId, x, y)` | そのマス 1 つを通ったことにする（テスト用。今のマップだけ）。新しく記録したら `true` |
| `clear(mapId?)` | そのマップの記録を消す |
| `mapName(mapId?)` | マップの表示名（訪れたマップは覚えた表示名、無ければエディタの名前）。`Hai_Notes` が使う |
| `cellKind(x, y)` | 今のマップのそのマスの描き方：`"none"`・`"floor"`・`"wall"`・`"hidden"` |
| `marks()` | 今のマップの印 `[{ type: "unread"\|"read"\|"door"\|"doorOpen"\|"drop", x, y }]` |
| `foundPassages(mapId?)` | 見つけた隠し通路の数（となり合うマスは 1 本） |
| `open()` | 地図の画面を開く |

シーンのクラスは `window.Scene_HaiAutoMap`（テストは `layout()` で縮尺と置き場所を読む）。

## 中身（alias したところ）
- `Game_Player.prototype.update`：座標が変わったら記録する。
- `Game_System.prototype.onAfterLoad`・`DataManager.setupNewGame`：手元の写しを捨てる。
- `Scene_Map.prototype.updateScene`：M キーで地図の画面へ。
- `Window_MenuCommand.prototype.addOriginalCommands`・`Scene_Menu.prototype.createCommandWindow`：メニューの「地図」。
- `Input.keyMapper[77]`・`Input.gamepadMapper[8]` に `haiMap` を足す（コアの割り当てとはぶつからない）。

## 試験場
Map906「T_オートマップ」（`tools/maps/src/u1_automap.*`。暗い色調 `<hai_tone:-68,-68,-34,68>`）：
西の部屋に思念 U1a（手がかり付き）と宝箱、苔の床 (11,5) の先に見えない通路 (12–18,5)、東の部屋に宝箱（2 つ）、南の廊下に施錠扉 (17,11)（鍵はこの地図に無い）。
テストは `tests/u_automap.mjs`。
