# Hai_Thoughts — 残留思念と自動メモ（P3）

死者の残留思念（遺体・日記・壁の落書き）を調べて読む仕組みと、手がかり・施錠扉を自動で書き留めるメモ帳。
**本文はイベントの「文章の表示」（101・401）に書く。プラグインは本文を持たない**（W レーンが [docs/world.md](../world.md) 4.6 の表をそのまま写せるように）。
プラグインが持つのは「既読」と「メモ帳」だけ。メモ帳の画面は U1 が作る（P3 は画面を作らない）。

## メモ欄のタグ
| タグ | 置く所 | 中身 |
|---|---|---|
| `<hai_thought:R04>` | 残留思念のイベント | 思念の ID（`docs/world.md` 4.6 の番号。任意の文字列でよい。値を省くと `マップID,イベントID`）。ID はゲーム全体で 1 つずつ |
| `<hai_clue:テキスト>` | 残留思念のイベント | 読み終えたときメモ帳に足す一行。**1 つのイベントに何個でも**書ける（上から順に足す）。`>` は書けない |
| `<hai_locked:坑道の鍵>` | 施錠扉のイベント | 鍵の名前（メモの一行と「〜で扉を開けた。」に使う）。値を省くと `<hai_key>` のアイテムの名前 |
| `<hai_key:121>` | 施錠扉のイベント | 開ける鍵のアイテム ID（大事なもの）。鍵は使っても減らない |

### 残留思念のふるまい
- 調べると、イベントの文章がそのまま出る（`Window_Message` のまま。ページ分けもふつうの 101 で）。
- **読み終えたら**（イベントの処理が終わったら。「イベント処理の中断」で終わっても同じ）：
  - 既読にする：`$gameSystem._hai.thoughts.read[ID] = true`。
  - そのイベントの**セルフスイッチ A を ON**（2 ページ目で見た目を変えたいとき用。使わなくてよい）。
  - `<hai_clue:…>` を、まだメモ帳に無ければ足す（ID は `clue:<思念の ID>`、2 つ目からは `clue:<ID>#2`…）。
- 初めて手がかりを足すときは、本文の後に「**メモ：**（一行）」のページを足し、効果音（Book1）を鳴らす。二度目からは出ない。
- **既読の思念**をもう一度調べると、本文の 1 行目の頭に灰色の「（読んだ）」が付く。
- 文言・効果音はプラグインのパラメータで変えられる（`readMark`・`clueMessage`・`noteSe`）。

### 施錠扉のふるまい
- セルフスイッチ A が OFF の間、調べると：
  - 鍵を持っていれば：効果音（Open1）→「試験場の鍵で扉を開けた。」→ **セルフスイッチ A を ON**。扉のメモがあれば `done: true` にする。
  - 鍵がなければ：「鍵がかかっている。」と、初めてのときは「メモ：坑道の鍵が要る扉（廃坑・上層 12,5）」。
    メモ帳に `kind: "door"` の一行を足す（ID は `door:<マップID>,<イベントID>`。二度足さない）。
- 扉の 1 ページ目の list は**中身なし**でよい（プラグインが中身を作る。書いても使わない）。
- 2 ページ目（セルフスイッチ A）が開いた扉。プライオリティを「通常キャラの下」にすると通れる。
- 文言・効果音はパラメータ（`lockedMessage`・`unlockMessage`・`unlockSe`・`doorNote`）。

## W レーンが残留思念と施錠扉を置く手順（文字マップ）
設定（`tools/maps/src/<名前>.json`）の `events` に書く。見本は `tools/maps/src/p3_thoughts.txt`・`.json`（→ `data/Map904.json`）。

### 残留思念（`docs/world.md` 4.6 の 1 本を写す）
1. 表の「場所」のマスに文字を置き（地図だけの文字を `chars` に `{ "as": "." }` で足す）、`type: "text"` のイベントにする。
2. `note` に `<hai_thought:番号>` を書く。表の「手がかり」が ○ なら、本文の下の「メモ：」の「」の中を **1 つずつ** `<hai_clue:…>` にする（R10 は 2 つ）。
3. `lines` に本文を写す（1 行＝1 要素。1 ページ 4 行まで。2 ページなら配列の配列）。行の頭の「」は付けない。`\N[1]` はそのまま。
4. `image` に見た目（遺体は `Damage1`、落書き・爪痕は `!Other1` の 5 番など。持ち主がエディタで決める）。

```json
{
  "at": "b", "name": "思念 R10 脱走を企てた捕虜", "type": "text",
  "note": "<hai_thought:R10><hai_clue:地下牢の看守の箱の番号は 4・1・3><hai_clue:捕虜の寝床の下の壁が柔らかい（廃坑・下層）>",
  "image": { "characterName": "!Other1", "characterIndex": 5, "direction": 4, "pattern": 1 },
  "lines": [
    ["看守の箱の番号を盗み見た。四、一、三。", "地下牢の看守どもは、鍵を番号の箱にしまう。帝国の兵より几帳面だ。", "この穴が向こうへ抜けたら、俺たちは箱を開けて、あの廊下を抜ける。"],
    ["寝床の下の壁は、ほかより柔らかい。道具はそこに隠してある。", "もし俺が戻らなかったら、次の誰かが使え。"]
  ]
}
```
- 読んだ後に見た目を変えたいときだけ `type: "raw"` にして 2 ページ目（`"conditions": { "selfSwitchCh": "A", "selfSwitchValid": true }`）を足す。
  **2 ページ目にも同じ本文を入れる**（既読の思念を読み直せるように。「（読んだ）」はプラグインが付ける）。
- 思念のイベントは、**処理が終わると（どのページでも）既読になる**。聖女像（R05「3 回祈ったあと」）のように本文の前に条件があるものは、
  祈りを数える所を別のイベントに分け、`<hai_thought>` のイベントは本文を出すだけにする。

### 施錠扉（`docs/world.md` 4.7）
1. 壁の切れ目の床に扉の文字を置く（扉のマスは床。扉のイベントが通せんぼする）。
2. `type: "raw"` で 2 ページ：1 ページ目は扉の絵（`!Door1` の 0 番、向き 2）・「通常キャラと同じ」・中身なし、2 ページ目は A で開いた扉（向き 8）・「通常キャラの下」。
3. `note` に `<hai_locked:鍵の名前><hai_key:アイテムID>`。

```json
{
  "at": "L", "name": "施錠扉", "type": "raw", "note": "<hai_locked:坑道の鍵><hai_key:201>",
  "pages": [
    { "image": { "characterName": "!Door1", "characterIndex": 0, "direction": 2 }, "priorityType": 1, "walkAnime": false },
    { "conditions": { "selfSwitchCh": "A", "selfSwitchValid": true },
      "image": { "characterName": "!Door1", "characterIndex": 0, "direction": 8 }, "priorityType": 0, "walkAnime": false }
  ]
}
```
- 番号錠（R10 → 413）のように鍵でない仕掛けは、W がイベントで組む（数値入力 103 → 変数 → 条件分岐 111）。メモが要れば 357 で `Hai_Thoughts` の `addNote` を呼ぶ。

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `addNote` | `text`、`id`（空なら一行そのもの）、`kind`（`clue`/`door`/`item`） | メモ帳に一行足す。場所はこのイベントの座標。足したら効果音 |
| `markRead` | `id` | 思念を既読にする（演出なし） |
| `clearNotes` | なし | メモ帳を空にする（テスト用） |

## 窓口（`window.Hai.Thoughts`）— U1（オートマップ・メモ画面）が読む
| 関数 | 戻り値 |
|---|---|
| `isRead(id)` | その思念を読んだか |
| `markRead(id)` | 既読にする。新しく既読にしたら `true` |
| `notes(kind?)` | メモの一覧（写し。足した順）。`kind` を渡すとその種類だけ |
| `addNote(note)` | `{ text, id?, kind?, mapId?, x?, y? }` を足す。足したらそのメモの写し、同じ ID があれば `null`。省いた `mapId`・`x`・`y` は今のマップとプレイヤーの座標 |
| `hasNote(id)` | その ID のメモがあるか |
| `clearNotes()` | メモ帳を空にする |
| `unreadCount(mapId?)` | そのマップ（省略で今のマップ）の読んでいない思念の数。**訪れたマップだけ**分かる（訪れていないマップは 0） |
| `thoughts(mapId?)` | そのマップの思念の一覧 `[{ id, x, y, read }]`（オートマップに印を描く用。訪れていないマップは `[]`） |
| `KINDS` | `["clue", "door", "item"]` |

メモの形：
```js
{ id: "clue:R10", text: "地下牢の看守の箱の番号は 4・1・3", mapId: 27, x: 8, y: 6, kind: "clue", time: 1234 }
{ id: "door:26,5", text: "坑道の鍵が要る扉（廃坑・上層 10,8）", mapId: 26, x: 10, y: 8, kind: "door", time: 1300, done: true }
```
| 欄 | 中身 |
|---|---|
| `id` | 二度足さないための名前。思念の手がかりは `clue:<思念の ID>`（2 つ目から `#2`…）、扉は `door:<マップID>,<イベントID>` |
| `text` | 一行（制御文字 `\N[1]` などはそのまま。画面で `drawTextEx` に通す） |
| `mapId`・`x`・`y` | 書き留めた場所（思念・扉のイベントの座標） |
| `kind` | `clue`（手がかり）・`door`（施錠扉）・`item`（もの。U1・W が使う） |
| `time` | 書き留めたときのプレイ時間（秒。`$gameSystem.playtime()`） |
| `done` | 扉を開けたら `true`（扉のメモだけ。U1 が消し線や灰色にする） |

## 状態（セーブに入る）
```js
$gameSystem._hai.thoughts = {
  read: { R10: true, R13: true },
  maps: { 904: [{ id: "R13", eventId: 1, x: 3, y: 6 }, …] }, // 訪れたマップの思念（マップを読み込むたびに作り直す）
};
$gameSystem._hai.notes = [ /* 上のメモの形 */ ];
```
古いセーブで欄が無ければ、読むときに空で作る。

## 中身（alias したところ）
- `Game_Interpreter.prototype.setup`：マップのイベント（depth 0）がそのページの list で始まるとき、思念なら list を写して「（読んだ）」と「メモ：」のページを足し、
  施錠扉なら list を作る。読み終えたときの処理を `this._haiThought` に覚える。
- `Game_Interpreter.prototype.terminate`：覚えた処理（既読・セルフスイッチ A・メモ）を行う。
- `Game_Event.prototype.start`：中身のない閉じた施錠扉も始める（コアは list が空のイベントを始めない）。
- `Game_Map.prototype.setupEvents`：そのマップの思念の一覧を覚える（`unreadCount` をほかのマップから読めるように）。
