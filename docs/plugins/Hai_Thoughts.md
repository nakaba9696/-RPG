# Hai_Thoughts — 残留思念・会話できない薄い思念と自動メモ（P3・P11）

> 注：この説明の**例**（セレス・オーブ・牢獄の間・魔石・旧マップの番号など）は前の世界「灰の王国」のもの（控えは [docs/old/](../old/)）。新しい世界「最後の鐘」の設計は [docs/world.md](../world.md)。仕組みの直しは P11・P12 などの issue で行う。

死者の残留思念（遺体・日記・壁の落書き）を調べて読む仕組みと、手がかり・施錠扉を自動で書き留めるメモ帳。
新しい世界（[docs/world.md](../world.md)）では、残留思念は**主人公（墓守）にしか見えない**（6.1）。墓守の記憶は、各地の**会話できない薄い思念**にある（6.5。`<hai_faint>`、#134）。
**本文はイベントの「文章の表示」（101・401）に書く。プラグインは本文を持たない**（W レーンが world.md の表をそのまま写せるように）。
プラグインが持つのは「既読」「見た薄い思念」と「メモ帳」だけ。メモ帳の画面は U1 が作る（P3 は画面を作らない）。

## メモ欄のタグ
| タグ | 置く所 | 中身 |
|---|---|---|
| `<hai_thought:R04>` | 残留思念のイベント | 思念の ID（任意の文字列。値を省くと `マップID,イベントID`）。ID はゲーム全体で 1 つずつ |
| `<hai_faint:F01>` | 会話できない薄い思念のイベント | 思念の ID（`<hai_thought>` の代わりに書く。ID の決まりは同じ。下の「薄い思念のふるまい」） |
| `<hai_clue:テキスト>` | 残留思念のイベント | 読み終えたときメモ帳に足す一行。**1 つのイベントに何個でも**書ける（上から順に足す）。`>` は書けない |
| `<hai_locked:坑道の鍵>` | 施錠扉のイベント | 鍵の名前（メモの一行と「〜で扉を開けた。」に使う）。値を省くと `<hai_key>` のアイテムの名前 |
| `<hai_key:121>` | 施錠扉のイベント | 開ける鍵のアイテム ID（大事なもの）。鍵は使っても減らない |

### 残留思念のふるまい
- 調べると、イベントの文章がそのまま出る（`Window_Message` のまま。ページ分けもふつうの 101 で）。
- **読み終えたら**（イベントの処理が終わったら。「イベント処理の中断」で終わっても同じ）：
  - ただし、**文章の窓が一度も閉じないまま終わったときは読んでいない扱い**（P17 #257。R2 困る 5・R1 #22）。調べた瞬間に割り込まれて本文の窓を閉じる前に処理が終わると、既読・セルフスイッチ A・メモのどれも付けない。
  - 窓は**マップの上で**閉じたときだけ数える（P20 #292。R3 困る 3）。文が出ている間に戦闘に割り込まれ、本文が戦闘の画面の窓で送られて閉じたときは読んでいない扱い
    （`Window_Message.terminateMessage` で、閉じたのが `Scene_Map` かを `$gameMessage._haiClosedOnMap` に残す）。
  - 敵がぶつかったのと同じ時に調べて、思念が始まる順を待っている間に戦闘が始まったら（`BattleManager.setup`）、その思念は始めない（始まる印を消す）。
    戦闘のあとに思念が勝手に流れ、決定の押しっぱなしで送られて既読になるのを防ぐ。調べ直せば読める。
    「窓が閉じた」は、そのイベントの文章（と選択肢）の窓を閉じ終えて、次の命令に進んだとき（`Game_Interpreter.updateWaitMode` の `"message"` の待ちが解けたとき）。
  - 既読にする：`$gameSystem._hai.thoughts.read[ID] = true`。
  - そのイベントの**セルフスイッチ A を ON**（2 ページ目で見た目を変えたいとき用。使わなくてよい）。
  - `<hai_clue:…>` を、まだメモ帳に無ければ足す（ID は `clue:<思念の ID>`、2 つ目からは `clue:<ID>#2`…）。
- 初めて手がかりを足すときは、本文の後に「**メモ：**（一行）」のページを足し、効果音（Book1）を鳴らす。二度目からは出ない。
- **既読の思念**をもう一度調べると、本文を**薄く暗く**出す（P21 #327。持ち主の決定「テキストを薄っすら暗くして既読がわかるように」。印は付けない）。
  - 暗くするのは、list の**頭の地の文の並び**（indent 0 の 101/401。あいだのウェイト・音・色調・フラッシュ・揺れは越える）の文章だけ。
    最初の条件分岐・コモンイベントの呼び出し（仲間の行）・場面の命令で止める。そのあとの文章、「メモ：」の行、ほかのイベントの文章は元の明るさ。
    名前の欄は別の窓なので暗くしない。頭が条件分岐の list（鐘番の思念の 2 ページ目の 3 つ目の場面など）は暗くしない。
  - しくみ：プラグインが写した list の 101 に印 `_haiDim` を付け（マップのデータそのものには付けない）、その 101 が出した文章だけ `$gameMessage._haiDim` が立つ
    （`$gameMessage.clear` で外れる）。文章の窓はページの頭（`newPage`）でそれを見て、地の文の色を灰色にする。
  - 見せ方はパラメータで選ぶ：

    | パラメータ | 既定 | 中身 |
    |---|---|---|
    | `readStyle` | `dim` | `dim`：文を暗くする。`mark`：前と同じく 1 行目の頭に `readMark` を付ける。`both`：両方 |
    | `readDim` | `gray` | `gray`：地の文（`\C[0]`）を `readDimColor` の色で描く。色の付いた語（`\C[6]` など）はそのまま。`fade`：縁取りごと `readDimOpacity` の不透明度で描く |
    | `readDimOpacity` | `128` | `fade` のときの不透明度（0〜255） |
    | `readDimColor` | `8` | `gray` のときの文字色の番号（`\C[n]` の n。8 は明るさ 192 の灰色。白は 255） |
    | `readMark` | `\C[8]（読んだ）\C[0]` | `mark`・`both` のときだけ使う |

    `js/plugins.js` の行には `readStyle` などが無いので、既定（`dim`・`gray`）で動く。
  - 灰色を既定にした理由：半透明は黒い縁取りまで薄くなり、窓の後ろのマップの模様が字に透けて、128 では字がにじむ（170 でも縁が甘い）。
    灰色は縁取りが残って字の形がくっきりしたまま、白い字との差で既読と分かる。窓なしの薄い思念（暗い画面の上）でも同じ。
- 文言・効果音はプラグインのパラメータで変えられる（`readMark`・`clueMessage`・`noteSe`）。

### 薄い思念のふるまい（`<hai_faint>`。docs/world.md 6.5）
墓守が二度目の夜に記憶を預けた、砦の人たちの思念。話しかけても答えない。調べると、その人の目から見た**墓守のいる一場面**だけが見え、主人公の記憶が一つ戻る。
`<hai_thought>` の印だけでは「暗くして文章だけ」と「戻った記憶の数」が出せないので、**新しいタグにした**（既読・メモ・オートマップの印は残留思念と同じに数える）。
- 調べると：画面が暗くなる（色調 `faintTone`、既定 `-102,-102,-85,170`、`faintFrames` 30 フレーム）→ 本文が**窓なし・顔なし・名前なし・画面の真ん中**に出る
  （プラグインが 101 を `["", 0, 2, 1, ""]` に書き換える）→ 色調が元に戻る。
- 見終えたら（文章の窓が一度閉じてから。残留思念と同じ）：残留思念と同じく既読・セルフスイッチ A・`<hai_clue>` のメモ。**初めて見たときだけ**「戻った記憶の数」を 1 増やし、変数 138（`faintVariable`）に写す。
- もう一度調べると、同じ場面が薄く暗く出る（残留思念と同じ。コモンイベント 201 より前の本文だけ）。数は増えない。
- 「イベント処理の中断」で終わっても、色調は元に戻す（暗いまま残さない）。
- **仲間の行は名前と窓を残す**（P17 #257。R2 困る 4）：窓なし・名前なしにするのは、**コモンイベント 201（「数の一言のコモンイベント」）の呼び出しより前**の文章だけ。
  201 の後ろ（条件分岐の中でも）の文章の表示は、W が書いたまま（名前・窓・位置）で出す。033 F02・028 F03 のあとのブルーノの行がこれ。
- **会話・選択肢は置かない**。`tools/data/check.mjs` が `<hai_faint>` のイベントの選択肢（102）・数値入力（103）・アイテム選択（104）を落とす。
- 記憶が戻ったときの主人公の一言（world.md 3.5「……覚えている。この人の葬式を出した」）は、W6 のコモンイベント 201 が出す（プラグインは出さない）。
  **製品のマップの薄い思念は、本文の最後で 201 を呼ぶ**（117。`tools/data/check.mjs` が見る）。201 は初めて見たとき（セルフスイッチ A が OFF）だけ、変数 138（この思念の分はまだ数えていない）で、1 つ目・4 つ目と、**7 つ目から先で名前が戻っていない間（スイッチ 110 OFF）**に一言を出す（P13 #189・text.md 7-11）。
- **薄い思念は 11（F01〜F11）＋相棒の司祭**（world.md 6.5）。司祭は W11 が 172 に `<hai_faint:F12>` で置く。記憶の数（変数 138・書庫の「戻った記憶」）には数えるが、**201 は呼ばない**（一言は text.md 5.5 の e のあとに W11 が場面に書く。名前が戻ってスイッチ 110 が ON になる）。全部見たかは 138 が 12。
- 地の文の主語は、その人の目から見た「墓守」。主人公の正体を指さす場面にはしない（6.5）。

```json
{
  "at": "f", "name": "薄い思念 F01 墓所の番の老人", "type": "text", "note": "<hai_faint:F01>",
  "image": { "characterName": "!Flame", "characterIndex": 4, "direction": 2, "pattern": 1 },
  "lines": ["棺の前に、墓守がしゃがんで耳を寄せている。", "やがて立ち上がり、壁の外套を取って羽織った。"]

```
（見本は `tools/maps/src/p6_companions.json` の f・g → `data/Map907.json` (4,9)・(8,9)。絵は持ち主がエディタで決める。）

### 施錠扉のふるまい
- セルフスイッチ A が OFF の間、調べると：
  - 鍵を持っていれば：効果音（Open1）→「試験場の鍵で扉を開けた。」→ **セルフスイッチ A を ON**。扉のメモがあれば `done: true` にする。
  - 鍵がなければ：「鍵がかかっている。」と、初めてのときは「メモ：坑道の鍵が要る扉（廃坑・上層 12,5）」。
    メモ帳に `kind: "door"` の一行を足す（ID は `door:<マップID>,<イベントID>`。二度足さない）。
- 扉の 1 ページ目の list は**中身なし**でよい（プラグインが中身を作る。書いても使わない）。
- 2 ページ目（セルフスイッチ A）が開いた扉。プライオリティを「通常キャラの下」にすると通れる。
- 文言・効果音はパラメータ（`lockedMessage`・`unlockMessage`・`unlockSe`・`doorNote`）。

## W レーンが残留思念と施錠扉を置く手順（文字マップ）
設定（`tools/maps/src/<名前>.json`）の `events` に書く。見本は `tools/maps/src/p3_thoughts.txt`・`.json`（→ `data/Map904.json`）。

### 残留思念（world.md の表の 1 本を写す。下の例は前の世界の R10）
1. 表の「場所」のマスに文字を置き（地図だけの文字を `chars` に `{ "as": "." }` で足す）、`type: "text"` のイベントにする。
2. `note` に `<hai_thought:番号>` を書く。表の「手がかり」が ○ なら、本文の下の「メモ：」の「」の中を **1 つずつ** `<hai_clue:…>` にする（R10 は 2 つ）。
3. `lines` に本文を写す（1 行＝1 要素。1 ページ 4 行まで。2 ページなら配列の配列）。行の頭の「」は付けない。`\N[1]` はそのまま。
4. `image` に見た目（遺体は `Damage1`、落書き・爪痕は `!Other1` の 5 番など。持ち主がエディタで決める）。

```json
{
  "at": "b", "name": "思念 R10 脱走を企てた捕虜", "type": "text",
  "note": "<hai_thought:R10><hai_clue:地下牢の看守の箱の番号は 4・1・3><hai_clue:捕虜の寝床の下の壁が柔らかい（廃坑・下層）>",
  "image": { "characterName": "!Other1", "characterIndex": 5, "direction": 4, "pattern": 1 },
  "lines": [
    ["看守の箱の番号を盗み見た。四、一、三。", "地下牢の看守どもは、鍵を番号の箱にしまう。帝国の兵より几帳面だ。", "この穴が向こうへ抜けたら、俺たちは箱を開けて、あの廊下を抜ける。"],
    ["寝床の下の壁は、ほかより柔らかい。道具はそこに隠してある。", "もし俺が戻らなかったら、次の誰かが使え。"]
  ]
}
```
- 読んだ後に見た目を変えたいときだけ `type: "raw"` にして 2 ページ目（`"conditions": { "selfSwitchCh": "A", "selfSwitchValid": true }`）を足す。
  **2 ページ目にも同じ本文を入れる**（既読の思念を読み直せるように。暗くするのはプラグインがする）。
- 思念のイベントは、**処理が終わると（どのページでも。文章の窓が一度閉じていれば）既読になる**。聖女像（R05「3 回祈ったあと」）のように本文の前に条件があるものは、
  祈りを数える所を別のイベントに分け、`<hai_thought>` のイベントは本文を出すだけにする。

### 施錠扉
1. 壁の切れ目の床に扉の文字を置く（扉のマスは床。扉のイベントが通せんぼする）。
2. `type: "raw"` で 2 ページ：1 ページ目は扉の絵（`!Door1` の 0 番、向き 2）・「通常キャラと同じ」・中身なし、2 ページ目は A で開いた扉（向き 8）・「通常キャラの下」。
3. `note` に `<hai_locked:鍵の名前><hai_key:アイテムID>`。

```json
{
  "at": "L", "name": "施錠扉", "type": "raw", "note": "<hai_locked:坑道の鍵><hai_key:201>",
  "pages": [
    { "image": { "characterName": "!Door1", "characterIndex": 0, "direction": 2 }, "priorityType": 1, "walkAnime": false },
    { "conditions": { "selfSwitchCh": "A", "selfSwitchValid": true },
      "image": { "characterName": "!Door1", "characterIndex": 0, "direction": 8 }, "priorityType": 0, "walkAnime": false }
  ]
}
```
- 番号錠（R10 → 413）のように鍵でない仕掛けは、W がイベントで組む（数値入力 103 → 変数 → 条件分岐 111）。メモが要れば 357 で `Hai_Thoughts` の `addNote` を呼ぶ。

## 言い残し（P14 #230）
夜の戸で拾う言い残し（world.md 8.2・9 章、scenes/01〜03 の夜の戸、04-climax の頂の三十）。中身は**パラメータ「言い残し」の表**に持つ。
W は夜の戸のイベントで**そのスイッチを ON にするだけ**（文を二か所に書かない）。

| スイッチ | 話し手 | 一行 | 決めた所 |
|---|---|---|---|
| 314 | 木樵の女房 | 薪、三束。戸の脇に置いといたよ | W15（scenes/01 の七） |
| 413 | 焼けた村の子 | おねえちゃん、三つしか叩かなかったよ。おかあ | W16（scenes/02 の 1-11） |
| 1061 | 列に並んだ女 | 名を呼ばれて、この子が笑った。初めてだ | W16（scenes/02 の 2-14） |
| 620 | 名無し兵 | 顔は覚えている。たぶん | W17（scenes/03 の 13） |

- ON の行だけが、書庫（`Hai_Facilities`）の見出し「言い残し」に「話し手」と「一行」の 2 行ずつ、表の順に出る。拾っていなければ何も並ばない（無いことは一覧に出ないことで分かる）。
- 頂（W14）は `Hai.Thoughts.legacies()` で同じ表を読む（スクリプトで `Hai.Thoughts.legacies().some(l => l.switchId === 413)` など。条件分岐ならスイッチを直接見てもよい）。
- 行を足すときは、パラメータの表に足す（エディタのプラグイン管理で編集できる。`@type struct<Legacy>[]`）。

## 薄い思念のあとの固有の一言（P14）
パラメータ「薄い思念のあとの一言」（既定 `F09:……一つ多い`）に書いた薄い思念は、そのイベントの list の中の
**コモンイベント 201（「数の一言のコモンイベント」）の呼び出し**を、固有の一言に差し替える（scenes/03 の 20）。
- 出す形はコモンイベント 201 と同じ：初めて見たときだけ（セルフスイッチ A が OFF）、下の窓、名前は `\N[1]`（パラメータ「固有の一言の話し手」）。
- W 側は F09 の list を今のまま（最後に `117 [201]`）で置けばよい。ほかの薄い思念はコモンイベント 201 のまま。
- 思念 ID と一言は `;` で区切って増やせる（例 `F09:……一つ多い;F11:……`）。

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `addNote` | `text`、`id`（空なら一行そのもの）、`kind`（`clue`/`door`/`item`） | メモ帳に一行足す。場所はこのイベントの座標。足したら効果音 |
| `markRead` | `id` | 思念を既読にする（演出なし） |
| `faintBegin`・`faintEnd` | なし | 薄い思念の暗転と戻し（`<hai_faint>` のイベントにプラグインが自動で入れる。エディタで置かなくてよい） |
| `clearNotes` | なし | メモ帳を空にする（テスト用） |

## 窓口（`window.Hai.Thoughts`）— U1（オートマップ・メモ画面）が読む
| 関数 | 戻り値 |
|---|---|
| `isRead(id)` | その思念を読んだか |
| `markRead(id)` | 既読にする。新しく既読にしたら `true` |
| `notes(kind?)` | メモの一覧（写し。足した順）。`kind` を渡すとその種類だけ |
| `addNote(note)` | `{ text, id?, kind?, mapId?, x?, y? }` を足す。足したらそのメモの写し、同じ ID があれば `null`。省いた `mapId`・`x`・`y` は今のマップとプレイヤーの座標 |
| `hasNote(id)` | その ID のメモがあるか |
| `removeNote(id)` | その ID のメモを消す。消したら `true`（U1 の入手ログが古いものを消す用） |
| `clearNotes()` | メモ帳を空にする |
| `unreadCount(mapId?)` | そのマップ（省略で今のマップ）の読んでいない思念の数。**訪れたマップだけ**分かる（訪れていないマップは 0） |
| `thoughts(mapId?)` | そのマップの思念の一覧 `[{ id, x, y, read, faint? }]`（オートマップに印を描く用。薄い思念は `faint: true`。訪れていないマップは `[]`） |
| `isFaint(id)` | その薄い思念を見たか |
| `faintCount()` | 薄い思念を見て戻った記憶の数 |
| `markFaint(id)` | 薄い思念を見た扱いにする（演出なし。既読にもする。テスト用）。新しく数えたら `true` |
| `legacies()` | 拾った言い残し（スイッチが ON のもの）`[{ switchId, speaker, text }]`。表の順（P14） |
| `legacyTable()` | 言い残しの表のすべて `[{ switchId, speaker, text, heard }]`（P14） |
| `faintLine(id)` | その薄い思念のあとの固有の一言（無ければ `""`。P14） |
| `messageDimmed()` | 今の文章の窓が、既読の思念の文として暗く出ているか（P21。テストが読む） |
| `readStyle()` | `{ style: "dim" \| "mark" \| "both", dim: "gray" \| "fade" \| "" }`（パラメータの今の値） |
| `KINDS` | `["clue", "door", "item", "memory"]`（`memory` は P6 の記憶の断片。`Hai_Companions` が足す） |

メモの形：
```js
{ id: "clue:R10", text: "地下牢の看守の箱の番号は 4・1・3", mapId: 27, x: 8, y: 6, kind: "clue", time: 1234 }
{ id: "door:26,5", text: "坑道の鍵が要る扉（廃坑・上層 10,8）", mapId: 26, x: 10, y: 8, kind: "door", time: 1300, done: true }
```
| 欄 | 中身 |
|---|---|
| `id` | 二度足さないための名前。思念の手がかりは `clue:<思念の ID>`（2 つ目から `#2`…）、扉は `door:<マップID>,<イベントID>` |
| `text` | 一行（制御文字 `\N[1]` などはそのまま。画面で `drawTextEx` に通す） |
| `mapId`・`x`・`y` | 書き留めた場所（思念・扉のイベントの座標） |
| `kind` | `clue`（手がかり）・`door`（施錠扉）・`item`（もの。U1・W が使う） |
| `time` | 書き留めたときのプレイ時間（秒。`$gameSystem.playtime()`） |
| `done` | 扉を開けたら `true`（扉のメモだけ。U1 が消し線や灰色にする） |

## 状態（セーブに入る）
```js
$gameSystem._hai.thoughts = {
  read: { R10: true, R13: true, F01: true },
  faint: { F01: true },                          // 見た薄い思念（戻った記憶の数はこの数）
  maps: { 904: [{ id: "R13", eventId: 1, x: 3, y: 6 }, …] }, // 訪れたマップの思念（マップを読み込むたびに作り直す）
};
$gameSystem._hai.notes = [ /* 上のメモの形 */ ];
```
古いセーブで欄が無ければ、読むときに空で作る。

## 中身（alias したところ）
- `Game_Interpreter.prototype.setup`：マップのイベント（depth 0）がそのページの list で始まるとき、思念なら list を写して、既読なら本文の 101 に暗くする印（`readStyle` が `mark`・`both` なら「（読んだ）」）を付け、「メモ：」のページを足し
  （薄い思念は前後に暗転と戻しを足し、文章の窓を透明・真ん中にする。固有の一言のある思念は、コモンイベント 201 の呼び出しを一言に差し替える）、
  施錠扉なら list を作る。読み終えたときの処理を `this._haiThought` に覚える。
- `Game_Interpreter.prototype.updateWaitMode`：思念のイベントで文章の窓を待ち終えたら、覚えた処理に「見た」の印を付ける。
- `Game_Interpreter.prototype.terminate`：「見た」の印があれば、覚えた処理（既読・セルフスイッチ A・メモ・戻った記憶の数）を行う。暗いままなら色調を戻す。
- `Game_Event.prototype.start`：中身のない閉じた施錠扉も始める（コアは list が空のイベントを始めない）。
- `Game_Interpreter.prototype.command101`：印の付いた 101 が文章を出したら `$gameMessage._haiDim` を立てる。`Game_Message.prototype.clear`：それを外す。
- `Window_Message.prototype.newPage`・`resetTextColor`・`processColorChange`：`_haiDim` の文章だけ、地の文を灰色（`fade` なら縁取りごと半透明）で描く。次の文章では元に戻す。
- `Game_Map.prototype.setupEvents`：そのマップの思念の一覧を覚える（`unreadCount` をほかのマップから読めるように）。
