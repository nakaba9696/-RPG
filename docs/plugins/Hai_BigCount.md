# Hai_BigCount — 大きな数（P19）

頂の三十（場面表 [04-climax.md](../story/scenes/04-climax.md) の 5.7、章末 1 の P の表「三十の数の表示」）で、
一回ごとの数を**文章の窓でなく画面の上に大きく**出す窓口。R2 の 7 章 04:815（[2026-10-13-r2.md](../reviews/2026-10-13-r2.md)）の直し。
015 のイベントの差し替えは文7 が行う（このプラグインはデータを触らない）。

## プラグインコマンド
| コマンド | 表示名 | 引数 | 中身 |
|---|---|---|---|
| `show` | 大きな数を出す | `number`（数）・`variableId`（変数）・`text`（文字）・`duration`（出す時間）・`fadeIn`・`fadeOut`・`wait`（完了まで待つ） | 画面の上の真ん中に字を大きく出す。前の数は入れ替わる |
| `hide` | 大きな数を消す | `fadeOut`・`wait` | 出している数を消す |

- 出す字は **文字 → 変数 → 数** の順で決まる。文字が空なら、変数（0 でなければ）か数を漢数字に直して「。」を付ける（1〜99。30 → 「三十。」、31 → 「三十一。」）。
- `duration` は 0 で「消すまで残す」（次の `show` で入れ替わる）。0 より大きいと、そのフレーム数のあと `fadeOut` で消える。
- `fadeIn`・`fadeOut` は空ならパラメータの値（12・20 フレーム）。現れるときは少し大きい所から縮んで落ち着く。
- `wait` が `true` だと、現れ終わるまで（`duration` が 0 より大きいなら消え終わるまで）次の命令に進まない。
- **音は出さない。** 鐘の効果音はイベントの「SE の演奏」（250）で一回ごとに鳴らす。
- 場所移動で消える（移った先に持ち越さない）。メニューを開いて戻っても残る。状態は `$gameTemp` に持ち、セーブには入らない。

## パラメータ
| 名前 | 表示名 | 既定 | 中身 |
|---|---|---|---|
| `fontSize` | 字の大きさ | 112 | 画面の高さ 720 のときの画素。画面の高さに比例する |
| `positionY` | 高さの位置（%） | 22 | 字の中心の高さ（画面の高さに対する割合） |
| `textColor` | 字の色 | `#ffffff` | |
| `outlineColor` | 縁の色 | `rgba(0, 0, 0, 0.85)` | 頂の白い石の上でも読めるように濃くした |
| `outlineWidth` | 縁の太さ | 10 | |
| `fadeIn` / `fadeOut` | 現れ方・消え方の時間（既定） | 12 / 20 | フレーム数 |

## 見た目
- 書体は文章の窓と同じ（`$gameSystem.mainFontFace()`）。
- 位置は `Graphics.width`・`Graphics.height` に対する割合で毎フレーム決める（画面の大きさが変わってもずれない。字の大きさも高さに比例）。
- `Scene_Map` の一番手前（文章の窓・ボタンより前）に置く。画面の色調（223）は掛からない。フェードアウト（221）では一緒に暗くなる。
- 文章の窓は下（位置 2）に出すと、数と重ならない。

## 文7 が書くイベントの例（015 親鐘の綱）
今の 015 は一回ごとに「SE → 文章の表示（透明・中央）『一。』」。これを「SE → 大きな数を出す」に替える。

```
◆変数の操作：#1152 頂:綱の回数 += 1
◆SEの演奏：Bell3 (95, 80, 0)
◆プラグインコマンド：Hai_BigCount, 大きな数を出す
：　　　　　　　　　：変数 = 1152
：　　　　　　　　　：完了まで待つ = true
◆文章：なし, なし, 通常, 下
：　　：鐘が鳴る。音が、灰の払われた空へ上がっていく。
```

JSON では：
```json
{"code":122,"indent":0,"parameters":[1152,1152,1,0,1]},
{"code":250,"indent":0,"parameters":[{"name":"Bell3","volume":95,"pitch":80,"pan":0}]},
{"code":357,"indent":0,"parameters":["Hai_BigCount","show","大きな数を出す",{"number":"0","variableId":"1152","text":"","duration":"0","fadeIn":"","fadeOut":"","wait":"true"}]},
{"code":657,"indent":0,"parameters":["変数 = 1152"]},
{"code":657,"indent":0,"parameters":["完了まで待つ = true"]},
{"code":101,"indent":0,"parameters":["",0,0,2,""]},
{"code":401,"indent":0,"parameters":["鐘が鳴る。音が、灰の払われた空へ上がっていく。"]}
```

- 文の無い番（「八。」だけの番）は、`show` のあと「▶ 引く」の選択肢（今の形）を出せば、数は残ったまま次の選択を待つ。
- 「四。　五。　六。」のように続けて打つ番は、`duration` を 0 のまま `show` を 3 回（間に SE と「ウェイト」30 前後）にするか、`text` に「四。　五。　六。」と書いて 1 回で出す。
- 切り替え（011 稽古場・梁）は場所移動なので、数は消える。戻ったら次の番の `show` で出す。
- 三十のあとは `hide` で消してから 5.8 へ（`wait` を `true` にすると消え終わってから進む）。
- 二周目の早送り（`Hai.Comfort.endingSeen()`）で数だけ進める番も、`show` を `fadeIn` 0・`wait` false で打てば待たずに進む。

## 窓口（`Hai.BigCount`）
| 関数 | 中身 |
|---|---|
| `show(text, { duration, fadeIn, fadeOut })` | 字を出す（コマンドの `show` と同じ。字は直に渡す） |
| `hide(fadeOut)` | 消す |
| `text()` | 出している字（出していなければ `""`） |
| `phase()` | `"in"`・`"show"`・`"out"`・`"none"` |
| `isBusy()` | 「完了まで待つ」で待つ間か |
| `kanji(n)` | 1〜99 を漢数字に |
| `sprite()` | 今のマップの画面の絵（テスト用） |

テストは `tests/p_bigcount.mjs`。
