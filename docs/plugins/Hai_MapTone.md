# Hai_MapTone — マップごとの色調・遠景・暗がり（V1）

> 注：この説明の**例**（セレス・オーブ・牢獄の間・魔石・旧マップの番号など）は前の世界「灰の王国」のもの（控えは [docs/old/](../old/)）。新しい世界「最後の鐘」の設計は [docs/world.md](../world.md)。仕組みの直しは P11・P12 などの issue で行う。

マップのメモ欄（マップの設定の「メモ」）にタグを書くと、そのマップに入ったときに画面の雰囲気が変わる。
どの場所にどの値を付けるかの推しは [../look.md](../look.md) の 3 章。

## メモ欄のタグ
| タグ | 例 | 中身 |
|---|---|---|
| `<hai_tone:赤,緑,青,グレー>` | `<hai_tone:-68,-68,-34,68>` | 画面の色調（イベントの「画面の色調変更」と同じ値。赤・緑・青は -255〜255、グレーは 0〜255）。場所移動のフェードの間に**即時**で掛かる |
| `<hai_parallax:名前,横,縦>` | `<hai_parallax:DarkClouds,1,0>` | 遠景（`img/parallaxes` の名前）。横・縦は流れる速さ（0 で止まる。0 でない向きはループ）。マップの設定の遠景より優先 |
| `<hai_dark:半径>` / `<hai_dark:半径,濃さ>` | `<hai_dark:5>`、`<hai_dark:4,200>` | 暗がり。プレイヤーの周り（半径はマス。小数可）だけ明るく、外を黒く覆う。濃さは 0〜255（省略でパラメータ `darkOpacity`、既定 230） |

- 1 つのメモ欄に何個でも書ける（改行してよい）。
- **色調**：タグの無いマップに移ると、このプラグインが掛けた色調は `0,0,0,0` に戻る。ただし、イベントで色調を変えていた（掛けた値と今の値が違う）ときは触らない。
  同じマップの中の場所移動では掛け直さない。色調は戦闘の画面にも掛かる（コアの決まり）。
- **暗がり**：ピクチャ・タイマー・ウィンドウ（地図の名前・メニューのボタン・文章）は覆わない。戦闘には掛からない。天気（雨・雪）より上に描く。
  色調とは別の層なので、色調の上から黒く覆う。
- 仕組み：画面の 1/4 の大きさの絵（真ん中が透明な黒の放射状のぼかし）を**1 回だけ**描き、4 倍に拡大してプレイヤーの位置に置く。
  毎フレームは位置を動かすだけ（半径・濃さ・画面の大きさが変わったときだけ描き直す）。ソフトウェア描画（テストのヘッドレス Chromium）でも重くならない。

## パラメータ（プラグイン管理）
| 名前 | 表示 | 既定 | 中身 |
|---|---|---|---|
| `darkOpacity` | 暗がりの濃さ（既定） | 230 | `<hai_dark>` の 2 つ目を省いたときの、外の黒さ |
| `darkSoftness` | 明るい輪のぼかし（%） | 45 | 半径のうち外側の何 % をぼかすか。0 でくっきり、100 で中心から徐々に暗く |

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `dark`「暗がりの半径を変える」 | `radius`（マス。0 で消す） | 今いるマップの暗がりの半径を変える（灯りの道具・灯火の指輪など）。マップを出ると、メモ欄の値に戻る。セーブに入る（`$gameMap._haiDarkRadius`） |
| `darkReset`「暗がりをメモ欄の値に戻す」 | なし | |

イベントの命令では `357` に `["Hai_MapTone", "dark", "暗がりの半径を変える", {"radius": "2"}]`。

## 状態
- `$gameSystem._hai.mapTone.applied`：このプラグインが今掛けている色調（無ければ `null`）。セーブに入る。古いセーブには無いので、読むときに作る。
- `$gameMap._haiDarkRadius`：プラグインコマンドで変えた暗がりの半径（`null` ならメモ欄のまま）。マップに入るたびに `null` に戻る。

## 窓口（`window.Hai.MapTone`）
| 関数 | 中身 |
|---|---|
| `dark()` | 今のマップの暗がり `{ radius, opacity }`（無ければ `null`）。コマンドで変えた値を含む |
| `appliedTone()` | このプラグインが掛けている色調（無ければ `null`） |
| `parseTone(meta)`・`parseParallax(meta)`・`parseDark(meta)` | メモ欄（`$dataMap.meta`）からタグを読む |
| `params` | `{ darkOpacity, darkSoftness }` |

## W レーンがマップに雰囲気を付ける手順
1. [../look.md](../look.md) の 2 章でタイルセットを選び、文字マップの設定（`tools/maps/src/<名前>.json`）に `"tilesetId": 14` などと書く（A〜C がダンジョンの 11・13・14 は凡例 `dungeon` がそのまま使える）。
2. 同じ設定の `"note"` にタグを書く（3 章の推しの値から）。例：
   ```json
   "note": "<hai_tone:-85,-85,-102,68>\n<hai_dark:5>"
   ```
   エディタで付けるときは、マップの設定の「メモ」に 1 行ずつ書く。
3. 戦闘の背景をマップの設定で指定する（`"fields": { "specifyBattleback": true, "battleback1Name": "DirtCave", "battleback2Name": "DirtCave" }`）。
4. 暗がりのあるマップでは、隠し通路の手がかり（P2）を光の輪に入る所に置く（[../look.md](../look.md) の 4 章）。
5. `node tools/maps/build.mjs <名前>` で変換し、テストプレイ（`node tests/serve.mjs 8000` → `index.html?hai_test` で `__game.transfer(マップID, x, y)`）で雰囲気を見る。

試験場は Map903（`tools/maps/src/v1_look.*`）、テストは `tests/v_look.mjs`。
