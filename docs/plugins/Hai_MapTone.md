# Hai_MapTone — マップごとの色調・遠景・暗がり・霧・降る灰・門叩きの縄張り・タイルの色・白い一角・手がかりの灯り（V1・V4・V5・V6）

> 注：この説明の**例**（旧マップの番号など）は前の世界「灰の王国」のものが残っている（控えは [docs/old/](../old/)）。新しい世界「最後の鐘」の設計は [docs/world.md](../world.md)。仕組みの直しは P11・P12 などの issue で行う。

マップのメモ欄（マップの設定の「メモ」）にタグを書くと、そのマップに入ったときに画面の雰囲気が変わる。
どの場所にどの値を付けるかの推しは [../look.md](../look.md) の 3 章。

## メモ欄のタグ
| タグ | 例 | 中身 |
|---|---|---|
| `<hai_tone:赤,緑,青,グレー>` | `<hai_tone:-68,-68,-34,68>` | 画面の色調（イベントの「画面の色調変更」と同じ値。赤・緑・青は -255〜255、グレーは 0〜255）。場所移動のフェードの間に**即時**で掛かる |
| `<hai_parallax:名前,横,縦>` | `<hai_parallax:DarkClouds,1,0>` | 遠景（`img/parallaxes` の名前）。横・縦は流れる速さ（0 で止まる。0 でない向きはループ）。マップの設定の遠景より優先 |
| `<hai_dark:半径>` / `<hai_dark:半径,濃さ>` | `<hai_dark:5>`、`<hai_dark:4,200>` | 暗がり。プレイヤーの周り（半径はマス。小数可）だけ明るく、外を黒く覆う。濃さは 0〜255（省略でパラメータ `darkOpacity`、既定 230） |
| `<hai_fog:濃さ>` / `<hai_fog:濃さ,横,縦>` | `<hai_fog:120>`、`<hai_fog:150,0.2,0.02>` | 霧（V4）。画面全体に白い霧の層を重ねる。濃さは 0〜255、横・縦は流れる速さ（1 フレームの画素。省略で `0.3,0.05`）。地図に付いて動く。絵は使わない |
| `<hai_ash:強さ>` | `<hai_ash:4>` | 降る灰（V4）。灰色の粒（強さ × 10 個。強さは 1〜9）が、ゆっくり左右に揺れて落ちる。天候（雨・雪）とは別に重ねられる。絵は使わない |
| `<hai_tiletone:赤,緑,青,グレー>` | `<hai_tiletone:-17,-17,-8,136>` | 地図の**タイルだけ**の色調（V6）。値は `<hai_tone>` と同じ。人物・イベントの絵には掛からない。**タイルセットのメモ欄**に書くとそのタイルセットのマップ全部に掛かり、マップのメモ欄に書くとそのマップではそちらが優先。画面の色調はこの上からさらに掛かる |
| `<hai_pale:x,y,幅,高さ[,強さ]>` | `<hai_pale:53,27,7,9>` | 白く見せる一角（V6。マス）。縁を半マスぼかした灰白（強さ 0〜255、省略で 150）を「スクリーン」で地図のタイルに重ねる（暗い所ほど明るく、木の形は残る）。人物の下。いくつも書くときは `;` で区切る |

- 1 つのメモ欄に何個でも書ける（改行してよい）。
- **色調**：タグの無いマップに移ると、このプラグインが掛けた色調は `0,0,0,0` に戻る。ただし、イベントで色調を変えていた（掛けた値と今の値が違う）ときは触らない。
  同じマップの中の場所移動では掛け直さない。色調は戦闘の画面にも掛かる（コアの決まり）。
- **霧**：プラグインが白いぼかしの塊を並べた絵（384×384、継ぎ目なく並ぶ）を 1 回だけ描き、近い霧と遠い霧（2 倍に拡大、ゆっくり）の 2 枚にして流す。
  地図の層（`_baseSprite`）の中、地図の上に置くので**色調が掛かる**（暗い色調では灰色の霧）。天候・灰・暗がり・ピクチャより下。濃さが変わるときは 1 フレームに 4 ずつ寄る（255 から 0 まで約 1 秒）。
- **灰**：6×6 の灰色の粒の絵を 1 つ描き、強さ × 10 個の粒で使い回す。画面の下に出た粒は上に戻る。地図がスクロールすると粒も一緒に動く。天候の上、暗がりの下（暗がりのマップでは明るい輪の中だけ見える）。
- 重なりの順：地図（タイルの色調・白い一角を含む）→ 霧 → 天候 → 灰 → 暗がり → 手がかりの灯り → ピクチャ・タイマー → ウィンドウ。
- **タイルの色調**（V6）：地図の下の層・上の層（`Tilemap._lowerLayer`・`_upperLayer`）にコアの `ColorFilter` を付ける。人物は Tilemap の別の子なので掛からない。
  層は大きさ（bounds）を持たないので、フィルタの範囲（`filterArea`）を画面全体にしてある。値が変わったときだけ付け直す。
- **白い一角**（V6）：マップに入るとき（`Spriteset_Map.createTilemap`）に一角ごとに 1 枚の絵を描き、Tilemap の子（z 0.5＝下の層のタイルの上・人物の下）に置く。毎フレームは位置を動かすだけ。
- **手がかりの灯り**（V6）：暗がりのマップでは、調べられるイベントが明るい輪の外でも淡く光る。条件は「決定ボタンで始まる・今のページに絵（歩行グラフィックかタイル）がある・`<hai_enemy>` が無い・消えていない」。
  イベントのメモ欄の `<hai_glow>` で条件に合わなくても光り（絵の無いイベント＝壁の刻みなどは小さな光だけ）、`<hai_noglow>` で光らない。思念のたぐい（`<hai_thought>`・`<hai_faint>`・`<hai_memory>`・`<hai_remains>`）は青白い光でゆっくり明滅し、ほかは鈍い灯の色。
  暗がりの上の層に、イベントごとに小さな光（96×96 の放射状のぼかし。種類ごとに 1 回だけ描く）と、イベントの絵の写し（`Sprite_Character`。濃さ `glowOpacity`）を置く。
  濃さはプレイヤーとの距離で決まる：輪のぼかしの半ばより内は 0（元の絵が見える）、輪の外で 1、輪の外 `glowRange` マスを過ぎると 0 へ。画面の色調を自分で掛ける（元の絵と同じ色）。
- **門叩きの縄張り**（V5。[world.md 3.7](../world.md#37-最後の地域の山場)「その地域の色調が暗くなる」）：コマンド `lair` で地域を決めると、その地域のマップ（パラメータ `lairAreas`）に入ったとき、
  メモ欄の色調に `lairTone` を足し（タグが無ければ `0,0,0,0` に足す）、霧の濃さに `lairFog` を足す（霧の無いマップにも薄い霧が出る）。マップのメモ欄は書き換えない。
  コマンドを実行したマップがその地域なら、1 秒で暗くなる。地域は `$gameSystem` に持つのでセーブに入る。4 つ目の鐘のあとは `lairReset` で戻す。
- **暗がり**：ピクチャ・タイマー・ウィンドウ（地図の名前・メニューのボタン・文章）は覆わない。戦闘には掛からない。天気（雨・雪）より上に描く。
  色調とは別の層なので、色調の上から黒く覆う。
- 仕組み：画面の 1/4 の大きさの絵（真ん中が透明な黒の放射状のぼかし）を**1 回だけ**描き、4 倍に拡大してプレイヤーの位置に置く。
  毎フレームは位置を動かすだけ（半径・濃さ・画面の大きさが変わったときだけ描き直す）。ソフトウェア描画（テストのヘッドレス Chromium）でも重くならない。

## パラメータ（プラグイン管理）
| 名前 | 表示 | 既定 | 中身 |
|---|---|---|---|
| `darkOpacity` | 暗がりの濃さ（既定） | 230 | `<hai_dark>` の 2 つ目を省いたときの、外の黒さ |
| `darkSoftness` | 明るい輪のぼかし（%） | 45 | 半径のうち外側の何 % をぼかすか。0 でくっきり、100 で中心から徐々に暗く |
| `lairAreas` | 縄張りの地域 | `west:60-64,80-84,110-124;south:70-74,100-105;east:50-54,90-94` | 地域の名前とマップ ID の範囲（`名前:始め-終わり,…` を `;` で区切る）。west＝西の谷と麦の街道・修道院（記録院の鐘）、south＝南の水（水底の鐘）、east＝東の山（鋳物場の鐘）。推しの理由は [../look.md](../look.md) 3.4 |
| `lairTone` | 縄張りの色調の差 | `-51,-51,-34,51` | 縄張りになった地域で、メモ欄の色調に足す値 |
| `lairFog` | 縄張りの霧 | 50 | 縄張りになった地域で、霧の濃さに足す値（0 で足さない） |
| `glowOpacity` | 手がかりの灯りの濃さ | 150 | 暗がりの外で、調べられるイベントの絵を重ねる濃さ（0〜255）。0 で手がかりの灯りを出さない（V6。`js/plugins.js` には書いていないので既定の値で動く） |
| `glowRange` | 手がかりの灯りの届く距離 | 8 | 明るい輪の外、何マス先まで手がかりの灯りが見えるか（V6） |
| `ashStopSwitch` | 灰が止むスイッチ | 1165 | ON の間、どのマップの `<hai_ash>` も降らない（朝の砦。W14 が作るスイッチ。0 で使わない。P14） |

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `dark`「暗がりの半径を変える」 | `radius`（マス。0 で消す） | 今いるマップの暗がりの半径を変える（灯りの道具・灯火の指輪など）。マップを出ると、メモ欄の値に戻る。セーブに入る（`$gameMap._haiDarkRadius`） |
| `darkReset`「暗がりをメモ欄の値に戻す」 | なし | |
| `fog`「霧の濃さを変える」 | `density`（0〜255。0 で消す） | 今いるマップの霧の濃さを変える（小鐘を鳴らして霧が引く）。約 1 秒で移る。マップを出るとメモ欄の値に戻る。セーブに入る（`$gameMap._haiFogDensity`） |
| `fogReset`「霧をメモ欄の値に戻す」 | なし | |
| `ash`「降る灰の強さを変える」 | `power`（0〜9。0 で止める） | 今いるマップの灰の強さを変える（鳴らした鐘の数で薄くする）。マップを出るとメモ欄の値に戻る。セーブに入る（`$gameMap._haiAshPower`） |
| `ashReset`「降る灰をメモ欄の値に戻す」 | なし | |
| `lair`「縄張りの地域を決める」 | `area`（`west`・`south`・`east`） | 3 つ目の鐘のあと、まだ鳴っていない地域を門叩きの縄張りにする（W11 のイベントから）。その地域のマップの色調が暗くなり、霧が出る。セーブに入る（`$gameSystem._hai.mapTone.lair`） |
| `lairReset`「縄張りを消す」 | なし | 4 つ目の鐘を鳴らして門叩きが退いたとき |
| `stopAsh`「灰を止める」 | なし | 頂の三十のあと（04-climax 5.8、P14）。これから先、どのマップの `<hai_ash>` も降らない。`ash` で変えた強さも無視する。セーブに入る（`$gameSystem._hai.mapTone.ashStopped`） |
| `resumeAsh`「灰を戻す」 | なし | `stopAsh` を取り消す（試し用） |

イベントの命令では `357` に `["Hai_MapTone", "dark", "暗がりの半径を変える", {"radius": "2"}]`。

## 状態
- `$gameSystem._hai.mapTone.applied`：このプラグインが今掛けている色調（無ければ `null`）。セーブに入る。古いセーブには無いので、読むときに作る。
- `$gameSystem._hai.mapTone.lair`：縄張りになった地域の名前（無ければ `null` か無い）。セーブに入る。
- `$gameSystem._hai.mapTone.ashStopped`：「灰を止める」のあと `true`（無ければ降る）。セーブに入る。
- `$gameMap._haiDarkRadius`：プラグインコマンドで変えた暗がりの半径（`null` ならメモ欄のまま）。マップに入るたびに `null` に戻る。
- `$gameMap._haiFogDensity`・`$gameMap._haiAshPower`：プラグインコマンドで変えた霧の濃さ・灰の強さ（同上）。

## W レーンがマップに雰囲気を付ける手順
1. [../look.md](../look.md) の 2 章でタイルセットを選び、文字マップの設定（`tools/maps/src/<名前>.json`）に `"legend"` と `"tilesetId"` を書く（A〜C がダンジョンの 11・13・14・17・18・22・23 は凡例 `dungeon` がそのまま使える。24 は `highway`、25 は `monastery`）。
   地域ごとの推しは `tools/maps/looks.json`（タイルセット・凡例・メモ欄・曲・環境音・戦闘の背景）にまとめてあるので、そこから写す。
2. 同じ設定の `"note"` にタグを書く（look.md 3 章 = looks.json の推しの値から）。例：
   ```json
   "note": "<hai_tone:-85,-85,-102,68>\n<hai_dark:5>"
   ```
   エディタで付けるときは、マップの設定の「メモ」に 1 行ずつ書く。
3. 戦闘の背景をマップの設定で指定する（`"fields": { "specifyBattleback": true, "battleback1Name": "DirtCave", "battleback2Name": "DirtCave" }`）。
4. 暗がりのあるマップでは、隠し通路の手がかり（P2）を光の輪に入る所に置く（[../look.md](../look.md) の 4 章）。
5. `node tools/maps/build.mjs <名前>` で変換し、テストプレイ（`node tests/serve.mjs 8000` → `index.html?hai_test` で `__game.transfer(マップID, x, y)`）で雰囲気を見る。

試験場は Map903（`tools/maps/src/v1_look.*`）、テストは `tests/v_look.mjs`。森のタイルの色・白い林・手がかりの灯りは `tests/v_forest.mjs`（V6）。霧と灰は見本の Map916–918・920・921 と製品のマップで、縄張りは Map080・070 で `tests/v_regions.mjs` が見る。
