# Hai_Apostle（取り込んだ思いの技と「呑まれ」・呼びかけ）

[docs/world.md](../world.md) 3.1・3.7・9.2 の、主人公（墓守）が最後の地域で自分の意志で使えるようになる力（P12、#143）。
強いが、使うたびに「呑まれ」が溜まり、溜まりきると数ターン操作できない。仲間が呼びかけると減って戻る。
頂の「耐える戦い」（決まったターン数を耐えれば勝ち）は [Hai_Boss.md](Hai_Boss.md) の `<hai_endure>`。

## 技を覚える
- パラメータ「覚えるスイッチ」（既定 162）が ON の間、「技を使う者」（既定アクター 1）は「技」（既定 183）を使える。
  覚えさせる命令（スキルの増減）は要らない。スイッチを OFF に戻すと使えなくなる。
- 技はアクターの職業が持つスキルタイプで、戦闘の「技」の窓に出る（思いの刃はスキルタイプ 1。職業 10 の特徴「スキルタイプ追加 1」）。

## 呑まれ
- スキルのメモ欄 `<hai_engulf:40>` の技を戦闘で使うたびに、使った者の呑まれが 40 溜まる（最大は「呑まれの最大」、既定 100）。
- 最大になると、**その行動の終わりに**「呑まれのステート」（既定 194）が付き、戦闘ログに `message1`（「%1は呑まれた。」）。
  ステートの行動制約「敵を攻撃する」で、そのあいだ自動で敵を攻撃する（操作できない）。
- ステートがターンで切れたら、呑まれは「切れたあとの呑まれ」（既定 50）に下がる。
- 呑まれは**戦闘の頭と終わりで 0** に戻る（戦闘をまたいで持ち越さない）。
- 戦闘の画面では、技を使う者の顔の上に細いゲージ（名前「呑」、紫）で出る。覚えるスイッチが OFF で呑まれも 0 なら出さない。

## 呼びかけ
- 「呼びかけの言葉」に書いた仲間は、戦闘に出ている味方の誰かの呑まれが 0 より大きい間、アクターコマンドの最後に「呼びかける」が出る。
- 選ぶと、呑まれのいちばん多い味方に呼びかける（狙いを選ぶ手間はない）。呑まれが「呼びかけで減る量」（既定 60）だけ減り、呑まれのステートが外れる。
- 戦闘ログには、スキルの文章の代わりに「ブルーノ「あなた！」」（「呼びかけの一行」`%1「%2」`）が出る。続いてステートの `message4`（「%1は顔を上げた。」）。
- 言葉の既定は 04-climax 章末 1「呼びかけの文」（P14 で差し替え。頭は world.md 11 章の主人公の呼び方）：
  | アクター | 仲間 | 言葉 |
  |---|---|---|
  | 5 | ブルーノ | あなた！　数えてください。いち、に、さん |
  | 6 | ノラ | あんた！　あんた、顔が灰色！ |
  | 7 | ディル | あんた、読めてるか |
  | 8 | ゼリナ | あんた！　戻り |
  | 9 | アンセルモ | お前さん。わしの数え歌を。ひとつ、戸の外 |
  | 10 | ベルトラン | お前！　手が自分のじゃなくなる前に、止めろ！ |
  | 11 | トゥーラ | 兄貴！　馬鹿、戻れ！ |
- 頂の最後のターンで名前で呼ぶ（9.2）ときは、プラグインコマンド「呼びかけの言葉を変える」（`setCallWord`）で言葉を差し替える。
  言葉を空にするとパラメータの言葉に戻る。変更はセーブに入る。「ルカ」は禁止語の表（world.md 10 章）の場所の決まりを守る。

## 耐える戦いの命令（P14 #230）
頂の「夜の思い」（04-climax 5.7、world.md 9.2）のための命令。倒す戦いではなく、耐えて呼ぶ戦い。
- パラメータ「耐える戦いの命令」（`endureCommands`、既定 ON）が ON なら、**耐える戦い**（`Hai_Boss` の `<hai_endure>`）の間、
  技を使う者（主人公）の命令は「**耐える**」（防御。`endureGuardName`）と「**呼ぶ**」（`endureCallName`）の二つだけになる。数えない。
- 「呼ぶ」：連れている仲間（パーティの、生きていて呼びかけの言葉を持つ者。控えも含む）が、**隊の順に一人ずつ回って**主人公を呼ぶ。
  主人公が自分に「呼びかけのスキル」を使う形で、呑まれが「呼びかけで減る量」だけ減り、呑まれのステートが外れる。戦闘ログはその仲間の名前と言葉（「ブルーノ「あなた！　数えてください。いち、に、さん」」）。
  回る順は戦闘ごとに頭から。呼べる仲間がいなければ「呼ぶ」は薄く出て選べない。
- 仲間の側の命令はふだんのまま（呑まれが溜まれば「呼びかける」が出る）。
- 呑まれは主人公が技を使わなければ溜まらない。耐える戦いで溜めたいときは、バトルイベントのスクリプト `Hai.Apostle.addEngulf(1, 40)` で溜める。
- 試しの戦いなどで切りたいときは `Hai.Apostle.setEndureCommands(false)`（セーブに入る。`null` でパラメータに戻す）。

## 状態とセーブ
- `$gameSystem._hai.apostle = { engulf: { 1: 80 }, words: { 5: "……" }, endureCommands?: false }`。古いセーブで無ければ読むときに空で作る。
- 呑まれは戦闘の中だけの値（頭と終わりで 0）。言葉の変更だけが戦闘をまたいで残る。

## 窓口（`window.Hai.Apostle`）
| 関数 | 中身 |
|---|---|
| `isLearned()` | 覚えるスイッチが ON か |
| `engulf(actorId)` | その者の呑まれ |
| `addEngulf(actor, n)` | 呑まれを n 溜める（最大になったら、その行動の終わりにステート） |
| `isEngulfed(actor)` | 呑まれのステートが付いているか |
| `engulfCost(skill)` | そのスキルの `<hai_engulf>` の値 |
| `callWord(actorId)`・`setCallWord(actorId, word)` | 呼びかけの言葉 |
| `canCall(actor)` | その者が呼びかけられるか（言葉があり、技を使う者でない） |
| `callTarget()` | 呼びかけを受ける味方（呑まれのいちばん多い者。いなければ null） |
| `resetEngulf(actorId)` | 呑まれを 0 に（0 で全員） |
| `isEndureBattle()` | 耐える戦いの最中か（P14） |
| `nextCaller()` | 次に「呼ぶ」で呼ぶ仲間（`Game_Actor`。いなければ `null`） |
| `usesEndureCommands()`・`setEndureCommands(on)` | 耐える戦いの命令を使うか / 切り替える（`null` でパラメータに戻す） |

## W が使う手順
1. 最後の地域の山場の手前で、スイッチ 162 を ON（思いの刃を使えるようになる）。
2. 門叩きが抱えた思いの塊（3.7）・頂の「夜の思い」（9.2）は、ふつうの敵グループで作る。耐える戦いは敵のメモ欄に `<hai_endure:N>`（[Hai_Boss.md](Hai_Boss.md)）。
3. 頂の最後のターンは、敵グループのバトルイベント（ターン N）で `setCallWord` を使い、名前で呼ぶ言葉に差し替える。戦闘のあとは空に戻す。

テストは `tests/p_apostle.mjs`（P12）と `tests/p_hooks.mjs`（P14 の耐える戦いの命令）。
