# Hai_Boss（ボスの作り）

VISION.md 核 2「必須戦闘はボスだけ。ボスからも逃げられる。装備と仲間の組み合わせで、レベルを上げずに突破する道がある」と
核 7「ボスのドロップは固定」のための、**ボスだけに要る仕組み**（P7、#67）。`js/plugins/Hai_Boss.js`。

ボスは敵のメモ欄のタグで作る。ほかの仕組みは次のプラグインのものをそのまま使う。

## P4・P9 との境目
| 仕組み | どこが持つか | 中身 |
|---|---|---|
| ボスの印 `<hai_boss>` | **共通**（P4 が作ったタグ） | P4：逃走、P9：装備のドロップ、P7：名前・撃破の記録 |
| ボスから逃げられる | P4 `Hai_Battle` | `<hai_boss>` の敵がいる戦闘はいつも逃走可（P7 は作らない） |
| 行動の型（定型・確率・HP 条件・狙いの癖） | P4（MZ の行動パターン＋`<hai_target>`） | P7 は作らない。1 回ごとの行動はこの型で選ばれる |
| 耐性・耐性の穴 | P4（特徴「属性有効度」など） | P7 は**見せ方**（弱点のヒント）だけ |
| **複数行動**（固定 n 回、HP で増える） | **P7** | MZ の「行動回数追加」は確率なので、固定の回数を足した |
| **形態変化**（HP の割合で、割合を引き継ぐ） | **P7** | MZ の「敵キャラの変身」（336）は HP をそのまま（割合でない）で、条件はイベントで書く必要があった |
| **弱点のヒント**・自動メモ | **P7** | 戦闘ログに 1 行、`Hai.Thoughts` のメモに 1 行 |
| **戦闘の頭の名前** | **P7** | `<hai_boss_name>` |
| **撃破の旗**（スイッチ・記録） | **P7** | `<hai_boss_switch>`、`Hai.Boss.defeated(troopId)` |
| 固定ドロップ | P9 `Hai_Items`（`<hai_drop:…>`）か MZ の「ドロップアイテム」の確率 1/1 | P7 は作らない |
| 呼び出し（番犬・紙魚・近衛を呼ぶ） | MZ の敵グループのバトルイベント | 「敵キャラの出現」（335）。下の「W がボスを作る手順」の 4 |
| 全滅したとき | P5 `Hai_Defeat` | 「ボス戦」コマンドも「戦闘の処理」と同じく全滅の処理に乗る |

## メモ欄のタグ（敵）
| タグ | 中身 |
|---|---|
| `<hai_boss>` | ボスの印。逃走可（P4）、装備のドロップ（P9）、名前の表示・撃破の記録（P7） |
| `<hai_boss_name:看守長グラウ>` | 戦闘の頭に出す名前（出現の文章の前に 1 行、パラメータ「名前の表示」の書式）。無ければ敵の名前 |
| `<hai_actions:2>` | 1 ターンに 2 回行動（固定。特徴「行動回数追加」より優先） |
| `<hai_actions_low:3,50>` | HP 50% 以下なら 3 回行動（`<hai_actions>` より優先）。回数はターンの頭（コマンド入力の前）の HP で決まる |
| `<hai_transform:197,30>` | HP 30% 以下になった**最初の行動の終わり**に敵 197 へ形態変化。**HP の割合を引き継ぐ**。何行でも書ける（段階ごとに 1 行） |
| `<hai_weak_hint:雷>` | 雷（`System.json` の属性の名前か番号）の弱点を突かれた最初の 1 回に「〜は雷に弱いようだ。」。何行でも書ける |
| `<hai_boss_switch:151>` | 倒したらスイッチ 151 を ON。何行でも書ける |

### 形態変化
- 形態変化の段は、**戦闘の頭の敵**（第一形態）のタグと、**今の形態**のタグの両方から読む。どちらに書いてもよい。1 つの段は 1 戦闘で 1 回だけ。
- 一度に何段も下回ったら（大きなダメージで 50% と 25% を一度に越えたなど）、いちばん低い割合の段へ飛ぶ。
- 文章「〜の姿が変わった！」（パラメータ）と白く光る演出。絵（`battlerName`）・名前・能力値・耐性・行動パターンは変わった先の敵のもの。
- 形態変化の後の敵も `<hai_boss>` を持てばボスとして続く（逃走・名前・撃破の旗）。撃破の旗は第一形態と今の形態の両方の `<hai_boss_switch>` を立てる。
- `Hai.Boss.phase(enemy)` で今の形態（1 が最初）。
- 倒れた（HP 0）敵は形態変化しない。

### 弱点のヒント
- ダメージの属性の有効度がパラメータ「弱点とみなす有効度」（既定 1.5）以上で、`<hai_weak_hint>` に書いた属性のとき。通常攻撃は攻撃時属性のうち一番効くもの。
- 戦闘ログ：その戦闘で 1 回だけ（逃げてやり直すとまた出る）。
- メモ：`Hai.Thoughts` があれば `「試しの番人は雷に弱い。」`（ID `boss:<敵 ID>:<属性 ID>`、種類 `clue`）を 1 回だけ。U1 の手がかりのタブに出る。
- 分かった弱点は `Hai.Boss.knownWeak(enemyId)`（属性 ID の配列。セーブに入る）。U1・P8（理知の間）の敵の情報の材料。
- 状態異常の穴（眠りが効く・混乱が効く）のヒントはまだ無い（#71）。

## プラグインコマンド「ボス戦」（`bossBattle`）
話しかけて始める型のボス（W1 の看守長の型）に使う。

| 引数 | 中身 |
|---|---|
| 敵グループ（`troopId`） | 戦う敵グループ |
| 逃げたときのマップ・X・Y・向き | 逃げたら移す場所（控え室）。マップ 0 なら移さない |

- **逃走可・敗北不可**の「戦闘の処理」と同じ（中で `command301` を呼ぶ）。負けたら P5 の全滅の処理（魔石を落として拠点へ。イベントはそこで止まる）。
- 結果は `Hai.Boss.lastResult()`：0 勝ち／1 逃げた／2 負け。コマンドの後ろに条件分岐（スクリプト `Hai.Boss.lastResult() === 0`）を置く。
- 「戦闘の処理」（301）＋「勝ったとき／逃げたとき」の分岐で書いても同じことができる（W1 の Map035 はこちら）。どちらでもよい。

```
◆文章：試しの番人「ここより先は、試しを越えた者だけが行ける。」
◆プラグインコマンド：Hai_Boss, ボス戦（敵グループ 196、逃げたら 912 (4,3) 右向き）
◆条件分岐：スクリプト：Hai.Boss.lastResult() === 0
  ◆セルフスイッチの操作：A = ON
  ◆文章：番人は崩れ落ちた。
：それ以外のとき
  ◆文章：……逃げ出した。
：分岐終了
```

## W がボスを 1 体作る手順
`docs/world2.md` 9 章（第1段階は `docs/world.md` 4.4）の表の 1 行から作る。例は契約の番人（オーブ「契約」）。

1. **敵キャラ（W の帯）**：形態ごとに 1 つ。能力値は HP の帯（看守長 2000 を 1 とした倍率）から。
   - 耐性・耐性の穴は特徴で（`docs/plugins/Hai_Battle.md` の 3。物理軽減は「特殊能力値 物理ダメージ率」、穴は「属性有効度 200%」か「ステート有効度 150%」）。
   - **即死は効かない**：「ステート無効化（戦闘不能）」（world2.md 9 章）。
   - 行動は P4 の型（行動パターン）。「3 ターンごと」は条件「ターン」`a + 3X`、「HP 50% で強技」は条件「HP」。
2. **メモ欄**：
   | 表の欄 | タグ |
   |---|---|
   | （ボス） | `<hai_boss>`、`<hai_boss_name:契約の番人>` |
   | 行動の型「2 回行動」 | `<hai_actions:2>`（HP で増えるなら `<hai_actions_low:3,30>`） |
   | 形態変化「HP 50% で第二形態」 | 第一形態に `<hai_transform:第二形態の ID,50>` |
   | 耐性の穴（属性） | `<hai_weak_hint:炎>`（形態ごとに穴が違えば、それぞれの形態に） |
   | 撃破の旗 | `<hai_boss_switch:スイッチ>`（筋の旗。world.md 8 章・world2.md の旗の表） |
   | 固定ドロップ | 「ドロップアイテム」の確率 1/1、2 つ以上なら P9 の `<hai_drop:item,ID,1>` |

   契約の番人なら：秤の顔 `<hai_boss>` `<hai_boss_name:契約の番人>` `<hai_transform:獣の顔の ID,50>` `<hai_weak_hint:炎>`、
   獣の顔 `<hai_boss>` `<hai_actions:2>` `<hai_weak_hint:物理>` `<hai_boss_switch:…>`（第二形態の「物理 150%」は属性「物理」の有効度 1.5）。
3. **敵グループ（W の帯）**：第一形態を 1 体。名前は `W<番号>_ボス：<名前>`。
4. **呼び出し**（看守長の点呼、紙魚の王の分裂、灰の騎士の近衛）：敵グループに呼ばれる敵を「途中から出現」で置き、
   バトルイベントのページ（条件「敵キャラの HP」〜% 以下、スパン「バトル」）で「敵キャラの出現」（335）。P7 のプラグインは使わない。
   「状態の切り替え」（岩背負いの石化など、見た目が変わらないもの）は、同じページで「ステートの変更」（333）か、形態変化で別の敵にする。
5. **イベント**（ボスの部屋）：話しかけて「ボス戦」コマンド（上）か「戦闘の処理」（逃走可）。ページ 2 は撃破の旗（スイッチか セルフスイッチ A）で消える。
   逃げたら控え室へ（ボスは次の戦闘で全快している。戦闘ごとに作り直されるので何もしなくてよい）。
6. **テスト**（`tests/w_*.mjs`）：`__game.startBattle(敵グループ)` で始め、`Hai.Boss.isBoss`・`numActions()`・形態変化（敵の HP を `setHp` で割合の手前にして穴の技を当てる）・
   `Hai.Boss.defeated(敵グループ)` と撃破のスイッチを確かめる。**倒し方の手順（穴を突く装備と仲間で、上げないレベルで勝てる）**を 1 本通す（`tests/p_battle.mjs` の 5 が見本）。

## 窓口（`window.Hai.Boss`）
| 関数 | 中身 |
|---|---|
| `isBoss(enemy)` | 敵（`Game_Enemy`・敵のデータ・敵 ID）が `<hai_boss>` か |
| `defeated(troopId)` | その敵グループのボス戦に勝ったことがあるか（`<hai_boss>` の敵がいた戦闘の勝利で記録） |
| `phase(enemy)` | `Game_Enemy` の今の形態（1 が最初）。戦闘の外の値には 0 |
| `lastResult()` | 「ボス戦」コマンドの最後の結果（0 勝ち／1 逃げた／2 負け、まだなら -1） |
| `knownWeak(enemyId)` | ヒントで分かった弱点の属性 ID の配列 |
| `currentBoss()` | 今の戦闘のボス（`Game_Enemy`、いなければ `null`） |
| `actionCount(enemyId, hpRate)` | タグから決まる 1 ターンの行動の回数（タグが無ければ 0） |
| `transforms(enemyId)` | その敵の形態変化の段 `[{ from, to, rate }]` |

## パラメータ
| 名前 | 表示名 | 既定 |
|---|---|---|
| `nameFormat` | 名前の表示 | `――%1――`（空にすると出さない） |
| `transformMessage` | 形態変化の文章 | `%1の姿が変わった！` |
| `hintMessage` | 弱点のヒントの文章 | `%1は%2に弱いようだ。` |
| `hintNote` | 弱点のメモ | `%1は%2に弱い。`（空にするとメモに残さない） |
| `weakRate` | 弱点とみなす有効度 | 1.50 |

## 状態（セーブに入る）
```js
$gameSystem._hai.boss = { defeated: { 196: true }, weak: { 196: [4] }, lastResult: 0 };
```
古いセーブで無ければ、読むときに空で作る。戦闘の中の形態・ヒントを出したかは `Game_Enemy` の上（`_haiBossBase`・`_haiBossPhase`・`_haiBossDone`・`_haiBossHinted`）。

## 中身（alias したところ）
- `Game_Enemy.prototype.setup`（形態の記録の初期化）・`makeActionTimes`（複数行動）
- `BattleManager.displayStartMessages`（名前の 1 行）・`endAction`（形態変化）・`processVictory`（撃破の旗）
- `Game_Action.prototype.executeHpDamage`・`Window_BattleLog.prototype.displayActionResults`（弱点のヒント）
