# Hai_Battle（戦闘の戦術性）

VISION.md の核 7「戦術が試されるターン制バトル」のためのプラグインとデータ（P4、#21）。
MZ の既定の戦闘（ターン制、前方表示）の上に、**MZ の設定（特徴・行動パターン・TP）で表せるものは設定だけ**で作り、
足りない所だけを `js/plugins/Hai_Battle.js` で足している。

| 仕組み | どこで作っているか |
|---|---|
| SP（回復・蘇生・強技の資源） | MZ の TP を読み替え（用語）＋プラグイン（最大値・持ち越し・溜まらない） |
| 状態異常 6 種＋縛り | `States.json` 141–147 の設定だけ（プラグインなし） |
| 属性と耐性・物理軽減 | 特徴「属性有効度」「特殊能力値 物理ダメージ率」「ステート有効度／無効化」 |
| 敵の行動の型 | `Enemies.json` の行動パターン。狙いの癖だけプラグイン（`<hai_target:…>`） |
| ボスからの逃走 | プラグイン（`<hai_boss>`） |
| おまかせ | プラグイン（パーティコマンド） |
| ダメージの属性の色 | プラグイン（`Sprite_Damage` の alias） |

## 1. SP
- MZ の TP を「SP」と呼ぶ（`System.json` の `terms.basic` の 6・7 番を「ＳＰ」「SP」。`optDisplayTp` は true のまま）。MP は攻撃魔法の資源として別に残る。
- **最大値は 50**（パラメータ「SP の最大値」）。
- 味方の SP は**戦闘をまたいで持ち越す**（MZ の既定の「戦闘の頭で 0〜24 の乱数、終わりで 0」をやめる）。敵は既定どおり。
- **溜まらない**：ダメージを受けて溜まる既定（`chargeTpByDamage`）と、スキルの「得られる TP」（`applyItemUserEffect`）を切っている。
  増えるのは、アイテムの効果「TP 増加」（例：霊水）と特徴「TP 再生率」だけ。
- **全快は宿（拠点）だけ**：イベントで プラグインコマンド「SP を全快」（`Hai_Battle` の `recoverSp`、アクター 0 で全員）を使う。
  イベントの「全回復」（314）は SP に触らない（灰の泉などの全回復地点では SP は戻らない）。仲間が加わったとき（アクターの初期化）は満タン。
- 回復・蘇生の技は SP を使う（`tpCost`）。攻撃魔法は MP（`mpCost`）。

## 3. 属性と耐性
`System.json` の `elements` は持ち主の欄なので触らない。使うのは **1 物理／2 炎／3 氷／4 雷／8 光／9 闇**（5 水・6 土・7 風は使わない）。

- 耐性は特徴「属性有効度」（`code 11`）。0＝無効、0.5＝半減、2＝弱点。
- **物理軽減**は特徴「特殊能力値 物理ダメージ率」（`code 23, dataId 6`）。属性「物理」の有効度ではなく、こちらを使う
  （炎の物理技も含めて、命中タイプが「物理攻撃」のもの全部に効く）。
- 状態異常への耐性は「ステート有効度」（`code 13`、1.5 で入りやすい）と「ステート無効化」（`code 14`）。

### 装備の耐性の穴を作る規則（W レーンが装備を作るとき）
1. **防具 1 つにつき、属性の耐性（有効度 1 未満）は最大 2 属性まで。**
2. **完全無効（有効度 0）は、防具 1 つにつき 1 属性まで**（その防具の耐性の 1 つに数える）。
3. ステート無効化（`code 14`）は防具 1 つにつき 1 状態異常まで。
4. 強い耐性の防具には、別の属性の弱点（有効度 1.5）か、能力値の下げを付けてよい（穴を作るため）。
5. 物理ダメージ率は防具 1 つで 0.8（2 割減）まで。

全員が全属性・全状態異常を防げる組み合わせが作れないようにする（装飾品の枠は 1 つ）。

### 例（`Weapons.json`・`Armors.json` 141–）
| 種類 | ID | 名前 | 中身 |
|---|---|---|---|
| 武器 | 141 | 灰の杖 | 杖。攻撃時属性 炎（通常攻撃が炎になる） |
| 武器 | 142 | 霜の短剣 | 短剣。攻撃時属性 氷、攻撃時に氷 10% |
| 防具 | 141 | 沈黙除けの首輪 | 装飾品。沈黙を無効化（看守長の号令の対策） |
| 防具 | 142 | 獣革の外套 | 軽装。炎 50%・氷 50%（2 属性）。雷は防げない |
| 防具 | 143 | 雷避けの護符 | 装飾品。雷 無効（1 属性） |
| 防具 | 144 | 看守の鎖帷子 | 重装。物理ダメージ率 80%、雷 150%（弱点）、敏捷性 −2 |

## 4. 敵の行動の型
MZ の行動パターン（`Enemies.json` の `actions`）で書く。行動の選び方（MZ の既定）：
条件を満たす行動のうち、**一番高いレーティング −3 より大きいもの**だけが候補になり、`レーティング −（最高 −3）` の重みで乱数で選ぶ。
だから「レーティングを 4 以上離す」と、高いほうだけを必ず使う。

| 型 | 書き方 | 例 |
|---|---|---|
| 定型（順番） | 条件「ターン」 `a + b × X`。1 ターン目が 1（`conditionType 1, param1 a, param2 b`）。b を同じにして a をずらす | 141 獄卒：`1+3X` 防御 → `2+3X` 眠りの棍棒 → `3+3X` 攻撃 |
| 確率 | 条件なしの行動を並べ、レーティングで重みを付ける | 142 胞子茸：攻撃 5・毒の一撃 5・惑わしの囁き 4（重み 3:3:2） |
| HP 条件 | 条件「HP」`0〜0.5`（`conditionType 2, param1 0, param2 0.5`）。レーティングを 4 以上高くすると必ず使う | 143 骨の番人：HP 50% 以下で渾身の一撃（9） |
| ターゲット癖 | 敵のメモ欄（プラグイン）。下の表 | 144 夜狩りの犬：`<hai_target:lowest>`、145 怒れる囚人：`<hai_target:taunt>` |
| 属性 | 特徴で耐性と弱点 | 146 霜の亡霊：氷 無効、炎 200% |

### ターゲット癖（メモ欄）
| タグ | 意味 |
|---|---|
| `<hai_target:lowest>` | 味方のうち、HP（実数）が最も低い者を狙う |
| `<hai_target:taunt>` | 狙われ率（特徴「狙われ率」。ステート 20 挑発など）が最も高い者を**必ず**狙う |
| （なし） | MZ の既定：狙われ率の重みで乱数 |

効くのは「敵単体」の技だけ（全体・ランダムの技、混乱しているときは既定どおり）。

## 5. ボス「看守長グラウ」（`Enemies.json` 161、`Troops.json` 161）
`docs/world.md` 4.4 の看守長。形態変化（HP 50% の点呼、25% の狂乱）とドロップは P7・W2 で足す。ここでは行動の型と耐性だけ。

| 項目 | 中身 |
|---|---|
| 能力値 | HP 2400、攻撃 45、防御 30、魔力 30、魔防 25、敏捷 30 |
| 耐性 | 物理ダメージ率 50%、雷 無効、毒 無効 |
| 穴 | **炎 200%**、**眠り 150%**（入りやすい） |
| 行動 | ① 鉄鞭（5）か鎖縛り（5、縛り 2 ターン）② `3+3X` ターンに更生の号令（9、全体に小ダメージ＋沈黙 80%）③ HP 50% 以下で懲罰の鎖（7。①より 3 倍選ばれやすい） |
| メモ欄 | `<hai_boss>`（逃げられる） |

倒し方の手順（`tests/p_battle.mjs` の 5 で通している）：沈黙除けの首輪を付けた術者が灰火（炎 200%）を当て続ける → 号令の沈黙は首輪で防ぐ →
眠り香（アイテムなので沈黙中も使える）で眠らせて 1 ターン止める → 凍てつく霧で凍らせ、凍っている間に物理で殴る（物理 50% × 氷 150%）。

## 6. 逃走
- 敵のメモ欄に `<hai_boss>` がある敵が 1 体でもいる戦闘は、「戦闘の処理」で逃走不可にしてあっても**逃げられる**（パラメータ「ボスから逃げられる」）。
  `Troops.json` にはメモ欄が無いので、印は敵の側に付ける。
- 成功率は MZ の既定（`0.5 × 味方の平均敏捷 ÷ 敵の平均敏捷`、失敗ごとに +0.1）。失敗すると敵の 1 ターン。
- 逃げたあとの扱い（ボスの HP の全快、控え室へ戻す）は、ボスのイベントの「逃げたとき」で書く（W2）。

## 7. おまかせ
- パーティコマンドの一番下（「戦う」「逃げる」の次）に「おまかせ」。選ぶと、入力できる味方全員が「攻撃」（狙いは乱数）を選び、ターンが進む。次のターンも続く。
- おまかせの間は画面の下に「おまかせ中　決定／キャンセルで止める」。決定・キャンセル（タッチの右クリック）を押すと、**次のターンの頭で**止まり、パーティコマンドに戻る。
- ターン制（`battleSystem` 0）だけ。タイムプログレスでは出さない。

## 8. ダメージの属性の色
ダメージの数字（HP が減るもの）を、属性で色分けする。回復・ミス・MP は MZ の既定の色。通常攻撃は攻撃時属性のうち一番効くもの。

| 属性 | 色 |
|---|---|
| 2 炎 | 赤 `#ff5a3c` |
| 3 氷 | 水色 `#7fdcff` |
| 4 雷 | 黄 `#ffe23c` |
| 8 光 | 白 `#ffffff`（既定のダメージの色も白なので、見分けは付かない） |
| 9 闇 | 紫 `#c07cff` |
| ほか（物理・属性なし） | MZ の既定（白） |

パラメータ「属性の色」（`2:#ff5a3c,3:#7fdcff,…`）で変えられる。

## 10. W レーンが敵・装備・技を作るとき
- 状態異常は 141–147 を使う（MZ の既定の 4 毒・10 睡眠などは使わない）。付ける技の効果は「ステート付加」、成功率は 0.3〜0.8。
- ザコの技の命中タイプ：物理技は「物理攻撃」、ブレス・号令などは「必中」、魔法・歌は「魔法攻撃」。
- 回復・蘇生の技は SP（`tpCost`）。攻撃魔法は MP。技の「得られる TP」は効かない（0 にしておく）。
- 敵の行動：上の 4 の型から選ぶ。ボスは `<hai_boss>`、耐性の穴を最低 1 つ（属性 200% か状態異常 150%）。
- 装備：3 の規則（耐性 2 属性まで・無効 1 つまで）。
- 敵の狙いの癖は `<hai_target:lowest>`・`<hai_target:taunt>`。
- 拠点の宿のイベント：「全回復」（314）＋ プラグインコマンド「SP を全快」（357 `["Hai_Battle","recoverSp","SP を全快",{"actorId":"0"}]`）。

## 窓口（`window.Hai.Battle`）
| 関数 | 返すもの |
|---|---|
| `params` | `{ maxSp, chargeByDamage, chargeByAction, bossEscape, autoCommand, elementColors }` |
| `isBossTroop()` | 今の敵グループに `<hai_boss>` の敵がいるか |
| `targetHabit(enemy)` | その敵の狙いの癖（`"lowest"`・`"taunt"`・`""`） |
| `pickTarget(habit, unit)` | 癖で選んだ相手（癖が無ければ `null`） |
| `recoverSp(actorId)` | SP を全快（0 でパーティ全員） |
| `isAuto()` / `setAuto(on)` | おまかせ中か / 切り替え |
| `elementColor(elementId)` | その属性の色（無ければ `null`） |

## パラメータ
| 名前 | 表示名 | 既定 |
|---|---|---|
| `maxSp` | SP の最大値 | 50 |
| `chargeByDamage` | ダメージで SP が溜まる | false |
| `chargeByAction` | 技で SP が溜まる | false |
| `bossEscape` | ボスから逃げられる | true |
| `autoCommand` | おまかせの名前 | おまかせ |
| `autoHelp` | おまかせ中の表示 | おまかせ中　決定／キャンセルで止める |
| `elementColors` | 属性の色 | `2:#ff5a3c,3:#7fdcff,4:#ffe23c,8:#ffffff,9:#c07cff` |

## 状態とセーブ
- SP は MZ の TP（`Game_Battler._tp`）のままなのでセーブに入る。おまかせは戦闘の間だけ（`BattleManager._haiAuto`、セーブに入らない）。
- `$gameSystem._hai` は使っていない。
