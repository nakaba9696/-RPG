# Hai_Warp — セーブ地点の結界と転送（U3）

> 注：この説明の**例**（セレス・オーブ・牢獄の間・魔石・旧マップの番号など）は前の世界「灰の王国」のもの（控えは [docs/old/](../old/)）。新しい世界「最後の鐘」の設計は [docs/world.md](../world.md)。仕組みの直しは P11・P12 などの issue で行う。

`VISION.md` 核 9「快適さ」の**セーブ地点間の転送結界**。結界に触れると覚え、調べると「休む／記録する／転送する／やめる」。

## メモ欄のタグ
| タグ | 置く所 | 中身 |
|---|---|---|
| `<hai_warp:名前>` | 結界のイベント | 結界の名前（転送の一覧とメモに出る）。値を省く（`<hai_warp>`）とイベントの名前 |

## ふるまい
### 触れる
- 結界に向かって**歩いてぶつかる**（トリガーが「決定ボタン」で、プライオリティが「通常キャラと同じ」とき）と、その結界を「訪れた」として覚える。
  トリガーを「プレイヤーから接触」にした結界は、ぶつかる・踏むで同じことが起きる。
- 初めてのときだけ、効果音（`Saint3`）と「西の結界に触れた。転送の行き先に加わった。」を出す。
  **自動メモ**（P3 `Hai.Thoughts`）があれば、メモ帳に「西の結界（結界の試験場）」の 1 行を足す（ID `warp:<マップID>,<イベントID>`、種類 `clue`）。
- 二度目からは何も出ない。

### 調べる（決定ボタン・タッチ）
訪れたことにしたうえで（初めてなら上の文章を先に出す）、文章「西の結界が静かに光っている。」と選択肢を出す。
| 選択肢 | 中身 |
|---|---|
| 休む | 効果音（`Recovery`）、全員を全回復（314）、「結界の光に包まれ、傷と疲れが癒えた。」 |
| 記録する | セーブ画面（352。`SceneManager.push(Scene_Save)`） |
| 転送する | 「どこへ転送する？」と行き先の一覧（`Window_ChoiceList`＝`Window_Command`）。選ぶと効果音（`Teleport`）と場所移動（暗転） |
| やめる | 閉じる（キャンセルでも同じ） |

- **行き先が無い**（ほかに訪れた結界が無く、拠点も決まっていない）ときは「転送する」を出さず、文章に「まだ他の結界を知らない。」を足す。
- 行き先の一覧は**拠点**（下）が先頭、続けて訪れた順。**いまの結界は除く**。8 つを超えるとスクロール。
- 転送先は結界のイベントの **1 マス下**（下を向いて立つ）。下のマスから結界へ歩けないとき（壁・壁の上面・置物）は**結界の位置**に立つ。
- イベントの 1 ページ目に命令があれば、それを先に流してから選択肢を出す（調べたときだけ。触れたときは流さない）。

### 拠点
- P5 `Hai_Defeat` の拠点（プラグインコマンド「拠点を設定」・`Hai.Defeat.setHome`）が**決まっていれば**、一覧の先頭に「牢獄の間」（パラメータ `homeName`）を**常に**出す（結界を訪れていなくても）。
  行き先は拠点の座標そのもの（1 マス下にはずらさない）。
- 拠点と同じ名前（`<hai_warp:牢獄の間>`）の結界は、一覧に重ねて出さない。
- 拠点のマップの結界から開いたときは、拠点を出さない（いまの所なので）。
- 拠点が決まっていない（`System.json` の開始位置に戻る状態）ときは出さない。

### セーブ
メニューからのセーブは **MZ の既定のまま（どこでもできる）**。結界・書見台の「記録する」はセーブ画面を開くだけ。
「どこでもセーブを止めるか」は持ち主の判断待ち（#59。推し：止めない。結界は回復と転送の価値で差を付ける）。

## プラグインコマンド
| コマンド | 表示名 | 中身 |
|---|---|---|
| `open` | 結界を開く | このイベントで選択肢を出す。`<hai_warp>` のイベントなら訪れたことにもする。結界でないイベント（記録の書見台など）から呼ぶと、イベントの名前で選択肢を出す（訪れたことにはしない） |
| `saveRecord` | 記録を作る | 引数 `label`（既定「朝の砦」）。今の状態を記録として自動で書く（P14。下の「記録を作る」） |

`<hai_warp>` のイベントの中身から「結界を開く」を呼んだときは、プラグインが足す選択肢は出さない（二重にしない）。
選択肢の前に台詞を入れたいときなどに使う。

## W が結界を置く手順（文字マップ）
1. 結界のマスに文字を置き（地図だけの文字を `chars` に `{ "as": "." }` で足す）、`type: "raw"` のイベントにする。
2. `note` に `<hai_warp:名前>`。名前は転送の一覧に出るので、場所の分かる短い名前にする（「坑道の入口」など）。
3. ページは 1 枚：絵（下の候補）、プライオリティ「通常キャラと同じ」、トリガー「決定ボタン」、中身なし。足踏み（`stepAnime`）で光らせる。
4. 結界の**下のマスは通れる床**にする（転送で着く所）。下が壁なら結界の位置に立つ（動けるが、見た目が重なる）。

```json
{
  "at": "W", "name": "坑道の入口の結界", "type": "raw", "note": "<hai_warp:坑道の入口>",
  "pages": [{ "image": { "characterName": "!Crystal", "characterIndex": 1, "direction": 8 },
              "priorityType": 1, "stepAnime": true, "directionFix": true, "trigger": 0 }]
}
```
- 拠点（牢獄の間 Map010）にも 1 つ置く：`<hai_warp:牢獄の間>`（W2 以降。old/world.md 3.2 の広間）。灰の泉・記録の書見台とは別のイベント。
- 帰りの転送陣（old/world.md 4.4。オーブの間 → 牢獄の間の広間）は結界ではなく、W が場所移動（201）で作る。

### 絵の候補（同梱の素材）
| 絵 | 番号・向き | 見た目 |
|---|---|---|
| `!Crystal` | 1・上（8） | 白い結晶、きらめく（**試験場で使用**。白い結界に合わせた） |
| `!Crystal` | 2・上（8） | 水色の結晶 |
| `!Other1` | 6・下（2）ほか | 台座の上の玉 |
P5 の魔石の印（`!Crystal` 0・上＝紫）とは色を変える。

## 記録を作る（P14 #230。朝の砦）
結末のイベント（W14、010 の後日談）から `saveRecord` を呼ぶと、記録「朝の砦」を自動で作る（04-climax 章末 1）。
- **書く枠**：空いている枠（オートセーブの枠 0 は使わない）。空きが無ければ、**いちばん新しい記録を除いた**いちばん古い枠。
  頂の手前で遊ぶ人が作った記録は、いちばん新しい記録なので上書きしない。
- 記録の一覧では「ファイル N」の横に「記録の名前の形」（既定 `「%1」`）で名前が出る（`DataManager` の記録の情報に `haiLabel` を足す。その枠にふつうに記録し直すと消える）。
- ロードすると、**コマンドの次の命令から**続く（中身を写す間だけ、実行中のイベントが次の命令を指す。記録を作り直さない）。
- 書くのは非同期（`DataManager.saveGame`）。イベントは待たずに進む（中身はコマンドの時点で写してある）。

## パラメータ
| 名前 | 表示名 | 既定 |
|---|---|---|
| `homeName` | 拠点の名前 | 牢獄の間 |
| `visitMessage` | 初めて触れたときの文章（`%1` 名前。空で出さない） | %1に触れた。転送の行き先に加わった。 |
| `menuMessage` | 調べたときの文章（`%1` 名前） | %1が静かに光っている。 |
| `noDestMessage` | 行き先が無いときの文章 | まだ他の結界を知らない。 |
| `warpMessage` | 転送先を選ぶときの文章 | どこへ転送する？ |
| `restMessage` | 休んだときの文章（空で出さない） | 結界の光に包まれ、傷と疲れが癒えた。 |
| `restText`・`saveText`・`warpText`・`cancelText` | 選択肢 | 休む・記録する・転送する・やめる |
| `noteFormat` | メモの一行（`%1` 名前、`%2` マップの表示名） | %1（%2） |
| `visitSe`・`restSe`・`warpSe` | 効果音 | Saint3・Recovery・Teleport |
| `recordFormat` | 記録の名前の形（`%1` 名前） | 「%1」 |

## 状態（セーブに入る）
```js
$gameSystem._hai.warp = {
  visited: [{ mapId: 909, eventId: 1, x: 4, y: 3, name: "西の結界" }, …], // 訪れた順
};
```
古いセーブに無ければ読むときに空で作る。いま選択肢を出している結界（一覧から除く所）と、転送の着地の調整は `$gameTemp` に置く（セーブに入らない）。

## 窓口（`window.Hai.Warp`）
| 関数 | 中身 |
|---|---|
| `visited()` | 訪れた結界 `[{mapId, eventId, x, y, name}]`（写し。訪れた順） |
| `visit(mapId, eventId)` | **今のマップ**の結界を訪れたことにする（文章は出さない。メモは足す）。覚えたらその写し、結界でなければ `null` |
| `destinations()` | 今の転送の一覧 `[{name, mapId, eventId, x, y, d, home}]`（拠点が先頭、いまの所は除く） |
| `warpTo(index)` | `destinations()` の `index` 番へ転送する（効果音と場所移動の予約。できたら `true`） |
| `addSource(fn)` | ほかのプラグインが行き先を足す（P13 の見張り台）。`fn()` は `[{name, mapId, x, y, d}]`。一覧の後ろに足し（同じ名前は重ねない）、着く所はその座標のまま（`exact: true`） |
| `openMenu(eventId?)` | その結界（省略で目の前か足元の結界）の選択肢を出す。イベントが動いていればしない（`false`） |
| `recordSlot()` | 「記録を作る」が書く枠の番号（書ける枠が無ければ `-1`。P14） |
| `saveRecord(label)` | 今の状態を記録として書く（`Promise`。書いた枠の番号で解決する。P14） |

## 中身（alias したところ）
- `Game_Interpreter.prototype.setup`：`<hai_warp>` のイベントが始まるとき、list を作る（訪れる・文章・選択肢）。
- `Game_Event.prototype.start`：中身のない結界も始める。調べた（`Game_Player.triggerAction` の中）か触れたかを覚える。
- `Game_Player.prototype.checkEventTriggerTouch`：「決定ボタン」の結界にぶつかったら、まだ訪れていなければ始める。
- `Game_Player.prototype.performTransfer`：結界への転送で着いたあと、1 マス下に立てるか見て位置を直す。
- `Window_SavefileList.prototype.drawTitle`：「記録を作る」で作った記録の名前を、「ファイル N」の横に出す。
