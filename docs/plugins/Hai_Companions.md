# Hai_Companions — 仲間：遺骸・召喚・控え・記憶の断片（P6）

> 注：この説明の**例**（セレス・オーブ・牢獄の間・魔石・旧マップの番号など）は前の世界「灰の王国」のもの（控えは [docs/old/](../old/)）。新しい世界「最後の鐘」の設計は [docs/world.md](../world.md)。仕組みの直しは P11・P12 などの issue で行う。

VISION.md の核 5「仲間は死者の霊。遺骸を見つけ、拠点で呼び戻す。記憶 4 断片で完全体」のためのプラグイン（#45）。
仲間 5 人の設定は [docs/old/world.md](../old/world.md) 6 章（前の世界）。新しい世界の仲間 7 人は [docs/world.md](../world.md) 6 章。
**本文（遺骸・記憶の文章）はイベントの「文章の表示」（101・401）に書く。プラグインは本文を持たない**（W レーンが 6 章の表をそのまま写せるように）。
プラグインが持つのは「見つけた・呼び戻した・読んだ」の状態と、本文の後ろに足す一行・召喚陣・編成の画面。

## メモ欄のタグ
| タグ | 置く所 | 中身 |
|---|---|---|
| `<hai_remains:5>` | 遺骸のイベント | アクター 5 の遺骸 |
| `<hai_memory:5,2>` | 記憶の断片のイベント | アクター 5 の記憶の 2 番目（1 生い立ち・2 転機・3 罪か誇り・4 臨終） |
| `<hai_wake:……>` | アクター（`Actors.json`） | 召喚して目覚めたときの一言（顔と名前つきで出す。無ければ出さない。`>` は書けない） |
| `<hai_complete:5>` | スキル（`Skills.json`） | アクター 5 が完全体で覚える強技。**完全体のほかでは覚えない**（職業の習得表・レベルアップ・イベントの「スキルの増減」でも覚えない） |
| `<hai_vow>` | ステート（`States.json`） | このステートの者が、味方への物理攻撃の身代わりになる（鉄の誓い） |

### 遺骸のふるまい
- 調べると、イベントの文章がそのまま出て、その後に効果音（Teleport）と「**オルドの遺骸を拠点へ送った。**」。
- 読み終えたら（イベントの処理が終わったら）：見つけた扱い（`found[5] = true`）、そのイベントの**セルフスイッチ A を ON**、スイッチ 131〜135 を ON（下の「筋の旗」）。
- 2 ページ目（セルフスイッチ A）を画像なし・中身なしにすると、遺骸が消える（送られた）。
- 見つけたあとに同じ遺骸を調べても、一行は足さない。

### 記憶の断片のふるまい
- 調べると、イベントの文章の後に「**メモ：オルドの記憶 2/4「転機」**」（効果音 Book1）。
- 読み終えたら：`memories[5][2] = true`、セルフスイッチ A を ON、メモ帳に一行（`Hai.Thoughts.addNote`、kind `"memory"`、ID `memory:5,2`）、変数 131〜135 に読んだ数。
- **4 つ目**を読むと、続けて「オルドの記憶がすべて戻った。オルドは完全体になった！／強技「鉄の誓い」を覚えた。」（効果音 Saint5）。
  その仲間が `<hai_complete:5>` のスキルを覚え、スイッチ 141〜145 を ON。**仲間がまだ加わっていなくても**読めて、覚えた技は呼び戻したときに持っている。
- 読み直しても一行も知らせも出ない。`<hai_thought>` と同じイベントに書いてもよい（「（読んだ）」は Hai_Thoughts が付ける）。
- 遺骸と記憶を 1 つのイベントにまとめてもよい（`<hai_remains:5><hai_memory:5,4>`。オルドの臨終は遺骸と同じ場所）。足す行は「遺骸を送った」→「メモ」→「完全体」の順。

## プラグインコマンド
| コマンド | 引数 | 中身 |
|---|---|---|
| `summonMenu`（召喚陣） | なし | 見つけた遺骸のうち、まだ呼び戻しておらず、パーティにいない仲間を選択肢で出す（最後に「やめる」）。選ぶと 効果音 → 暗転 → 呼び戻す → 明るくなる → 「〜が目を覚ました。」→ 目覚めの一言。誰もいなければ「まだ呼び戻せる魂がない。」 |
| `partyMenu`（編成） | なし | 編成の画面を開く（下） |
| `summon` | `actorId` | 演出なしで呼び戻す（見つけた扱いにもする） |

### 編成の画面（`Scene_HaiParty`）
- `Window_MenuStatus`（メニューの「並び替え」と同じ窓）にパーティ全員。1 人選び、もう 1 人選ぶと入れ替わる。同じ人をもう一度選ぶか、キャンセルで取り消し。
- **上から 4 人が戦闘に出る**（`maxBattleMembers`）。控え（5 人目から）は顔が薄く出る（MZ の既定）。
- **主人公（アクター 1）は控えに回せない**：入れ替えると主人公が 5 番目以降になるときはブザーが鳴り、上の説明が「〜は控えに回せない。」になる。
  これは `Game_Party.swapOrder` で守っているので、メニューの「並び替え」でも同じ（そちらは何も起きないだけ）。

### 鉄の誓い（`<hai_vow>`）
MZ の「かばう」は HP が 1/4 を切った味方しか守らないので、`<hai_vow>` のステートの者がいる間は、味方への**物理**攻撃（必中でないもの）を必ず身代わりで受ける
（`BattleManager.checkSubstitute`・`Game_Unit.substituteBattler` の alias）。反撃はステートの「反撃率 100%」。

## 筋の旗（docs/old/world.md 8 章）
状態は `$gameSystem._hai.companions` が正本。W のイベントが条件分岐で見られるように、変わったときにスイッチと変数へ**写す**（パラメータで番号を変えられる。0 で写さない）。
仲間の並び（パラメータ `companionActors`、既定 `5,6,7,8,9`）の順に 1 つずつ後ろ。

| 旗 | 既定 | いつ |
|---|---|---|
| 遺骸:オルド〜シオン | スイッチ 131〜135 | 遺骸を見つけたとき |
| 加入:オルド〜シオン | スイッチ 136〜140 | 召喚したとき |
| 完全体:オルド〜シオン | スイッチ 141〜145 | 記憶が 4 つ揃ったとき |
| 仲間の数 | 変数 102 | 召喚したとき（召喚した人数） |
| 記憶:オルド〜シオン | 変数 131〜135 | 記憶を読んだとき（読んだ数 0〜4） |

`System.json` に名前の無い番号は、コアが書き込みを無視する（W1 が 8 章の名前を入れると効く）。旗はイベントの側から変えない（プラグインの状態とずれる）。

## W レーンが遺骸と記憶を置く手順（文字マップ）
設定（`tools/maps/src/<名前>.json`）の `events` に書く。見本は `tools/maps/src/p6_companions.txt`・`.json`（→ `data/Map907.json`）。

### 遺骸（`docs/old/world.md` 6 章の「遺骸の場所」）
1. 場所のマスに文字を置き（`chars` に `{ "as": "." }` で足す）、`type: "raw"` で 2 ページ。
2. 1 ページ目：遺骸の絵（`Damage1` などの倒れた人）・「通常キャラと同じ」・決定ボタン、list に遺骸の文章（101・401）。2 ページ目：セルフスイッチ A、画像なし、中身なし。
3. `note` に `<hai_remains:アクター ID>`。名前に「遺骸」を入れる（T2 の到達性の検査が「遺骸」を見る）。

```json
{
  "at": "a", "name": "遺骸 オルド", "type": "raw", "note": "<hai_remains:5>",
  "pages": [
    { "image": { "characterName": "Damage1", "characterIndex": 0, "direction": 2, "pattern": 1 }, "priorityType": 1, "trigger": 0,
      "list": [
        { "code": 101, "indent": 0, "parameters": ["", 0, 0, 2, ""] },
        { "code": 401, "indent": 0, "parameters": ["崩れた梁の下に、大柄な男の亡骸がある。"] },
        { "code": 0, "indent": 0, "parameters": [] }
      ] },
    { "conditions": { "selfSwitchCh": "A", "selfSwitchValid": true }, "priorityType": 0 }
  ]
}
```

### 記憶の断片（`docs/old/world.md` 6.1）
1. 場所のマスに文字を置き、`type: "text"` のイベントにする（読み直せるように 1 ページのまま）。
2. `note` に `<hai_memory:アクター ID,番号>`（番号は 1 生い立ち・2 転機・3 罪か誇り・4 臨終）。残留思念としても数えるなら `<hai_thought:R12>` も書く。
3. `lines` に本文を写す（1 ページ 4 行まで。多ければ配列の配列）。
4. オルドの臨終（R12）は遺骸と同じ所：遺骸のイベントの `note` を `<hai_remains:5><hai_memory:5,4><hai_thought:R12>` にし、本文を 6.1 の R12 にする。

### 召喚陣（Map010 (28,17)。W2 が仮のイベントを置き換える）
list を「プラグインコマンド Hai_Companions → 召喚陣」だけにする。説明の台詞（スイッチ 113「召喚陣を教わった」）は W がその前に置く。
```json
{ "code": 357, "indent": 0, "parameters": ["Hai_Companions", "summonMenu", "召喚陣", {}] }
```
編成は同じく `partyMenu`（召喚陣を調べたときの選択肢にするか、別の置物にするかは W が決める）。

## 状態（セーブに入る）
```js
$gameSystem._hai.companions = {
  found: { 5: true, 6: true },       // 遺骸を見つけた
  summoned: { 5: true },             // 召喚した
  memories: { 5: { 1: true, 4: true } }, // 読んだ記憶
};
```
古いセーブで欄が無ければ、読むときに空で作る。パーティの並び（控え）は MZ の `$gameParty._actors` のまま。
