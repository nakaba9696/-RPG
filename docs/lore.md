# 道具で語る設計 — 灰の王国（D7）

持ち主の方針（2026-10-11）：「アイテムの配置やテキストで、徐々に真相が分かっていく」。
拾った物・落とした物・作った物の**説明（2 行）と来歴（3〜6 行）**の一行一行を、真相のかけらにする。ストーリー（[world.md](world.md)・[world2.md](world2.md)）は変えない。

- 書き方の決まりは [docs/knowhow.md](knowhow.md) 5.1（このファイルの文はそれに従って書いた）。段階の印・禁止語・口調は world.md 10・11 章。
- 来歴の長い文は、アイテム・武器・防具の**メモ欄 `<hai_lore>…</hai_lore>`** に書く（[1.2](#12-来歴の書き場所メモ欄-hai_lore)）。U4（#96 `Hai_Lore`）が読む画面と「遺物の記録」を作る。
- 第1段階の今ある物の説明の差し替えは [docs/rewrite.md](rewrite.md) 3 章（差し替えるのは W2b）。第2段階の物は、W3〜W5 がこのファイルから写す（[world2.md 19 章](world2.md#19-w3w5-への申し送りd7道具で語る)）。
- ID・効果の数値・置き場所の座標は**推し**。W が帯と数値を決めたら、W の PR でこのファイルの行を直してよい（文は変えずに）。

## 1. 約束

### 1.1 説明欄（MZ の `description`、2 行）
- **1 行目は効果を短く**（数値を書いてよいのはここだけ）。効果の無い大事なものは「何を開けるか／何か」。
- **2 行目は来歴の一行**：物の様子か、置かれていた所。答えは書かない。
- 1 行は全角 40 字まで（説明の窓は全角およそ 46 字。余白を見て 40 字）。改行は `\n`。

### 1.2 来歴の書き場所（メモ欄 `<hai_lore>`）
```
<hai_lore>
帝国の工兵隊の鍵。輪に、木の札が一枚下がっている。
札の字は「下層　四十二」。四十二を削って三十九。
</hai_lore>
```
- 開きタグと閉じタグはそれぞれ 1 行に置き、間の 1 行が画面の 1 行（3〜6 行、1 行は全角 40 字まで）。
- 本文に `<` と `>` を使わない（MZ のメモ欄の読み取りが壊れる）。制御文字（`\C[n]` など）も使わない。行の頭に「」を付けない（台詞の引用は行の中で「」）。
- ほかのタグ（`<hai_max:2>`・`<hai_unique>`・`<hai_craft:…>`）と同じメモ欄に並べてよい。順はどれでもよい。
- **禁止語は全部使わない**。アイテムは持ち歩けて、どのマップでも読めるので、マップ限定の語（魂の灰・取り立て・結界の錠 など。world.md 10 章で「使ってよい所」がある語）も書かない。
  今の `tests/t_words.mjs` は説明欄だけを見ていて、メモ欄の `<hai_lore>` と、データベース側のマップ限定の語は見ない。U4（#96）が t_words にこのタグを足す（[1.4](#14-点検)）。

### 1.3 段階の印
| 印 | アイテムでの書き方 |
|---|---|
| 〔知〕 | 物の様子、持ち主の暮らし、誰でも知っている出来事（帝国の侵攻、異端狩り、灰の病、王都の封鎖） |
| 〔噂〕 | 書き付け・言い伝え・「〜という」で。物の**ずれ**（数が合わない、影が無い、墨が乗らない）で見せる |
| 〔進〕 | その真相が分かる所（world2.md 13 章の「主に出る所」・オーブの間）で手に入る物だけ。印の後ろに `〔進：場所〕` |
| 〔秘〕 | 書かない |

- 仲間の記憶（〔進〕）の中身を、物で先に言わない。物は記憶の**隣**に置く（同じ手触りの別の物）。
- 同じことを 3 通りで言わない：思念・オーブの場面がもう言った真相は、物では数・跡・欠けの別の角度から触る。

### 1.4 点検
- `node tests/run.mjs t_words`：説明欄の禁止語・制御文字を見る。
- このファイルの説明と来歴は、D7 の PR で次を数えた（`docs/` は t_words の対象外なので、同じ規則を手で回した）：禁止語の表 20 語（マップ限定の語も）、
  ぼかし語（どこか・少しだけ・そっと・ふと・かすかに・まるで）、締めの余韻（気がした・気がする・なぜか）、1 つの来歴の「……」は 1 つまで、1 文の読点は 3 つまで、1 行 40 字まで、来歴 3〜6 行・説明 2 行。
- U4 が t_words を直すときの頼み：`<hai_lore>([\s\S]*?)</hai_lore>` の中も集める。データベースの説明欄と来歴では、マップ限定の禁止語も当てる（今は `mapId === null` で見ない）。
