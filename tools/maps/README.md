# 文字マップ → `data/MapNNN.json`（tools/maps/）

1 文字 = 1 タイルの文字マップから、MZ のマップ（`data/MapNNN.json`）を作り、`data/MapInfos.json` に要素を足す。
オートタイル（A1〜A4）の形は周りを見て自動で決まり、壁は上面と側面に自動で分かれ、影も付く。
生成物（`data/MapNNN.json`）はコミットする（エディタでも開ける）。

```bash
node tools/maps/build.mjs                  # tools/maps/src/*.txt をすべて変換
node tools/maps/build.mjs sample_dungeon   # 1 枚だけ
node tools/maps/build.mjs --check          # 書き出さずに、data/ が今の文字マップと一致するかだけ見る
node tools/maps/density.mjs                # 置き物の密度の報告（1 画面ごと。下の「置き物の密度」）
```
`tests/t_maps.mjs` も「生成物が文字マップと一致するか」を確かめるので、文字マップを直したら変換し直してコミットする。

## ファイル
| ファイル | 中身 |
|---|---|
| `tools/maps/legend.json` | 凡例：タイルセットごとの文字の意味（**追記だけ**。既存の文字の意味を変えない） |
| `tools/maps/src/<名前>.txt` | 文字マップ（W レーンなどが書く） |
| `tools/maps/src/<名前>.json` | そのマップの設定（マップ ID・名前・凡例・BGM・イベント・その地図だけの文字・スタンプ・散らし） |
| `tools/maps/src/<名前>.deco.txt` | 重ね書きの文字マップ（無くてよい。置き物の z=2・z=3 だけ） |
| `tools/maps/density.mjs` | 置き物の密度の報告 |
| `tools/maps/build.mjs` | 変換 |
| `tools/maps/autotile.mjs` | オートタイルの形の計算 |

## 文字マップ（`.txt`）
```
##########################
###......########........#
###..o..............__...#
###..S...########...T....#
#####.###########...<....#
```
- どの行も同じ長さ（全角も 1 文字と数える）。行の数が高さ、1 行の文字数が幅。
- 地図の外は「隣が同じ種類」と見る（端に縁を描かない。エディタと同じ）。

## 設定（`.json`）
```json
{
  "mapId": 900,
  "name": "T_見本の迷宮",
  "displayName": "見本の迷宮",
  "legend": "dungeon",
  "bgm": "Dungeon1",
  "chars": {
    "S": { "name": "開始地点（テスト用の目印）", "as": "." },
    "T": { "name": "石碑", "as": "." }
  },
  "events": [
    { "at": "T", "name": "石碑", "type": "text", "image": { "tileId": "B:177" }, "lines": ["一行目", "二行目"] },
    { "at": "<", "name": "上り階段", "type": "transfer", "to": [1, 8, 6, "down"] }
  ]
}
```
| 欄 | 中身 |
|---|---|
| `mapId` | 出力先のマップ ID（`data/Map900.json`）。**自分の帯の番号**（`docs/ROADMAP.md` の「ID の帯」） |
| `name` | `MapInfos.json` の名前（エディタの左の一覧）。`MapInfos.json` に要素がすでにあれば触らない |
| `parentId` | エディタの一覧での親マップ（省略で 0） |
| `displayName` | ゲーム中に出る表示名 |
| `legend` | `legend.json` の `sets` の名前（タイルセットも決まる） |
| `tilesetId` | 凡例のタイルセットを変えたいとき |
| `bgm` | `"Dungeon1"` か `{ "name", "volume", "pitch", "pan" }`。指定すると自動演奏 |
| `bgs` | `bgm` と同じ書き方（環境音）。指定すると自動演奏 |
| `note` | マップのメモ欄（`<hai_…>` のタグ） |
| `fields` | そのほかのマップの欄を直接（`{ "scrollType": 3, "disableDashing": true }` など） |
| `chars` | この地図だけの文字（`legend.json` の文字を上書きもできる） |
| `deco` | この地図だけの重ね書きの文字（`legend.json` の `deco` に足す・上書きする） |
| `stamps` | スタンプ（下の「置き物の道具」） |
| `scatter` | 散らし（下の「置き物の道具」） |
| `events` | イベント（下） |
| `shadows` | `false` で影を付けない |

## 文字の定義（`legend.json` の `sets.<名前>.chars` と、設定の `chars`）
| 欄 | 中身 |
|---|---|
| `tiles` | 層 0〜3 のタイル（下の「タイルの書き方」）。`[床, 床の上, 上層1, 上層2]` |
| `wall` | 自動の壁：`{ "top": "A4:1", "side": "A4:9", "height": 2 }`。下 `height` マス以内に壁でないマスがあれば側面、なければ上面 |
| `ledge` | 段差（歩ける高台）：`{ "top": "A4:37", "side": "A4:45", "height": 1, "level": 1 }`。下の「置き物の道具」 |
| `roof` | 建物の屋根：`{ "top": "A3:5", "side": "A3:13", "height": 2 }`。下の「置き物の道具」 |
| `as` | 別の文字を下敷きにする。`tiles` の `null` の所は下敷きのまま（`"as": ".", "tiles": [null, null, "B:41"]` で床の上に岩） |
| `region` | リージョン ID（層 5） |
| `block` | `true` なら見えないイベントを置いて通れなくする（タイルの通行を地図ごとに上書きしたいとき） |
| `shadow` | `false` なら、この壁は右のマスに影を落とさない（隠し通路の手がかり「影の無い壁」。`docs/plugins/Hai_HiddenPassage.md`） |
| `name` | 説明（変換には使わない） |

通行はタイルセット（`data/Tilesets.json` の `flags`）で決まる。タイルセットで通れるタイルを地図の一部だけ通れなくするには `block`、
通れないタイルを通れるようにする（隠し通路など）は P2 の決まり（リージョン 251–254。[docs/plugins/Hai_HiddenPassage.md](../../docs/plugins/Hai_HiddenPassage.md)）に従う。

## タイルの書き方
| 書き方 | 意味 |
|---|---|
| `"A1:0"`〜`"A1:15"` | A1（水・滝）のオートタイル。番号はエディタの A タブの並び（左上から横に 8 個ずつ） |
| `"A2:0"`〜`"A2:31"` | A2（地面）のオートタイル |
| `"A3:0"`〜`"A3:31"` | A3（建物の屋根・壁）のオートタイル |
| `"A4:0"`〜`"A4:47"` | A4（壁）のオートタイル。行ごとに上面（0〜7、16〜23、32〜39）と側面（8〜15、24〜31、40〜47） |
| `"A5:0"`〜`"A5:127"` | A5（オートタイルでない地面） |
| `"B:0"`〜`"B:255"`（C・D・E も） | 上層のタイル。0〜127 は画像の左半分（横 8 個ずつ）、128〜255 は右半分。`"B:0"` は「何もない」 |
| `"B@3,2"` | 画像の列 3・行 2（0 始まり、16 列 × 16 行） |
| 数 | タイル ID そのまま |

## オートタイルの形の決め方
- 推測の表は持たず、`js/rmmz_core.js` の `Tilemap.FLOOR_AUTOTILE_TABLE`・`WALL_AUTOTILE_TABLE`・`WATERFALL_AUTOTILE_TABLE` を読み込み、
  周りのつながりから「4 つの 1/4 マスに欲しい部品」を決めて、それに合う形の番号を表から引く（`autotile.mjs`）。
- 床型（A1 の水、A2、A4 の上面）：周り 8 マスが同じ kind か。辺が違えば縁、斜めだけ違えば内側の角。47 通り。
- 壁型（A3、A4 の側面）：上下左右が同じ kind か。16 通り。滝型（A1 の滝）：左右だけ。4 通り。
- 同じ層の、同じ kind だけを「つながる」と見る（別の kind の A2 どうしは縁で区切られる）。
- 確かめ方（`tests/t_maps.mjs`）：
  - 床型の 256 通りの周りが 47 通りの形に行き渡り、角の値（左上 1・右上 2・右下 4・左下 8）と壁型の値（左 1・上 2・右 4・下 8）が合う。
  - エディタが設定した A4 の壁の上面の通行（縁の向きに出られないビット）が、全タイルセットの 120 種すべてで形の計算と一致する。
  - エディタの書いたマップ（Map001）を読み戻して計算し直すと一致する。
  - 見本の迷宮を MZ で表示して描画と通行を見る。

## 未対応・制約
- A2 の「カウンター」（テーブル）の種類の特別な描き方は、MZ の描画側（`_isTableTile`）に任せる（形の計算は床型と同じ）。
- A1 の水と滝の自動の組み立て（水の下に滝を置く）はしない。`tiles` で層ごとに書けば形の計算はされる。
- 影は「左のマスと左上のマスがどちらも A3・A4」のとき左半分に付ける。エディタの影と完全に同じかはエディタで確かめる。
- 段差・屋根の側面の下の段の形は、エディタと違うことがある（下の段の上面を側面の下までつなげる。梯子へ上がれるようにするため）。

## イベント
| `type` | 欄 | 中身 |
|---|---|---|
| `text` | `lines`（行の配列。ページを分けるなら配列の配列）、`image`、`speaker`、`background` | 決定ボタンで文章を出す。`image` を付けると通れない置物になる |
| `transfer` | `to: [マップ ID, x, y, 向き]`（向きは `"down"` など か 2/4/6/8）、`image`、`trigger`、`fade` | 踏むと場所移動（効果音 Move1） |
| `block` | なし | 見えない通行止め |
| `raw` | `pages`（MZ のページ。欠けた欄は既定値で埋まる） | そのほか何でも（`list` は `docs/mz-data.md` と CLAUDE.md のイベントコマンドの表） |

- 置き場所は `"at": "T"`（その文字があるマスすべてに 1 つずつ）か `"x"`・`"y"`。
- `image` は `{ "tileId": "B:177" }`（タイルの絵）か `{ "characterName": "Actor1", "characterIndex": 0, "direction": 2 }`。
- 名前は `name`、メモ欄は `note`。イベント ID は `events` の順、`block` の文字はその後ろ。
- `"id": 71` を付けたイベントは、その番号に置く（`x`・`y` で置く。並びのイベントと `block` の後ろで、間の番号は `null`）。いくつものレーンが同じマップにイベントを足すとき、番号の帯を分けるために使う（010 は W15 42–55・W16 56–60・W17 61–70・W14 71–99）。

## 置き物の道具（T10。`docs/mapdesign.md` 6.3）
床と壁の文字マップ（`.txt`）とは別に、置き物を描く道具。どれも使わなければ、出力は前と同じ。
全部を使った見本は `tools/maps/src/t10_tools.*`（Map915「T_置き物の道具の見本」、凡例 `village`）。

### 重ね書き（`<名前>.deco.txt`）
`.txt` と同じ大きさの 2 枚目。z=2・z=3 だけを書く。`.` と空白は「何も置かない」。床の種類ごとに置き物の文字を作らなくてよい。
```
<名前>.txt                 <名前>.deco.txt
,,,,,::.......             ..g.g.........  ← g は墓標
,,,,,::.......             ...x..........  ← x は骸骨
```
文字の意味は `legend.json` の `sets.<名前>.deco`（とマップの設定の `deco`）。
```json
"deco": {
  "g": { "name": "墓標", "z2": "B:142" },
  "X": { "name": "瓦礫の上の骸骨", "z2": "D:120", "z3": "D:242" }
}
```
| 欄 | 中身 |
|---|---|
| `z2` | z=2（上層の 1 枚目）のタイル |
| `z3` | z=3（上層の 2 枚目）のタイル。z2 の上に重なる |
| `block` | `true` なら見えないイベントで通れなくする |

### スタンプ（設定の `stamps`）
左上の 1 文字で、2 × 1・3 × 3 などの大きな置き物をまとめて置く。文字は重ね書き（`.deco.txt`）に書くのを推す。
`.txt` に書いたときは、その下は `as`（既定 `"."`）の床になる。
```json
"stamps": [
  { "at": "Y", "name": "大木", "tiles": [["B:176", "B:177"], ["B:184", "B:185"]] },
  { "at": "W", "name": "薪の山と壺", "tiles": [["B:170", "B:170"]], "upper": [["B:144", null]] }
]
```
| 欄 | 中身 |
|---|---|
| `at` | 左上の 1 文字（全角も可） |
| `tiles` | z=2 の行の配列。`null` のマスは置かない |
| `upper` | z=3 の行の配列（無くてよい） |
| `as` | `.txt` に書いたときの下の床の文字（既定 `"."`） |

- 重ね書きで、スタンプがかぶさるマス（左上を除く）は `.` にする（ずれると変換が止まる）。地図の外にはみ出しても止まる。

### 散らし（設定の `scatter`）
`on` の文字のマスに、種付きの乱数で `rate` の割合だけ `tiles` のどれかを置く。何度走らせても同じ結果（種を変えると並びが変わる）。
```json
"scatter": [
  { "on": ",", "tiles": ["B:152", "B:153", "B:160"], "rate": 0.2, "seed": 12 },
  { "on": ".", "z": 1, "tiles": ["A2:15"], "rate": 0.08, "seed": 21 }
]
```
| 欄 | 中身 |
|---|---|
| `on` | 散らす下の文字（`.txt` の文字。`"^A"` のように何文字でも） |
| `tiles` | 置くタイル（同じものを並べると出やすくなる） |
| `rate` | 割合（0 より大きく 1 以下） |
| `seed` | 種（整数） |
| `z` | 置く層（既定 2。1 なら床の重ね。A2 のオートタイルを散らすと灰だまり・汚れのまだらになる） |
| `solid` | `true` なら通れないタイルも散らせる（既定では、通れないタイルを書くと変換が止まる。道をふさがないため） |

- 置く層（z=2 なら z=3 も）が空いていて、重ね書き・スタンプ・イベント・段差や建物の側面のないマスだけに置く。
- 左上から行ごとに数えるので、地図の上の方を書き換えると、下の方の並びも変わる。

### 段差（文字の `ledge`）
A4 の上面を歩ける高台として描き、その下 `height` 行に崖の側面を自動で付ける。文字マップには**高台の上面の広さだけ**を書く。
側面になったマスは、もとの文字の z=0・z=1 を捨て、z=2・z=3 は残す（側面の行に梯子・坂の文字を書く）。
```
.....^^^^^^^^           ^ 高台（"ledge": { "top": "A4:37", "side": "A4:45", "height": 1 }）
.....^^^^^^^^           | 梯子（"as": ".", "tiles": [null, null, "B:18"]）
.....|....../.          / 坂の石段（"as": ".", "tiles": [null, null, "B:1"]）
..............          ← 14 行目（| と / の行）が崖の側面になる
```
| 欄 | 中身 |
|---|---|
| `top` | 上面（A4 の上面：A4:0〜7・16〜23・32〜39） |
| `side` | 側面（省くと top の 8 つ後＝画像の 1 行下） |
| `height` | 側面の行の数（既定 1） |
| `level` | 段の高さ（既定 1）。高い段の側面は低い段の上面にかぶさる。2 段にするなら、上の段を `level: 2` の別の文字にする |

- 上面の縁の通行はタイルセットの設定で決まる。縁の向きに出られない種類（`段差A（草地）` など Outside_A4 の段差）を選ぶと、高台の横からは上り下りできず、梯子・坂でだけ行き来できる。
- 2 段目の側面の行に梯子を書くときは、その文字の `as` を 1 段目の文字にする（下が 1 段目の上面のまま。見本の `L`）。
- 側面がかぶさった下の段の上面は、その側面とつながった形になる（縁を描かない。梯子へ上がれるように）。同じ絵の段でも `level` が違えばつながらない。

### 建物（文字の `roof`）
A3 の屋根の文字の下 `height` 行に、外壁を自動で付ける。屋根は通れない。戸口・窓は外壁の行に z=2 の文字で書く。
```
..RRRRRR..             R 屋根（"roof": { "top": "A3:5", "side": "A3:13", "height": 2 }）
..RRRRRR..
..........             ← 外壁（窓 n）
....d.....             ← 外壁（戸口 d。調べる戸ならイベントも置く）
```
`top` は A3 の屋根（A3:0〜7・16〜23）、`side` は外壁（省くと top の 8 つ後）、`height` の既定は 2、`level` の既定は 10（高台の上に建てられる）。

### 置き物の密度
`node tools/maps/density.mjs`（マップ ID を並べると、その枚だけ。エディタで描いたマップも可）。`tests/t_maps.mjs` も同じ報告を出す（落とさない）。
1 画面（27 × 15）ごとに「置き物のある床の割合 / 空の 3 × 3 の数」と、1 枚の z=2・z=3 の数を出す。目安は `docs/mapdesign.md` 6.1（床の 15〜25%、何もない 3 × 3 を作らない）。
- 床：z=0 が A3・A4 でなく、タイルセットの通行で通れるマス。段差の上面は床に数える。森の木の列のような、通れない置き物の壁の中は数えない。
- 空の 3 × 3：9 マスとも「置き物もイベントもない床」の窓の数（重なりも数える）。
