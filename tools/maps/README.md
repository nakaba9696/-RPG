# 文字マップ → `data/MapNNN.json`（tools/maps/）

1 文字 = 1 タイルの文字マップから、MZ のマップ（`data/MapNNN.json`）を作り、`data/MapInfos.json` に要素を足す。
オートタイル（A1〜A4）の形は周りを見て自動で決まり、壁は上面と側面に自動で分かれ、影も付く。
生成物（`data/MapNNN.json`）はコミットする（エディタでも開ける）。

```bash
node tools/maps/build.mjs                  # tools/maps/src/*.txt をすべて変換
node tools/maps/build.mjs sample_dungeon   # 1 枚だけ
node tools/maps/build.mjs --check          # 書き出さずに、data/ が今の文字マップと一致するかだけ見る
```
`tests/t_maps.mjs` も「生成物が文字マップと一致するか」を確かめるので、文字マップを直したら変換し直してコミットする。

## ファイル
| ファイル | 中身 |
|---|---|
| `tools/maps/legend.json` | 凡例：タイルセットごとの文字の意味（**追記だけ**。既存の文字の意味を変えない） |
| `tools/maps/src/<名前>.txt` | 文字マップ（W レーンなどが書く） |
| `tools/maps/src/<名前>.json` | そのマップの設定（マップ ID・名前・凡例・BGM・イベント・その地図だけの文字） |
| `tools/maps/build.mjs` | 変換 |
| `tools/maps/autotile.mjs` | オートタイルの形の計算 |

## 文字マップ（`.txt`）
```
##########################
###......########........#
###..o..............__...#
###..S...########...T....#
#####.###########...<....#
```
- どの行も同じ長さ（全角も 1 文字と数える）。行の数が高さ、1 行の文字数が幅。
- 地図の外は「隣が同じ種類」と見る（端に縁を描かない。エディタと同じ）。

## 設定（`.json`）
```json
{
  "mapId": 900,
  "name": "T_見本の迷宮",
  "displayName": "見本の迷宮",
  "legend": "dungeon",
  "bgm": "Dungeon1",
  "chars": {
    "S": { "name": "開始地点（テスト用の目印）", "as": "." },
    "T": { "name": "石碑", "as": "." }
  },
  "events": [
    { "at": "T", "name": "石碑", "type": "text", "image": { "tileId": "B:177" }, "lines": ["一行目", "二行目"] },
    { "at": "<", "name": "上り階段", "type": "transfer", "to": [1, 8, 6, "down"] }
  ]
}
```
| 欄 | 中身 |
|---|---|
| `mapId` | 出力先のマップ ID（`data/Map900.json`）。**自分の帯の番号**（`docs/ROADMAP.md` の「ID の帯」） |
| `name` | `MapInfos.json` の名前（エディタの左の一覧）。`MapInfos.json` に要素がすでにあれば触らない |
| `parentId` | エディタの一覧での親マップ（省略で 0） |
| `displayName` | ゲーム中に出る表示名 |
| `legend` | `legend.json` の `sets` の名前（タイルセットも決まる） |
| `tilesetId` | 凡例のタイルセットを変えたいとき |
| `bgm` | `"Dungeon1"` か `{ "name", "volume", "pitch", "pan" }`。指定すると自動演奏 |
| `note` | マップのメモ欄（`<hai_…>` のタグ） |
| `fields` | そのほかのマップの欄を直接（`{ "scrollType": 3, "disableDashing": true }` など） |
| `chars` | この地図だけの文字（`legend.json` の文字を上書きもできる） |
| `events` | イベント（下） |
| `shadows` | `false` で影を付けない |

## 文字の定義（`legend.json` の `sets.<名前>.chars` と、設定の `chars`）
| 欄 | 中身 |
|---|---|
| `tiles` | 層 0〜3 のタイル（下の「タイルの書き方」）。`[床, 床の上, 上層1, 上層2]` |
| `wall` | 自動の壁：`{ "top": "A4:1", "side": "A4:9", "height": 2 }`。下 `height` マス以内に壁でないマスがあれば側面、なければ上面 |
| `as` | 別の文字を下敷きにする。`tiles` の `null` の所は下敷きのまま（`"as": ".", "tiles": [null, null, "B:41"]` で床の上に岩） |
| `region` | リージョン ID（層 5） |
| `block` | `true` なら見えないイベントを置いて通れなくする（タイルの通行を地図ごとに上書きしたいとき） |
| `shadow` | `false` なら、この壁は右のマスに影を落とさない（隠し通路の手がかり「影の無い壁」。`docs/plugins/Hai_HiddenPassage.md`） |
| `name` | 説明（変換には使わない） |

通行はタイルセット（`data/Tilesets.json` の `flags`）で決まる。タイルセットで通れるタイルを地図の一部だけ通れなくするには `block`、
通れないタイルを通れるようにする（隠し通路など）は P2 の決まり（リージョン 251–254。[docs/plugins/Hai_HiddenPassage.md](../../docs/plugins/Hai_HiddenPassage.md)）に従う。

## タイルの書き方
| 書き方 | 意味 |
|---|---|
| `"A1:0"`〜`"A1:15"` | A1（水・滝）のオートタイル。番号はエディタの A タブの並び（左上から横に 8 個ずつ） |
| `"A2:0"`〜`"A2:31"` | A2（地面）のオートタイル |
| `"A3:0"`〜`"A3:31"` | A3（建物の屋根・壁）のオートタイル |
| `"A4:0"`〜`"A4:47"` | A4（壁）のオートタイル。行ごとに上面（0〜7、16〜23、32〜39）と側面（8〜15、24〜31、40〜47） |
| `"A5:0"`〜`"A5:127"` | A5（オートタイルでない地面） |
| `"B:0"`〜`"B:255"`（C・D・E も） | 上層のタイル。0〜127 は画像の左半分（横 8 個ずつ）、128〜255 は右半分。`"B:0"` は「何もない」 |
| `"B@3,2"` | 画像の列 3・行 2（0 始まり、16 列 × 16 行） |
| 数 | タイル ID そのまま |

## オートタイルの形の決め方
- 推測の表は持たず、`js/rmmz_core.js` の `Tilemap.FLOOR_AUTOTILE_TABLE`・`WALL_AUTOTILE_TABLE`・`WATERFALL_AUTOTILE_TABLE` を読み込み、
  周りのつながりから「4 つの 1/4 マスに欲しい部品」を決めて、それに合う形の番号を表から引く（`autotile.mjs`）。
- 床型（A1 の水、A2、A4 の上面）：周り 8 マスが同じ kind か。辺が違えば縁、斜めだけ違えば内側の角。47 通り。
- 壁型（A3、A4 の側面）：上下左右が同じ kind か。16 通り。滝型（A1 の滝）：左右だけ。4 通り。
- 同じ層の、同じ kind だけを「つながる」と見る（別の kind の A2 どうしは縁で区切られる）。
- 確かめ方（`tests/t_maps.mjs`）：
  - 床型の 256 通りの周りが 47 通りの形に行き渡り、角の値（左上 1・右上 2・右下 4・左下 8）と壁型の値（左 1・上 2・右 4・下 8）が合う。
  - エディタが設定した A4 の壁の上面の通行（縁の向きに出られないビット）が、全タイルセットの 120 種すべてで形の計算と一致する。
  - エディタの書いたマップ（Map001）を読み戻して計算し直すと一致する。
  - 見本の迷宮を MZ で表示して描画と通行を見る。

## 未対応・制約
- A2 の「カウンター」（テーブル）の種類の特別な描き方は、MZ の描画側（`_isTableTile`）に任せる（形の計算は床型と同じ）。
- A1 の水と滝、A3 の屋根・壁の自動の組み立て（屋根の下に壁を置く）はしない。`tiles` で層ごとに書けば形の計算はされる。
- 影は「左のマスと左上のマスがどちらも A3・A4」のとき左半分に付ける。エディタの影と完全に同じかはエディタで確かめる。
- 段差（高さの違う床）や、壁の上面を歩ける高台はまだない。

## イベント
| `type` | 欄 | 中身 |
|---|---|---|
| `text` | `lines`（行の配列。ページを分けるなら配列の配列）、`image`、`speaker`、`background` | 決定ボタンで文章を出す。`image` を付けると通れない置物になる |
| `transfer` | `to: [マップ ID, x, y, 向き]`（向きは `"down"` など か 2/4/6/8）、`image`、`trigger`、`fade` | 踏むと場所移動（効果音 Move1） |
| `block` | なし | 見えない通行止め |
| `raw` | `pages`（MZ のページ。欠けた欄は既定値で埋まる） | そのほか何でも（`list` は `docs/mz-data.md` と CLAUDE.md のイベントコマンドの表） |

- 置き場所は `"at": "T"`（その文字があるマスすべてに 1 つずつ）か `"x"`・`"y"`。
- `image` は `{ "tileId": "B:177" }`（タイルの絵）か `{ "characterName": "Actor1", "characterIndex": 0, "direction": 2 }`。
- 名前は `name`、メモ欄は `note`。イベント ID は `events` の順、`block` の文字はその後ろ。
